## 2. 本轮踩到的坑（写下来省下一轮）

1. **UI 量具连注释里的字面量也算**：`raw_input` 的判据是正则 `<input\b`，我在注释里写了「不是裸 `<input>`」就被计 1 处（`ui:audit` 红）。写注释别放标签字面量。
2. **新路由要重派生 coverage**：`route_ui_coverage.py --check` 会报 hash 漂移，跑一次不带 `--check` 的即可（本次 `pending_backlog` ceiling **没**抬高）。
3. **本地扫描会把运行期产物当代码**：`agent/data/checkpoints/**/files/**` 里有源码副本、根目录 `.ci_watch*.py` 是未跟踪脚本 ⇒ `scan_settings.py --check` / `test_tool_definitions_yaml` 在**脏工作区**必红；判绿必须在干净 worktree（本轮就是这么做的）。
4. **pip 在这台机器上极慢**（~5 kB/s）：`pywinpty` 2.1MB 下了 2m45s。装依赖要放后台作业，不要阻塞在主流程里等。
5. **CI 多次被新 push 取消**（同 concurrency 组）：想拿终判就别连续推；文档类提交请带 `[skip ci]`。
6. **`/api/feedback/submit` 不是 v2 信封**（返回 `{success,data}`）：前端用裸 fetch + `res.ok`，别用 `postEnvelope`（会在成功响应上抛错）。
