   断言已改为"前缀 + 可选参数白名单"。

   占用而失败 ⇒ 用 `git fetch` + `git merge --no-edit -m "Merge origin/master [skip ci]"` 再 push。

   重建前端、重启、冒烟）；完成后 `/api/version` 的 backend/build_commit 必须等于 master。
