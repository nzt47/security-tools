## 3. 仍存残余与**具体阻塞**（本机实测，非推断）

### 3.1 execution_backend（partial）—— 镜内真实推理

- 现状：container 已可**协议真跑**（镜内对端 + 挂载分离实测绿灯）；`local` 执行档已 OWNED（`agent/subagent/local_inference.py`）。
- 阻塞：镜内**真实推理**需镜像自带 Ollama + 模型。本机实测 `Get-Command ollama` 无输出；`core/local_llm.py` 仅实现 `ollama` 分支（vLLM 声明未实现）。
- 可行交付（机制级，非闭环）：提供 `--handler` 参考执行体（包装 `local` 后端）+ 自带 Ollama 的镜像接线；单测用替身 LLM 验证映射与 fail-closed，但**真实推理 E2E 无法在本环境做**。

### 3.2 memory_ops（missing）—— 按分身的导出/擦除/迁移

- 现状：`ScopedMemoryDomain` 只有 `write`/`read`；`_LayeredBackend`/`_Mem0Backend` 亦然。
- 机制已存在：`agent/memory/layered_store.py` 有 `list_entries`/`delete_entry`；`agent/memory/forgetting.py` 有 `ForgettingEngine`/`MemorySnapshotStore`（快照 30 天 / 被遗忘权）。缺的是**按分身的入口**。
- 阻塞：**擦除不可逆**，且 `agent/subagent/sandbox.py` 对批量 `DELETE FROM` 有明确红线；需"先快照后删 + 显式 confirm + 审计 + 租户守域"一整套设计，并需人类批准。
- 建议切分：先做**导出 + 迁移**（只读 / 复制，零不可逆），擦除单独立项。
