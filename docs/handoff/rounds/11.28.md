**C. 白名单终端（不是自由 shell —— 这条是硬约束）**
- 为什么不做自由 shell：CodeQL 是必需检查，`py/command-line-injection` 对「用户输入→subprocess」判 high；
  仓内 **0 处** `codeql[...]` 抑制先例（§8 陷阱 14 还记过“白名单不算 sanitizer”）。
- 现方案：`_TERMINAL_SPECS` 常量表 + `_terminal_run(command_id, params)`（`shell=False`、cwd 锁仓库根、
  30s 超时、输出各截 20KB、审计 `terminal.exec`）；参数只允许整数并**先夹紧再进 argv**。
- 白名单 5 条：`git status` / `git log -n N(1–50)` / `git diff --stat` / `python --version` / `pytest 清理脚本用例`。
- 实测（部署后）：`GET /api/terminal/commands` 200 列 5 条；`POST /exec {command_id:"git-status"}` → exit 0、argv `["git","status","--short","--branch"]`。
