# Release Notes — v1.3.1（草稿）

> 发布主题：动态权限体系 + 后端菜单树下发 + 系统日志导出
> 分支：`feat/continue-dev`（commit `ffdc56b7`，tag `v1.3.1`）
> 日期：2026-08-21

## 概述

本次发布落地了完整的权限闭环：路由/菜单配置化 → 后端按角色下发菜单树 → 前端动态渲染与路由守卫 → 操作级权限（按钮控制）→ 系统日志导出（最小落地版）。权限逻辑抽取为通用工具类 `PermissionManager`，为后续扩展（数据库驱动角色、操作级权限接入）预留扩展点。

## 新功能

### 1. 动态菜单与权限路由（前端）
- `router/routes.tsx`：路由配置化（`meta.title/icon/authority/hideInMenu`），`flattenRoutes` / `filterMenus` 工具
- `Sidebar` 递归菜单（多级、选中/悬停高亮）、`BreadCrumb` 按路由元信息生成、`AuthRoute` 路由守卫 + 403 页
- 全程 HashRouter，路径小写英文约定

### 2. 后端菜单树下发（方案 2）
- `GET /api/auth/menus`：按登录用户角色/权限码过滤全量菜单目录后下发
- 三账号：`admin`（环境变量凭据，角色通配）/ `manager` / `user`（内置演示账号，登录扩展支持）
- 权限码契约：菜单级 `system:*:view`、操作级 `system:log:export`（admin 通配）

### 3. PermissionManager 权限工具类
- `agent/permission_tool.py`：`filter_menus` / `has_permission` / `has_any_permission` / `register_role`（角色热注册扩展点）
- 数据（菜单目录/角色注册表）与逻辑分离，数据源可替换为 JSON/数据库

### 4. 操作级权限与系统日志导出（最小落地版）
- `usePermission` hook：按钮级权限判定（admin 通配 / 命中权限码）
- `SystemLog` 页：mock 日志表格 + 导出按钮（仅 `system:log:export` 持有者可见）+ CSV 导出（BOM，Excel 中文不乱码）

## Bug 修复

- 退出登录跳 403：`AuthRoute` 增加未登录优先跳登录页
- 切换账号 Zustand 残留：登录成功后强制刷新用户信息
- `routes.tsx` React "type is invalid" 警告：`usePermission` 循环依赖（routes → SystemLog → usePermission → routes）内联判定断开
- Export 大数据量测试超时：分片用例提高 timeout 阈值（全量共享环境耗时放大）
