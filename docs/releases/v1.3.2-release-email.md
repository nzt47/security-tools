云枢 v1.3.2 已完成开发与验证，核心变更如下。

## 一、新功能

1. **动态菜单与权限路由（前端）**
   - 路由配置化（`routes.tsx`：title/icon/authority/hideInMenu），侧边栏递归菜单、面包屑、路由守卫（403）全部数据驱动

2. **后端菜单树下发**
   - 新增 `GET /api/auth/menus`：按登录用户角色/权限码过滤全量菜单目录后下发；前端只渲染、不判定
   - 三角色账号：admin（通配全量）/ manager（中间权限）/ user（基础权限）

3. **PermissionManager 权限工具类**
   - `agent/permission_tool.py`：菜单过滤 + 操作级权限判定 + 角色热注册（扩展点：可接数据库/JSON 数据源）

4. **操作级权限与系统日志导出**
   - `usePermission` hook 统一按钮级权限判定（`system:log:export`，admin 通配）
   - 系统日志页：mock 表格 + 导出按钮（权限控制显隐）+ CSV 导出（BOM，Excel 中文不乱码）

## 二、稳定性修复（重点）

1. **Export 大数据量测试超时**
   - 根因：5000 行 × 3 分片 + yieldToMain 单次约 3s，全量共享环境耗时放大；vitest 第三参 timeout 形式未生效
   - 修复：改用 `{ timeout: 20000 }` options 形式

2. **Export 取消导出时序竞态**
   - 根因：测试"同一同步块点击取消"假设在全量负载下不成立，取消标志可能被 `handleExport` 开头重置，导致导出完成
   - 修复：等待「取消」按钮出现（`exporting=true`）后再点击，消除竞态

3. **其他**：退出登录误跳 403（已修复）、切换账号 Zustand 残留（登录强制刷新）、`routes.tsx` React 类型警告（循环依赖修复）

## 三、Wiki 自动化

- 新增 `scripts/sync_docs_wiki.ps1`：docs/wiki → GitHub Wiki 全量同步（幂等，自动 clone/commit/push）
- 新增 `scripts/schedule_wiki_sync.ps1`：注册每日 01:00 定时同步任务
- 已同步 23 个 Wiki 页面（含 OpenAPI 文档），访问：https://github.com/nzt47/security-tools/wiki
- 接口契约：`docs/api/system-log.openapi.yaml`（OpenAPI 3.0.3）+ Wiki 页面
