## 二、6 个方法契约（参数 / 返回值 / 测试断言）

### 1. `list_pending_approvals() -> List[Dict[str, Any]]`

- **参数**：无
- **实现**：从 `self._approval` 取 `state == "pending_review"` 的记录，转 dict 列表
- **返回**：`[{"record_id": str, "object_type": str, "object_id": str, "level": str, "state": str, "created_at": str}, ...]`
- **测试断言**：`[p["record_id"] for p in pending] == [rec.record_id]`；审批通过后 `list_pending_approvals() == []`
- **前置依赖**：`ApprovalFlow` 无现成 pending 列表方法 → **需给 ApprovalFlow 新增公开方法 `list_pending() -> List[ApprovalRecord]`**（过滤 `state == "pending_review"`，持锁 + `_ensure_loaded`）

### 2. `approve_change(record_id: str, actor: str = "reviewer", note: str = "") -> Dict[str, Any]`

- **实现**：`rec = self._approval.approve(record_id, actor=actor, note=note)`（approval.py L366 签名即 `approve(record_id, actor, note)`）
- **返回**：`{"record_id": rec.record_id, "state": rec.state, "level": rec.level}`（`rec.state == "approved"`）
- **测试断言**：`out["state"] == "approved"`
- **边界**：`ApprovalFlow` 已持锁 + 非法迁移抛 `ApprovalStateError`（透传即可）

### 3. `reject_change(record_id: str, actor: str = "reviewer", reason: str = "") -> Dict[str, Any]`

- **实现**：`rec = self._approval.reject(record_id, actor=actor, reason=reason)`（approval.py L376 签名；reason 为空抛 `ApprovalError`——审计要求）
- **返回**：`{"record_id": rec.record_id, "state": rec.state, "decision_reason": rec.decision_reason}`（`rec.state == "rejected"`）
- **测试断言**：`out2["state"] == "rejected"`；`out2["decision_reason"] == "风险"`
- **注**：`_transition` 以 reason 写 `rec.decision_reason`（approval.py L523-532 区域确认）

### 4. `get_evolution_audit(days: int = 7) -> Dict[str, Any]`

- **实现**：透传 `agent.health.dashboard.get_evolution_audit(days=days, archive=self._lineage_archive, approvals=self._approval)`（G1 已实现）
- **返回**：G1 视图（含 `recent_events`/`decision_stats`/`object_score_trend`/`cost_summary`/`approval_stats`）
- **测试断言**：`view["decision_stats"]["committed"] == 1`；`view["approval_stats"]["total"] == 1`
- **边界**：`_approval` 未注入时传 `None`（G1 不输出 `approval_stats`，兼容）

### 5. `auto_rollback`（property，懒加载单例）

- **参数**：无（只读属性）
- **实现**：首次访问构造 `AutoRollback(archive=self._lineage_archive)`（rollback.py L183 签名；默认 `restorer=None` = 仅记录不实际恢复），缓存至 `self._auto_rollback`
- **返回**：`AutoRollback` 实例
- **测试断言**：`svc.auto_rollback is not None`

### 6. `run_auto_rollback(object_id: str, version: str, metrics: Optional[Dict[str, Any]] = None) -> Dict[str, Any]`

- **实现**：`result = self.auto_rollback.check_and_rollback(object_id, version, metrics)`（rollback.py L213 签名；返回 `RollbackResult`）
- **返回**：`{"triggered": result.triggered, "reason": result.reason, "suppressed": result.suppressed, "halted": result.halted, "details": result.details}`
- **测试断言**：`out["triggered"] is False`；`"无上一 committed" in out["reason"]`（`check_and_rollback` 无基线时 reason 文案为"谱系中无上一 committed 版本"，已固化于 rollback.py 判定逻辑）
- **边界**：无基线/无谱系记录 → `triggered=False` 安全返回，不抛异常
