# 权限与菜单变更更新日志（2026-08-21）

> 范围：管理后台角色权限（app_server.py + yunshu-ui）
> 关联文档：[角色权限与菜单下发配置说明](./角色权限与菜单下发配置说明.md)

## 本次变更

### 1. manager 角色增加「消息中心」查看权限

- **改动**：[app_server.py](../../app_server.py) `_MOCK_MANAGER_ACCOUNT.permissions` 新增 `system:notification:view`
- **效果**：manager 登录后 `/api/auth/menus` 下发「消息中心」（`/system/notification`）；此前该子项对其隐藏
- **过滤逻辑**：无改动（`_filter_menus_for_user` 按权限码命中自动下发）
- **测试**：`tests/unit/test_auth_menus.py` 与 `tests/unit/test_auth_menus_login.py` 的 manager 用例断言同步（「消息中心」由 `not in` 改为 `in`）
- **文档**：权限对比表 manager 列更新

### 2. admin 角色增加「系统日志」导出权限码

- **改动**：`_ADMIN_USER.permissions` 新增 `system:log:export`（操作级权限码，非菜单权限码）；前端 `mocks/devMock.ts` 的 `MOCK_ADMIN` 同步
- **效果**：admin 登录返回的 `permissions` 显式携带导出权限，供系统日志页的导出功能（按钮级控制）使用；admin 菜单本就通配全量，菜单下发结果不变
- **测试**：`test_auth_menus_login.py::test_admin_login_returns_full_menu` 增加 `system:log:export in permissions` 断言
- **注意**：`system:log:export` 是操作级权限码，前端使用方式为 `userInfo.permissions.includes('system:log:export')` 控制操作按钮，与菜单权限码（控制菜单显隐/路由守卫）语义不同

### 3. user 角色增加「消息中心」查看权限

- **改动**：`_MOCK_USER_ACCOUNT.permissions` 新增 `system:notification:view`；前端 `mocks/devMock.ts` 的 `MOCK_USER` 同步
- **效果**：user 登录后 `/api/auth/menus` 下发「消息中心」（`/system/notification`）；此前该子项对其隐藏
- **过滤逻辑**：无改动（权限码命中自动下发）
- **测试**：两个测试文件的 user 用例断言同步（「消息中心」由 `not in` 改为 `in`）

### 4. 权限逻辑封装为 PermissionManager 工具类

- **改动**：新增 `agent/permission_tool.py`（`PermissionManager`：`filter_menus` / `has_permission` / `has_any_permission` / `register_role` / `get_role`）；app_server.py 删除 `_filter_menus_for_user`，改为 `_permission_manager = PermissionManager(_MENU_CATALOG, roles={...})` 实例化调用
- **效果**：菜单过滤与操作级权限判定统一入口；角色支持热注册（数据源可扩展为 JSON/数据库）；接口行为不变
- **测试**：新增 `tests/unit/test_permission_tool.py`（11 个纯函数单测，执行 <2s）；集成测试 15 个保持通过

## 影响范围

| 项 | 影响 |
|---|---|
| 后端接口 | `/api/auth/menus`（manager 菜单多「消息中心」子项）；`/api/auth/login` 返回的 user.permissions（admin 多导出码） |
| 前端 | 菜单渲染为后端下发结果，无代码改动；devMock 的 `MOCK_ADMIN` 同步（仅 `VITE_MOCK_API=true` 时生效） |
| 数据库/存储 | 无（账号权限为代码内置） |
| 生效方式 | 需重启后端进程（`app_server.py`）；devMock 模式 HMR 自动生效 |
| 既有功能 | 无破坏：user/admin 菜单行为不变，测试断言全部更新 |
