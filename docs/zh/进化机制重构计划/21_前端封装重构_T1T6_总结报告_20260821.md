## 三、关键优化点

### T1 工具与存储
- **storage 封装**：键名注册表 + Raw/JSON 双通道（token 等裸字符串契约键不被 JSON 序列化破坏）；读写 try/catch 防隐私模式/配额异常；损坏 JSON 回退不抛异常。
- **async 工具**：debounce/throttle 带 cancel；`fetcherRef` 设计（内联 lambda 不引发无限重拉）；abortable 统一 AbortError 语义。

### T2 组件体系
- **ModalBase**：统一弹窗外壳（portal/遮罩/Esc/滚动锁定/焦点还原），6 处重复外壳收敛为 1 处。
- **Table<T>**：泛型表格壳（loading/空态/对齐/列宽），消除 4 处重复表格实现。
- **Token 治理**：overlay/success 语义色入 Token；Toaster 硬编码色值（green-300/#16a34a）全部消除。

### T3 页面抽象
- **useTablePage**：分页/搜索/加载/竞态防护一体化（请求序号丢弃过期响应），页面从"骨架 + 业务"变为"纯业务列定义"。
- 5 页面重构后合计 **-16% 行数**，重复骨架代码 100% 收敛（列定义与操作渲染为必要业务代码，见任务报告说明）。
- 5 个弹窗（UserFormDialog 等）改走 ModalBase，硬编码色值全部 Token 化。

### T4 PromptLab 拆分
- 722 行单文件 → 8 个职责单一文件（最大 246 行），PreviewPanel 作为右侧面板容器（LLM 配置经 store 内部获取，props 收敛）。
- 工作台复用检查：DetachButton 已参数化、Markdown 单用、流式逻辑单一——**零过度抽象**。

### T5 网络层
- **SSE 错误口径统一**：onError 可选回调 + 三类终止语义文档化（done/AbortError/异常），契约向后兼容。
- **requestWithRetry**：默认关闭（env 开关）、仅幂等 GET、4xx 永不重试（401 交拦截器）。
- **api 契约文档**：6 模块 URL/状态 + Mock 切换检查单，后端就绪可无缝切换。

### T6 清理收口
- 死文件两步删除（git mv 留痕 → 确认 → git rm），活跃路由模板 7 个全部保留。
- sidebar.js 的 showToast 等核实为转发壳（非重复实现）保留——避免误删。
- frontend-rules.md 新增量化抽象标准（≥2 次）与反模式清单，固化本轮经验。
