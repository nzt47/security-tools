# 任务 T2：基础组件体系补齐

> 所属计划：[14_前端封装理想设计_审计与重构总览.md](14_前端封装理想设计_审计与重构总览.md)

---

## 一、目标描述

补齐云枢缺失的基础 UI 组件（Table / Pagination / ModalBase / PageContainer / Empty / Loading / Select / FormField），收敛 6 处重复弹窗外壳，修复 Toaster 硬编码色值违规范问题，为 T3 系统管理页统一抽象提供组件基座。

**【不易】边界**：不修改既有组件导出签名（`Button` / `Input` / `Card` / `ThemeToggle` 及 `components/ui/index.ts` 出口）；新增组件统一进 `components/ui/` 并经 `index.ts` 导出；全部样式走语义 Token，禁止硬编码（`frontend-rules.md` 第 1、6 条）。

## 二、前置依赖

T1（弱依赖：组件实现引用 `cn()` 与 T1 工具约定；如 T1 未完成，可用既有 `cn()` 先行，但需在任务报告中注明）。

## 三、执行步骤

1. **ModalBase（弹窗基座）**：抽取 6 处重复外壳（UserFormDialog:44-68、RoleFormDialog:35-54、MenuFormDialog:61-88、DataScopeDialog:39-52、PermissionAssignDialog:56-65、ConfirmDialog:43-57 共有的 `createPortal` + `fixed inset-0 z-50` + 遮罩 + Esc 关闭 + 标题 + footer）为 `components/ui/ModalBase.tsx`：
   - Props：`open / onClose / title / footer?: ReactNode / width? / children`；
   - 行为：Esc 关闭、遮罩点击关闭（可配置）、body 滚动锁定、焦点管理（关闭后焦点还原）、portal 渲染；
   - 语义 Token：遮罩 `bg-black/50`、容器 `bg-card border-border rounded-lg shadow-card`。
2. **Table（通用表格壳）**：抽取 4 处重复表格壳（UserList:170-247、RoleList:210-297、AuditList:140-197、MenuList:130-159 共有的 `overflow-hidden rounded-lg border` 容器 + thead 数组 map + loading/空态 `td colSpan`）：
   - Props：`columns: TableColumn<T>[]`（key/header/render/align/width）、`dataSource: T[]`、`loading?`、`emptyText?`、`rowKey`；
   - 内置 loading（Loader2 居中）与空态（Empty 组件）；
   - 泛型组件 `Table<T>`，严格类型。
3. **Pagination（分页）**：抽取 4 处重复分页 UI（UserList:250-288、RoleList:300-338、AuditList:200-226、NotificationCenter:235-261 共有的"共 N 条 + 上一页/下一页 + page/totalPages"）：
   - Props：`page / pageSize / total / onChange(page)`；含"共 N 条"文案与禁用态；
   - 样式：语义 Token，按钮复用 `Button variant="default" size="sm"`。
4. **PageContainer（页面容器）**：统一"标题 + 说明 + 操作区 + 内容"骨架（页面头部），Props：`title / description? / actions?: ReactNode / children`。
5. **Empty / Loading**：`Empty`（空态图 + 文案，语义 Token）、`Loading`（居中 spinner，替代各页 `Loader2` 裸用）。
6. **Select / FormField**：
   - `FormField`（label + error 体系，与 `Input` 的 label/error 能力对齐，供 T3 表单体系复用）；
   - `Select`（受控下拉：options/ value / onChange / placeholder，原生 select 实现 + Token 样式，禁引重型库）。
7. **修复 Toaster 硬编码色值**（`src/components/Toaster.tsx:51-54`）：`green-300/red-50/#16a34a` 等改为语义 Token（如新增 `success` / `warning` Token 到 index.css `:root`/`.dark`，Toaster 用 `bg-success text-success-foreground border-success/30`）；改后视觉回归确认 success/error/info 三态正常。
8. **组件索引与示例**：新增 `src/components/README.md`（组件清单 + Props 摘要 + 示例）；`Demo` 页（`src/pages/Demo/index.tsx`）补充新组件演示区块。
9. **单元测试**（vitest + @testing-library/react，`src/components/ui/*.test.tsx`）：
   - ModalBase：open/onClose 渲染、Esc 关闭、遮罩关闭、不打开时不渲染；
   - Table：columns 渲染、loading/空态、rowKey 唯一；
   - Pagination：页码计算、上一页/下一页禁用边界；
   - Select/FormField：受控交互、error 文案展示；
   - 既有组件（Button/Input/Card）回归不受影响。
