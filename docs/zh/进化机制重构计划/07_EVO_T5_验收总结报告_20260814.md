## 四、验证过程要点

1. **多维度边界防护**（edit_policy）：路径白名单（默认仅 `data/skills_repo`，白名单禁止指向 core 目录）+ 穿越攻击防护（`../`/反斜杠/大小写变体均拒绝）+ 扩展名黑名单（与 file_tools 对齐）+ 内容黑名单正则（`META_EDIT_BLOCKED_PATTERNS` 可追加）。
2. **三重审核链**（meta_editor）：输出守卫（critical 直接丢弃）→ Reviewer 审核（critical finding → rejected，不进入评估）→ 进程级沙盒评估（不达标 → rejected）。
3. **审批时序约束**：submit 前置条件为"已审核 + 已评估"；低分提案无法绕过；submit 后状态恒为 pending_review——人工审批（T6 approval.py）是唯一合并通道。
4. **停滞暂停**：`test_stalled_skill_paused`（连续 K 轮无提升暂停该技能，`META_EDIT_STALL_ROUNDS`=3）——防无效循环消耗。
