## 一、目标描述

替换 `offline_evolver._heuristic_predict()`（参数偏离幅度猜测成功率）的**假反馈骨架**，落地真实执行评估 + 分阶段评估 + 可验证性护栏：

- **`SkillExecutorEvaluator`**：在 `data/evals/` 样本池上真实执行技能，per-sample 判定（exact/contains/json/validator），统计 success_rate/latency/维度分；
- **`StagedEvaluator`**：分阶段评估（阶段 1 初筛 → 阶段 2 全量），阶段 1 低于阈值即淘汰（节省 token）；`TokenBudget` 预算熔断；
- **开放域替代验证**：无法执行的真实输出用自一致性（≥0.7 判成功）+ 反馈信号叠加；
- **无样本防伪**：类别无样本 → `no_samples`，绝不伪造指标；
- **LLM 降级**：LLM 不可用 → 全部 skipped + `degraded`。

**【不易】边界**：不修改既有提交判定逻辑（`improvement >= threshold` 保留，那是 T3 范围）；不改变 `_evaluate` 维度公式（0.5×success_rate + 0.3×latency_norm + 0.2×satisfaction）。

## 二、前置依赖

EVO-T1（谱系库，评估结果写入 eval_result）。

## 三、执行步骤

1. 定义评估器协议（`Evaluator` 接口：`evaluate(skill) -> EvaluationResult`，含 score/dimensions/sample_count/evaluator_version/status）。
2. 构建 `data/evals/` 真实样本池（search/code/chat 等类别，格式：任务描述 + 期望输出 + 判定方式）。
3. 实现 `SkillExecutorEvaluator`（沙盒真实执行 + per-sample 判定 + 统计）。
4. 实现 `StagedEvaluator`（分阶段 + TokenBudget 熔断 + 初筛阈值 `EVAL_STAGE1_MIN_SCORE`）。
5. 实现开放域替代验证（`SelfConsistencyScorer` + `FeedbackSignalScorer`）。
6. 实现评估器注册表（`EvaluatorRegistry`：search/code/chat 已注册，未注册类别走分阶段 LLM）。
7. 接入谱系：`EvaluationResult.to_eval_result_dict()` 与 `EvolutionRecord.eval_result` 对齐（score/dimensions/sample_count/evaluator_version/status）。
8. 单元测试（覆盖率 ≥ 80%）+ `run_evolution_demo.py` 回归（real 模式可运行）。

## 四、预期成果（交付物）

- 新增 `agent/skills_mgmt/evaluator.py`（含 `EvaluationResult`、`SkillExecutorEvaluator`、`StagedEvaluator`、`TokenBudget`、开放域验证、注册表）。
- `data/evals/` 真实样本池（≥3 类别）。
- `offline_evolver.evolve_once(..., evaluator=None)` 评估器注入点（不传保持启发式，向后兼容）。
- 单元测试 + 覆盖率 ≥ 80%。

## 五、评估标准（验收条件）

1. 真实执行评估生效，且与启发式结果可区分（有测试证明）；
2. 无样本类别返回 `no_samples`，绝不伪造指标（测试证明）；
3. 分阶段评估生效 + 预算熔断可触发（测试证明）；
4. 评估结果写入谱系 `eval_result`（score/status/sample_count/dimensions 对齐，有测试证明）；
5. 开放域替代验证（自一致性 + 反馈信号）有单元测试；
6. `run_evolution_demo.py` 可运行不崩溃（real 模式）；
7. 未修改既有提交判定逻辑（`improvement >= threshold` 保留）。
