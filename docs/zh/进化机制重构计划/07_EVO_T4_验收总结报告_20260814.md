## 四、验证过程要点

1. **阈值判定三层防护**：相对提升（`(cand-orig)/max(orig,ε)`）> 3% → proposed；原版无基线时用绝对分 ≥ 0.5（`PROMPT_OPT_ABS_MIN_SCORE`）；变体数量钳制 2-3 个。
2. **不自动应用闭环**：`PromptOptimizationProposal` 无 apply 方法（代码级证明）+ 谱系 decision 恒为 pending_review（数据级证明）——双保险。
3. **失败桶**：连续失败 N 次仅告警一次，成功重置——防"每次优化失败都打一条告警"的噪声风暴（Redis 降基数）。
4. **LessonEvalChannel**：Lesson 命中可验证类别 → 转评估器验证 → 进入建议管道（`test_verifiable_lesson_produces_proposal` / `test_unverifiable_lesson_returns_none`）。
