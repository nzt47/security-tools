## 一、背景（为什么做）

TASK-08 护栏 G5 要求"进化产物先过离线评估集回归（标准集不退化）→ 再进入在线保守观察期"，
但审计发现三个断点：

1. **评估集概念错位**：报告的"1.2 万+ 回归测试"是代码库单元/集成测试（`tests/`），
   不是技能/策略工件的行为评估样本，无法用于判定"Skill 参数变异后行为是否退化"。
2. **真实评估集过小**：`data/evals/` 仅 15 条样本（search/code/chat 各 5），
   `StagedEvaluator` 对无样本类别返回 `no_samples → score=0.0`，G5 门禁形同虚设。
3. **无扩充管道**：反思产物（TASK-02）、失败案例（feedback quality_cases）、
   新颖事件（TASK-06 NoveltyEvent）本可回流为评估样本，但无任何管道。

本任务把"技能评估集"建设为**一等资产**：schema 与目录规范、扩充管道、
可执行回归门禁 CLI、以及 `offline_evolver` 提交判定 / TASK-04 发布审核链接线。

## 二、交付内容

### 1. 评估集 v1（data/evals/，50 条样本，5 类覆盖）

| 类别 | 样本数 | 说明 |
| --- | --- | --- |
| search | 12 | 检索/问答/知识查询（exact/contains/json 校验） |
| code | 12 | 代码生成/算法实现（validator 表达式校验） |
| chat | 12 | 开放域对话（自一致性 + 反馈信号） |
| tool | 7 | 工具调用（计算器/时间/搜索/文件等） |
| planning | 7 | 规划/拆解/学习计划 |
| **合计** | **50** | 每类 ≥5，全部通过 schema 校验 |

- `manifest.json`：样本集版本登记（v1 → 类别 → 样本 id 清单），门禁按 (版本, 类别) 解析。
- schema v1：`metadata.input` / `difficulty`（TRIVIAL/SIMPLE/NORMAL/COMPLEX，
  复用 `enhanced_planner` 复杂度语义，为任务7 提供元数据）/ `source`
  （manual/reflection/feedback/novelty）/ `input_hash`（`sha256({category,task,input})[:16]` 去重）。
- `_pending/`：扩充管道 DRAFT 草稿目录（审核前绝不入评估集）。

### 2. 校验脚本 `scripts/eval_samples_validate.py`

- 逐条校验字段合法性（id 唯一 / category 与目录一致 / task 非空 /
  expected_output 四类校验器结构 / difficulty / source / input_hash 匹配）。
- `input_hash` 全池去重（跨类别），manifest 一致性（漏登记 / 幽灵 id / current 缺失）。
- 退出码：0=PASS（0 非法），1=FAIL。当前评估集 **PASS（0 非法）**。

### 3. 扩充管道 `agent/skills_mgmt/eval_sample_ingest.py`

- 素材提取：`extract_from_reflection`（低分反思）`extract_from_feedback`（quality_cases）
  `extract_from_novelty`（NoveltyEvent），含类别/难度规则推断。
- 流程：素材 → 候选 → 脱敏 → `data/evals/_pending/`（DRAFT）→ `review_pending`
  （复用 `reviewer.SecurityScanner`）→ `approve_draft`（审核通过才入正式类别 JSON）。
- **不变式（不易）**：
  - 默认关闭（`EVAL_SAMPLE_INGEST_ENABLED=false`）→ `run_ingest` 零副作用；
  - 显式开启也只产生 DRAFT，绝不直接写正式类别；
  - 真实轨迹素材（reflection/feedback/novelty）入库前强制脱敏
    （复用 `agent.security_utils.DataSanitizer`，与 `memory/black_box.py` 同源管道）。

### 4. 回归门禁 `agent/skills_mgmt/eval_regression.py`

- `evaluate_regression(skill, sampleset_version, budget) -> RegressionResult`，
  status ∈ {PASS, FAIL, NO_SAMPLES, budget_exceeded}（**绝不伪造指标**）。
- 复用 `EvaluatorRegistry / StagedEvaluator / TokenBudget / EvalSamplePool`
  （不修改 `evaluator.py`，编排层在其上）。
- 基线语义：首次评估记录基线（`data/evals/baselines.json`，按 skill_id + 版本）；
  后续 `delta = score - baseline`，`delta < -阈值（默认 0.05）→ FAIL`；
  **基线只升不降**（防"温水煮青蛙"式逐步下滑）。
- CLI：`python -m agent.skills_mgmt.eval_regression --skill <id> --set v1 --budget 500k`
  （退出码：0=PASS / 1=FAIL / 2=NO_SAMPLES|budget_exceeded / 3=技能不存在 / 4=其他）。
- `query_regression_status`：TASK-04 发布审核链只读查询（不评估、不写盘）。

### 5. 接线

- `offline_evolver.py`（提交判定处新增护栏 3，**纯增量，不触碰进化算法与报告结构**）：
  - `EVOLUTION_REGRESSION_GATE`：`off`（零调用）/ `warn_only`（默认，只读告警不拦截）/
    `enforce`（FAIL/NO_SAMPLES/budget_exceeded → 谱系 `decision=rejected` 并跳过提交）。
  - 首次（enforce）先以当前技能（params=None）建立基线，再评估变异体
    （防坏候选抬高基线）。
  - 门禁异常绝不阻断提交（`_check_regression_gate` 任何异常 → 告警 + 返回 None）。
- `review_gate.py`（TASK-04 发布审核链前置查询，只读不拦截）：
  `enforce_review` 通过审核后查询回归基线状态并记日志，无基线/异常静默跳过。

### 6. 配置开关（优先级：环境变量 > config.yaml > 硬编码默认值）

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `EVAL_SAMPLE_INGEST_ENABLED` | `false` | 扩充管道总开关（安全底线，零副作用） |
| `EVAL_SAMPLE_PENDING_DIR` | `./data/evals/_pending` | DRAFT 草稿目录 |
| `EVAL_SAMPLESET_MANIFEST` | `./data/evals/manifest.json` | 样本集版本登记 |
| `EVAL_REGRESSION_BASELINE_FILE` | `./data/evals/baselines.json` | 回归基线存储 |
| `EVAL_REGRESSION_DEFAULT_SET` | `v1` | 门禁默认样本集版本 |
| `EVAL_REGRESSION_DEGRADE_THRESHOLD` | `0.05` | 退化阈值（delta < -0.05 → FAIL） |
| `EVAL_REGRESSION_BUDGET_TOKENS` | `100000` | 门禁评估预算（TokenBudget 熔断） |
| `EVOLUTION_REGRESSION_GATE` | `warn_only` | 进化提交门禁模式（off/warn_only/enforce） |

config.yaml 对应节点：`skills_mgmt.eval_samples.*` / `skills_mgmt.evolution_regression_gate`。

## 五、使用示例

```bash
# 1. 校验评估集
python scripts/eval_samples_validate.py                 # PASS（0 非法）

# 2. 回归门禁 CLI（首次评估自动记录基线）
python -m agent.skills_mgmt.eval_regression --skill <skill_id> --set v1 --budget 500k

# 3. 扩充管道（默认关闭；开启后只产 DRAFT，审核通过才入库）
#    .env: EVAL_SAMPLE_INGEST_ENABLED=true
python -c "from agent.skills_mgmt.eval_sample_ingest import run_ingest; \
           print(run_ingest(reflection=[{'task':'示例任务','score':0.2}]))"

# 4. 进化提交门禁（enforce 拦截退化）
#    .env: EVOLUTION_REGRESSION_GATE=enforce
```
