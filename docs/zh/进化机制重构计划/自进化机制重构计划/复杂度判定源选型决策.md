# 复杂度判定源选型决策（S4 灰度落地）

> 日期：2026-08-23 | 关联：任务7 对比报告、《自进化启用路线图》S4、`data/complexity_labeled.jsonl`
> 决策：**默认判定源由 wire 切换为 wire_v2**（config.yaml `learning.complexity.source: wire_v2`）

---

## 一、决策背景

任务7 对比报告显示 wire 与 enhanced_planner 判定一致率仅 29.50%、对人工标注符合率均低（当时 20%/32%），判定质量是课程阶梯的数据瓶颈。复查补充了 `WireV2Classifier`（增强特征：扩充词表/文本长度/数字实体/步骤词/量词，全部可配置）与人工标注资产，本次完成 **200 条样本标注**（150 条 curated + 50 条评估集），对三源做同口径符合率对比后定案。

## 二、标注资产与口径

- 样本：`data/complexity_labeled.jsonl`（200 条，`label_status=labeled`，`labeled_by=manual`，逐条含 `label_reason`）。
- 分布：TRIVIAL 51 / SIMPLE 51 / NORMAL 31 / COMPLEX 67（curated 150 + eval_set 50）。
- 标准：TRIVIAL=单步查询/问答/计算；SIMPLE=单次生成/工具任务；NORMAL=分析/中等设计/局部重构；COMPLEX=系统级/架构/平台/显式多步骤/完整方案。
- 可复现：`scripts/apply_complexity_labels.py`（标注字典 + 一键重建）、`scripts/complexity_v2_compare.py --labeled`（符合率计算）。

## 三、符合率结果（200 条，同口径）

| 判定源 | 正确/总数 | 符合率 | 与 wire 差距 |
|---|---|---|---|
| wire（原默认） | 110/200 | **55.00%** | 基线 |
| **wire_v2（新默认）** | 125/200 | **62.50%** | **+7.5pp** |
| enhanced_planner | 未纳入本批（依赖较重、任务7 已示 32% 级） | — | 保留灰度候选 |

**wire 主要系统性误判**（混淆矩阵）：
- SIMPLE 判成 TRIVIAL：37 条（单次任务被低估）；
- COMPLEX 判成 NORMAL：23 条（系统级任务被低估）。

**wire_v2 修正**：上述两类误判显著收敛（v2 的 TRIVIAL/SIMPLE/COMPLEX 边界与标注更接近）。

## 四、选型结论与理由

**结论：默认判定源切换为 wire_v2。**

1. 同口径符合率 **+7.5pp**（62.5% > 55.0%），显著修正系统性误判；
2. **零风险切换**：当前 `planning.wire_enabled=false`（规划接线关闭），判定切换仅影响复杂度元数据与 KPI#4 复杂度维度（观测数据更准），**不改变任何路由/执行决策**；
3. 全部特征与阈值可配置（`COMPLEXITY_V2_*` / config `v2` 段），非法值回退默认；
4. 一键回退：`COMPLEXITY_SOURCE=wire` 环境变量即时恢复原行为（优先级高于 config）。

**局限性（如实披露）**：62.5% 仍未达 70% 理想门槛——关键词启发式对"复杂度"这种语义判定存在天花板。后续若需更高精度，候选路径：① LLM 分级通道（受 `learning.budget` 熔断保护，默认关闭）；② 标注集扩充至 500+ 后再校准权重。

## 五、切换影响面

| 影响面 | 说明 |
|---|---|
| orchestrator wire 判定 | 委托统一接口 → 判定变 v2；`wire_enabled=false` 时仅日志/元数据 |
| KPI#4 复杂度维度 | `judged_complexity` 使用 v2 判定（标注验证更准） |
| 课程自适应（任务7） | `curriculum.enabled=false` 未启用，无行为影响 |
| 评估集难度字段 | 任务1 评估集难度元数据可与 v2 判定对齐（后续校准） |
| 测试 | `test_complexity_classifier.py` / `test_complexity_v2.py` 断言已同步更新 |

## 六、回滚预案

- `COMPLEXITY_SOURCE=wire`（env）→ 立即恢复原 wire 判定（逐字节等价）。
- 灰度观察：切换后 2 周检查 KPI#4 复杂度维度数据分布与 orchestrator 日志无异常；异常即回退。
