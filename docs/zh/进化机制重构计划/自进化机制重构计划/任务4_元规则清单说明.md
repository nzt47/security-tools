# 任务4：元规则清单说明（护栏 G1 登记表）

> 计划：`docs/zh/进化机制重构计划/自进化机制重构计划/进化机制理想设计.md` 任务4
> 登记表：`data/learning/meta_policy/schema.json`（52 项，schema_version 1）
> 用途：决策层与运维可查询"哪些进化参数受版本管控、默认值与合法范围是什么、
>       生效读取点在哪里、属于哪条护栏"。

## 一、范围（G1 要求全覆盖）

TASK-08 护栏 G1 要求版本化管控的类别，本清单逐项登记：

- **变异策略**：变异策略权重（fine_tune/combine/mutate/reset）、父代选择策略与子代惩罚参数；
- **评估阈值**：StagedEvaluator 阶段比例/初筛分/样本数/预算、元编辑评估阈值、回归退化阈值；
- **进化权重**：提交门槛（improvement≥0.05）、候选筛选阈值（min_usage/target_success_rate/max_variants）；
- **触发条件**：KPI#7 最小候选基数、"连续 4 周"判定窗口、回放覆盖率阈值、回归门禁模式、
  LLM 候选生成开关、行为漂移阈值。

另登记同属"进化规则"的**预算 / 调度 / 回滚 / 护栏开关**参数（G4/G5/G2/G3 联动）。

## 二、登记表字段语义（schema.json entries[]）

| 字段 | 语义 |
| --- | --- |
| `name` | 参数唯一名（点分路径，如 `schedule.evolver_interval_days`） |
| `group` | mutation / evolution / eval / budget / schedule / trigger / rollback / guard |
| `category` | 变异策略 / 评估阈值 / 进化权重 / 触发条件 / 预算 / 调度 / 回滚 / 护栏开关 |
| `type` | int / float / bool / str / enum |
| `default` | 代码/配置默认值（非法值回退目标） |
| `min` / `max` | 合法范围（缺失=不设限） |
| `enum` | 枚举合法值（type=enum 时） |
| `unit` | 单位（token/天/周/% 等） |
| `env` | 环境变量键（`.env`，最高优先级；无则 null） |
| `config_path` | config.yaml 路径（如 `learning.evolver.interval_days`；无则 null） |
| `read_point` | 生效读取点（`文件::函数`），代码审计锚点 |
| `source` | 当前主来源层（env / config / code） |
| `guard` | 所属护栏（G1/G2/G3/G4/G5） |

## 三、读取优先级（不变式）

```
环境变量（entry.env） > config.yaml（entry.config_path） > 硬编码默认值（entry.default）
```

与项目既有约定一致；元规则层**不改变**任何模块的最终生效值来源
（仅登记 + 快照 + 门控 + 查询；`migrate` 默认 dry-run 不迁移）。

## 五、变更管理（G1 落地语义）

1. **bump**：`python -m agent.learning.meta_policy bump --param <name>=<value> ...`
   → schema 校验（非法值回退默认）→ 版本快照（`versions/vN.json`，只追加）→
   审批队列（`approval.py`，L1）→ 批准生效 / 拒绝保持。
2. **rollback**：`python -m agent.learning.meta_policy rollback` → 恢复上一版本快照
   （本身受控 + 审计）。
3. **零版本修改零容忍**：登记表内参数的任何运行时修改必须先 bump 留痕；
   读取点审计（`read_point` 字段）保证"所有读取点都经过版本化层或回退默认"可证。
