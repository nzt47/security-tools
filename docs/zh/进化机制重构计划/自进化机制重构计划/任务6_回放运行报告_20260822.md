## 3. fail-closed 验证（Step 6）

| 场景 | 结果 |
|---|---|
| 回放默认关闭（`EVAL_REPLAY_ENABLED` 未设） | `ReplayDisabledError` 显式拒绝，不静默跳过 |
| `spawn` runner 不可用（Queue 建管道失败） | `ReplayIsolationError`，提示改用 `EVAL_REPLAY_RUNNER=subprocess` |
| docker 后端无 docker 可执行文件 | `ReplayIsolationError` |
| 后端/执行器异常 | `ReplayIsolationError`，**绝不回退同进程执行** |
| worker 未产出结果（隔离失败） | verdict=escape（fail-closed 语义） |

  两个新增文件——本任务与既有代码零耦合，不可能引入既有用例回归。

## 5. 结论

1. 沙箱回放具备**真实安全边界**：危险样本 100% 被拦截/超时，宿主零残留；
2. 回放管道复用任务1 评估集回归通道（manifest + 样本池只读），样本走
   black_box 脱敏管道，明文不出隔离环境；
3. 单样本开销与既有真实评估同量级（~0.1 s / ~17 MB），成本模型可落地；
4. 默认关闭（`EVAL_REPLAY_ENABLED=false`），开启需显式配置 + 审计，零行为变化；
5. 未修改 `SkillExecutor`/`evaluator.py` 既有接口与算法（git diff 审计）。
