## 1. 背景（为什么做）

TASK-08 报告 §4.2 提出云枢化降级：**沙箱回放 = "合成边缘案例"**——在隔离环境离线回放历史轨迹与失败案例（feedback 失败样本、TASK-06 NoveltyEvent），验证更新产物对长尾场景的效果，回放不触碰生产数据。

审计发现两个前提问题：

1. **沙箱为软隔离**（主文档 §4.2）：现有扩展/技能执行沙箱是"同进程执行、黑名单可绕过、资源限制不 enforcement"。回放的是**不可信的历史轨迹与候选产物**（含 LLM 生成的变异参数、工具调用序列），软隔离下执行存在逃逸风险——dry-run 语义只保证"不提交工件"，不保证"执行安全"。
2. **无回放基础设施**：没有"轨迹记录 → 隔离回放 → 结果比对"的现成管道（EVO-T2 的 `SkillExecutor` 是子进程执行评估样本，但不是轨迹回放）。

本任务建立**评估回放隔离层**：进程级隔离（multiprocessing spawn 或受限容器）、只读数据挂载、网络禁断、超时与资源限制，并提供回放管道（复用任务1 评估集回归通道），使"沙箱回放"具备真实安全边界。

## 2. 目标描述（做什么）

1. **回放隔离层**：新回放执行环境与生产零共享写路径；不可信代码在隔离进程执行，网络禁断、文件系统只读挂载（回放素材只读）、CPU/内存/墙钟限制。
2. **回放管道**：输入（历史轨迹/失败案例/评估集样本 + 候选产物）→ 隔离执行 → 结果比对（成功/失败/超时/逃逸判定）→ 审计；复用任务1 门禁通道，样本走脱敏（`black_box.py`）。
3. **安全用例**：危险样本（文件写入/网络外联/死循环/提权尝试）全部被拦截或超时杀死，不逃逸到宿主。
4. **性能基准**：回放单样本开销纳入评估（报告 §6.1 成本模型更新所需的执行侧数据）。
5. 默认关闭（`EVAL_REPLAY_ENABLED=false`），显式开启仅限任务1 评估集回归与任务3 observe 态回放用途。

## 3. 不变式约束（不易——禁止触碰）

- 禁止修改 `SkillExecutor` 既有接口与 `evaluator.py` 评估算法；隔离层在其**外部**新增执行边界（或对既有 executor 提供隔离模式包装，接口不变）。
- 回放环境与生产零共享写路径（代码审计可证）；回放样本只读，不进入生产检索面。
- 涉及真实交互轨迹的样本入库前走既有脱敏/加密管道（`memory/black_box.py`），回放环境无法读取明文生产数据。
- 隔离层失败/不可用时回放必须显式失败（fail-closed），绝不静默降级为同进程执行。
- 安全底线：任何回放动作默认关闭；开启需显式配置 + 审计。

## 4. 执行步骤

### Step 1：现状审计
- 阅读 `agent/skills_mgmt/executor.py`（SkillExecutor）与 EVO-T2 运行报告 §3（子进程冷启动/自一致性执行路径），确认现有执行边界与可复用点。

### Step 2：隔离执行边界设计
- 方案选型（按【简易】最小充分）：优先 multiprocessing spawn + 受限工作目录 + 环境变量白名单 + 网络禁断（`os`/`socket` 等危险模块白名单或环境级禁断）+ 超时强杀；若运行环境支持，评估容器化（docker run --read-only --network none）作为可选后端。
- 资源限制：墙钟超时（默认 30s）、输出体积上限、子进程数量上限（防 fork 炸弹）。

### Step 3：回放管道实现
- 新增 `agent/learning/replay.py`：`ReplayJob`（样本集 + 候选产物 + 预算）→ 隔离执行 → `ReplayResult`（success/failed/timeout/escape + 结果快照 + 审计）。
- 复用任务1 的 `eval_regression` 通道作为回放入口（输入样本与产物、输出比对结论）。
- 审计字段：`replay_id / samples / candidate_id / verdict / duration / resource_usage / evidence(截断) / rollback_command`。

### Step 4：安全用例
- 危险样本集（测试资产）：写文件、网络外联、无限循环、提权尝试、读取环境变量密钥；全部断言被拦截/超时，且宿主零残留（无新文件、无新进程、无网络连接）。

### Step 5：性能基准
- 单样本回放墙钟/内存基准（对照 EVO-T2 报告 §3 数据），写入运行报告，供 POC-A 成本模型更新（报告理论缺陷 T4/T8 的落地数据）。

### Step 6：测试与文档
- 新增单测/集成测试：隔离边界（危险样本不逃逸）、fail-closed（隔离不可用时回放拒绝）、脱敏（明文不出隔离环境）、审计完备。
- 产出变更说明 + 回放运行报告。
