## 一、目标描述

将 T1-T5 的进化能力**收口为安全、可审计、可回滚的受控系统**：

1. **审批流（人机协同）**：所有影响生产行为的进化变更（技能参数提交、提示词建议应用、元智能体代码编辑）必须经审批放行——`approval.py` 按风险分级：
   - **L0 无需审批**：无行为影响的记录类操作（谱系写入、评估记录）→ 自动放行；
   - **L1 需审批**：影响生产行为的变更（技能参数提交、提示词建议应用）→ pending_review，人工 approve 后 merge；
   - **L2 需人工执行**：元智能体代码编辑、策略变更等高风险 → 只产出建议，人工执行（approve 后不可自动 merge，双保险）。
2. **安全阀熔断与自动回滚**：`rollback.py` 监控进化效果指标，异常率上升 / 成功率下降 / 延迟上升超阈值时自动回滚到上一 committed 版本（窗口过滤 + 无基线不触发）。
3. **可验证性护栏**：进化产生的任何修改必须可验证（真实评估达标才生效）。

**【不易】边界**：
- **未 merged 的 L1/L2 变更绝不生效**（`is_effective()=False`，applier 不执行）；
- 状态机严格：`draft → pending_review → approved / rejected → merged / archived`，非法迁移抛 `ApprovalStateError`；
- 自动回滚仅限"谱系中已 committed 的上一版本"，无基线不触发。

## 三、核心组件

1. **`agent/skills_mgmt/approval.py`**：
   - `APPROVAL_LEVELS = (L0, L1, L2)` + `APPROVAL_STATES` 状态机；
   - `ApprovalRecord`（level/action/payload/applier/manual_required）+ `ApprovalFlow`（submit/approve/reject/merge/archive/is_effective）；
   - `default_level_map()`：动作以 record/log/eval/lineage 开头 → L0；skill/prompt 生产变更 → L1；subagent_config/meta_agent/strategy/代码编辑 → L2；
   - JSONL 持久化 + 原子写入（服务重启后可恢复，pending/approved 无 applier 时 merge 抛 `ApprovalStateError` → 人工执行）。
2. **`agent/skills_mgmt/rollback.py`**（安全阀）：
   - 劣化触发：success_rate 下降 / latency 上升 / **error_rate 上升**（相对阈值 `ROLLBACK_ERROR_RISE_PCT` 默认 50%）；
   - `ROLLBACK_WINDOW_MIN` 窗口过滤：仅窗口内 committed 记录可作基线，超窗跳过；窗口内无记录 → 视为无基线不触发；
   - 自动回滚 + 当日熔断计数 + 日志/埋点（安全阀熔断带计数、自动回滚 warning 带 delta、劣化判定输入 info）。
3. **人机协同（HITL）**：`agent/skills_mgmt/hitl`（风险分级：low_risk_auto_approve / high_risk / critical_risk / block_dangerous / allow_safe）。

## 五、评估标准（验收条件，对应八项验收）

1. **审批分级正确**：L0 记录类自动放行（applier 自动执行）/ L1 阻塞待审 / L2 只产出建议（`test_l0_auto_approve` / `test_l2_only_suggestion`）；
2. **未审批的 L1/L2 变更绝不生效**：approve 后仍未生效，merged 才生效（`test_full_l1_state_machine_path` / `test_pending_review_cannot_merge`）；
3. **状态机完整**：非法迁移抛 `ApprovalStateError`（merged 后再 approve、rejected 后 merge）（`test_illegal_transition_rejected`）；
4. **安全阀熔断**：异常率上升 / 成功率下降 / 延迟上升均触发自动回滚（`TestAutoRollback::test_triggers_on_*`）；
5. **阈值内不误触发**：error_rate 在阈值内不触发（`test_no_trigger_error_rate_within_threshold` / `test_no_trigger_within_threshold`）；
6. **窗口过滤与无基线**：超窗基线跳过、窗口内无记录不触发（`test_window_filter_skips_stale_baseline` / `test_no_baseline_no_rollback`）；
7. **持久化与重启恢复**：审批记录 JSONL 持久化，新实例可恢复（`test_persistence_roundtrip`）；
8. **覆盖率 ≥ 80% + 既有测试通过**：approval.py 85%（实测）、rollback 有独立测试、全量回归无真实失败。
