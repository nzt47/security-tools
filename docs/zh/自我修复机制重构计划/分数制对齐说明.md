## 一、问题定义

### 1.1 混乱表现

Critic 评估模块存在**两套分数语义并存**的缺陷：

| 位置 | 分数语义 | 数值 | 说明 |
|------|----------|------|------|
| [EvaluationResult.overall_score](file:///C:/Users/Administrator/agent/agent/cognitive/critic.py#L47) | 0-100 分制 | `threshold` 默认 70 | 主评估路径的真实评分制 |
| 旧 `critic_evaluate_with_degrade` | 10 分制 | 硬编码 `7` | 降级路径伪造的"兜底分" |

### 1.2 混乱后果

1. **数值失真**：降级路径返回 `overall_score=7`（10 分制语义），被调用方当作 0-100 分制消费——`7` 既不代表"7 分合格"也不代表"7% 质量"，完全无意义；
2. **误判通过**：旧代码 [critic.py 异常降级路径](file:///C:/Users/Administrator/agent/agent/cognitive/critic.py#L236-L245) 使用 `degrade_result.get("passed", True)`——当降级结果不含 `passed` 键时，`.get()` 返回默认值 **True**，把"评估失败"误判为"评估通过"；
3. **默认分残留**：`.get("overall_score", 75)` 的 75 兜底分与 100 分制混用，语义双重混乱。

### 1.3 根因

降级路径本质是**"无法评估"的兜底**，而不是"低分评估"——它根本不应产出分数。旧实现对"降级"与"低分"两个概念混为一谈，用伪分数掩盖"评估服务不可用"这一事实。

## 二、对齐方案（三层全对齐）

### 第 1 层：降级源 —— 不产出分数

[graceful_degrade.py `critic_evaluate_with_degrade`](file:///C:/Users/Administrator/agent/agent/graceful_degrade.py#L759-L798)：

```python
result = {
    "degraded": True,
    "reason": "Critic 服务不可用，已跳过评估",
    "overall_score": None,   # 无分数：降级 ≠ 低分
}
```

- 删除硬编码 `7`；
- `overall_score` 恒为 `None`；
- 补充 `degraded` 标记与降级原因。

### 第 2 层：消费方 —— 不兜底、不默认

[critic.py 异常降级路径](file:///C:/Users/Administrator/agent/agent/cognitive/critic.py#L236-L245)：

```python
return EvaluationResult(
    overall_score=None,                 # 不再 .get("overall_score", 75)
    dimension_scores={},
    passed=False,                       # 不再 .get("passed", True)
    feedback=[degrade_result.get("reason", "Critic 评估失败，已降级")],
    retry_recommended=False,
    explanation=degrade_result.get("reason", "Critic 评估失败，已降级")
)
```

### 第 3 层：判定 —— 降级不触发重试

- `passed=False` 恒成立：降级 ≠ 通过；
- `retry_recommended=False`：降级不触发重试（重试只用于"分数不足"场景，不用于"服务不可用"场景）。

---

## 三、语义约定（不可变契约）

> **`overall_score=None` 与 `passed=False` 是不可分割的组合。**

任何消费 `EvaluationResult` 的调用方必须遵守：

1. **禁止回退默认分**：遇到 `overall_score is None` 时，不得 `.get(..., 默认分)` 兜底，也不得自行构造替代分数；
2. **None 即"未评估"**：`None` 表示"评估未发生（服务不可用/熔断/降级）"，与 `0`（评估了但质量为零）语义完全不同；
3. **passed 独立判定**：`passed` 只允许由真实评估结果计算得出；降级路径必须显式置 `False`，禁止依赖 `.get()` 默认值。
