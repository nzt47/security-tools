## 六、性能与成本控制

- **反思轮数收敛**：`reflection_retries`（默认 2）为失败反思设置独立上限，与 `max_iterations` 解耦，防反思自身循环放大 token 成本（D6 收敛保证）
- **增量注入**：`_think` 仅注入最近 3 轮失败摘要（`_failure_history` 保留上限），不重传全量历史，省 token（设计文档要点 5）
- **诊断裁剪**：`error_message` 截断 300、`project_context` 仅 8 键×100 字符、`repair_actions` 上限 3 条、`avoid` 上限 2 条
- **零 LLM 兜底**：LLM 不可用/故障/输出非法时由 `REPAIR_HINTS` 表规则兜底，反思仍产出根因与修复建议，不空转
