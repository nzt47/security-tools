# D7 / D9 / D11 缺陷修复回归测试用例清单

> 所属任务：任务 2「自愈执行器修复（验证真实化 + 动作补全 + 危险动作保护）」
> 覆盖缺陷：D7（验证假成功）、D9（restart_service 假成功 + restart_component 缺失）、D11（熔断器直改私有字段）
> 安全护栏：clear_cache 白名单 / clear_memory drop_caches 门控（守安全红线）
> 配套能力：M4 恢复动作映射表（`agent/self_healing/policy.py`）

## 一、缺陷 → 用例映射总览

| 缺陷 | 核心问题 | 修复策略 | 用例组 | 位置 |
|------|----------|----------|--------|------|
| D7 | `verify_heal` 依赖无参 `assess()` 假满分 | 动作专属验证器 + 真实健康分（`get_history(1)`，None/低分禁通过） | `TestVerifyHeal` / `TestVerifyAction` | `tests/integration/test_self_healer_integration.py` |
| D9 | Windows `Restart-Service 'yunshu'` 假成功 | 无 `restart_command` → SKIPPED；执行后必须验证，未验证 → FAILED | `TestRestartService` / `TestRestartComponent` | 同上 |
