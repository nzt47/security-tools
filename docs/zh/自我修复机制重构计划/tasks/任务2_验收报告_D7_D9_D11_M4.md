# 任务 2：自愈执行器修复 — 验收报告

> 所属阶段：阶段二（恢复层修复） ｜ 缺陷：D7、D9、D11、M4 ｜ 验收日期：2026-08-14

## 一、概览

修复自愈执行器"假成功/半成品"问题，让自愈闭环的"执行 → 验证"名副其实：

| 缺陷 | 问题 | 修复方案 |
|---|---|---|
| D7 | `verify_heal` 依赖无参 `assess()` 默认满分，验证永远"假成功" | 读取真实健康分（`get_history(1)`）+ 按动作类型定义专属验证器 |
| D9 | `restart_service` 在 Windows 下"假成功"；缺少 `restart_component` | 无重启方式返回 SKIPPED；执行后强制验证，未验证一律 FAILED；补全进程内模块热重启 |
| D11 | `recover_circuit_breaker` 直接改私有字段 `._state` | 改为全局熔断注册表公开 API（`get_all_circuit_breaker_status` + `force_close`/`get_status`） |
| M4 | 无"故障域 → 恢复动作"映射，告警自愈动作写死 | 新建 `agent/self_healing/policy.py` 声明式映射表 + 告警接线 |

## 二、修复详情与验证证据

### D7：验证机制真实化

- `verify_heal` = 动作验证器 ∧ 真实健康分 ≥ 阈值（默认 0.7）
- 健康分 `None` / history 空 → 验证失败（禁假满分），日志含 `verify_health.no_data`（WARNING）
- 动作验证器按 `verify_action` 分发：`restart_service`（端口探测）、`clear_cache`（目录大小下降）、`recover_circuit_breaker`（`get_status()` 非 OPEN）、`gc_collect`/`clear_memory`（RSS 下降 > 1MB）
- **证据**：`test_verify_health_none_fails`（None → False）、`test_verify_action_fails_returns_false`（健康分 0.9 但动作验证失败 → False）通过

### D9：restart_service / restart_component 补全

- Windows 无 `restart_command` → `SKIPPED("未提供可执行的重启方式")`（非 SUCCESS）
- 执行后必须经验证器确认（端口恢复），验证失败 → `FAILED` 并携带 `failed_ports` 明细
- 新增 `restart_component`：`importlib.reload` 进程内模块热重启，无 `target_module` → SKIPPED
- **证据**：`test_windows_no_restart_command_skipped`、`test_windows_restart_command_partial_ports_failed`、`test_reload_success` 通过

### D11：恢复熔断器规范化

- 通过 `get_all_circuit_breaker_status()` 定位 OPEN 熔断器 → `get_circuit_breaker(name).force_close()` 恢复
- 记录恢复前/后状态（`circuit_breaker_recovered` 日志）
- 全代码无 `._state =` 直接赋值（grep 仅注释提及）
- **证据**：`test_recover_open_breaker_public_api`（断言 `force_close()` 公开调用）通过

### M4：恢复动作映射表

- `agent/self_healing/policy.py`：4 个故障域（llm_timeout / tool_failure / memory_failure / decision_loop），每域含 `detect` 条件 + `actions`
- `ACTION_STATUS` 覆盖 HealAction 全部 9 值 + 预留动作，未实现动作 → `SKIPPED("未实现")`，未知动作 → `FAILED`
- `alert_manager._check_heal_action`：规则显式 `heal_actions` 优先，否则按告警名读映射表
- **证据**：`TestRestoreMap` / `TestDomainLookup` / `TestUnimplementedActions` 通过
