## 二、本轮（收尾）主要成果

1. **“建议/再定义”红色 HTTP 400 修复**
   - 根因：资产 id=`skill` 与统一斜杠解析路由 `/api/skills-mgmt/skill/<id>` 静态段撞段，
     `/skill/optimize|redraft|suggest-fix` 被劫持进斜杠解析器 → 报“缺少 command 参数”400。
   - 方案：斜杠路由改名 `/api/skills-mgmt/slash/<id>`（命令弹窗同步）；optimize 4xx 在 UI 优雅降级。
2. **三项评审提示云枢自动完成**
   - 新端点 `POST /<skill_id>/fix-auto`（service.apply_auto_fixes，确定性补丁 + 重新评审）：
     - QUAL_NO_SCHEMA → 依 default_params 自动生成 config_schema；
     - QUAL_NO_TAGS → 按 内容类型+自动分类+名称 补齐 2–5 个检索标签；
     - DATA_COLLECT_SENSITIVE → 自动标记 is_sensitive=true。
   - 「建议」弹窗新增「云枢可自动完成(N) · 一键自动修复并重新评审」。

## 四、遇到的问题与解决方案

| 问题 | 方案 |
| --- | --- |
| 空 body + JSON 头导致 Flask get_json 400 | hubGet/hubPost 仅在确有 body 时带 Content-Type；受影响路由 get_json(silent=True) 兜底 |
| 斜杠路由与按 id 动作路由撞段（id=skill 时全 400） | 斜杠路由改 `/slash/<id>` 独立命名空间 |
| 评审提示只给建议无法执行 | fix-auto 确定性补丁 + 自动重新评审 |
| 外来技能重复云枢自身功能仍可入库 | 评估 error 阻断 + install/converter 硬闸门（delete + 400 NATIVE_DUPLICATE） |
| 分类碎片类（last/pub/sma 等测试残留） | 通用 token 扩充 + 英文 token 建类最短长度；清理 21 条测试残留运行时技能 |
| 分类注册表脏数据/跨生态不一致 | asset:/rt: 命名空间隔离 + manual 标记不被覆盖 + rt 弱判定回退 asset |
| 按日归档测试跨午夜失败 | 测试时间戳改为当日相对值 |
| 运行时侧车 JSONL 反复 dirty | gitignore 补充 events/audit/merge-backups/classes/evolution_archive |
