## 一、agent/health/dashboard.py（G1）

**新增函数 `get_evolution_audit(days=7, archive=None, approvals=None, recent_limit=20)`**
（位置：`probe_trend` 路由之后）

| 修改点 | 说明 |
|---|---|
| 签名 | `days`=统计窗口（天）；`archive`=EvolutionArchive 实例（None=空视图）；`approvals`=ApprovalFlow 实例（None=不输出 approval_stats）；`recent_limit`=近期事件条数上限 |
| 窗口过滤 | `created_at` ≥ `now - days`；时间缺失/非法保守保留（不排除） |
| `recent_events` | 窗口内记录按时间倒序、限 recent_limit；字段含 record_id/object_id/decision/decision_reason/score 等 |
| `decision_stats` | 按 decision 计数（committed/rejected/rolled_back/pending_review） |
| `object_score_trend` | 按 object_id 分组、时间升序的评分序列（无 score 的记录跳过） |
| `cost_summary` | `total_events`（窗口内记录数）+ `total_tokens`（cost.tokens 汇总） |
| `approval_stats` | 仅注入 approvals 时输出 `total`/`pending`/`merged`/`rejected`（取自 `approvals.stats()`） |
| 空档案 | 返回空视图不抛异常（验收 6 断言） |

## 二、agent/skills_mgmt/service.py（G2）

**`__init__` 新增属性**（`_mcp_adapter` 之后）：
- `self._approval = None`（ApprovalFlow 实例，None=未接入审批流，测试动态注入）
- `self._auto_rollback = None`（AutoRollback 懒加载缓存）

**新增 6 个网关方法 + 1 个属性**（`mcp_adapter` property 之后）：

| 方法 | 实现要点 | 返回 |
|---|---|---|
| `auto_rollback`（property） | 懒加载 `AutoRollback(archive=self._lineage_archive)`（restorer=None=仅记录不实际恢复） | AutoRollback 实例 |
| `list_pending_approvals()` | `_approval.list({"state": "pending_review"})` 转 dict；未接入返回 `[]` | `[{"record_id","object_type","object_id","level","state","created_at"}]` |
| `approve_change(record_id, actor="reviewer", note="")` | 透传 `flow.approve(record_id, actor=actor, note=note)`；未接入抛 RuntimeError | `{"record_id","state","level"}` |
| `reject_change(record_id, actor="reviewer", reason="")` | 透传 `flow.reject(record_id, actor=actor, reason=reason)`；未接入抛 RuntimeError | `{"record_id","state","decision_reason"}` |
| `get_evolution_audit(days=7)` | 透传 dashboard 版，注入 `archive=self._lineage_archive`、`approvals=self._approval` | G1 视图 |
| `run_auto_rollback(object_id, version, metrics=None)` | `auto_rollback.check_and_rollback(...)` → RollbackResult 转 dict | `{"triggered","reason","suppressed","halted","details"}` |

**注**：approval.py **无需改动**——复用既有 `ApprovalFlow.list()`（等值过滤 + created_at 降序），未新增 `list_pending()`。
