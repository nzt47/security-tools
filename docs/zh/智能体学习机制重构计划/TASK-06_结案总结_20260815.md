## 三、关键实现摘要

- **钩子旁路注入**：学习钩子以回调挂在 `ChangeDetector.collect()` 出口，不改 diff 循环；异常 try/except 兜底，感知主链路零影响
- **分级路由**：低置信（<0.4）/中置信（0.4~0.7）→ 记忆 JSONL；高置信（≥0.7）→ 审计 + DRAFT 草稿
- **漂移评分**：重叠指标相对偏差均值（|cur-prev|/prev）；基线 0/非数值/无重叠跳过；无样本返回 0.0
- **漂移事件**：confidence=0.50（中置信 → 记忆 + 草稿双写），severity=warning
- **R6 修复**：`capture_baseline` 聚合缺陷（`reading.sensor_name` 字段 + `behavior_` 前缀去重），补真实数据用例固化
- **配置优先级**：env > config.yaml > 硬编码默认值
