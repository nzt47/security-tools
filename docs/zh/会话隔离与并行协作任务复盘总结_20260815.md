## 7. 经验沉淀

1. **共享仓库的 .git/index/HEAD 是全局单例**：并行会话必须 worktree 隔离，禁止共享主工作区 checkout/reset；
2. **幂等守卫必须与创建原子**：锁外 check-then-create 在并发下必然被击穿（本次实测 8 线程同 ID → 8 条重复索引）；
3. **内存无界增长是真泄漏**：懒创建缓存必须配容量上限 + 淘汰策略；
4. **pre-commit 的 stash 恢复是脆弱点**：并发写入未暂存文件会致 `patch does not apply`，hook 运行前应先收敛未暂存改动。
