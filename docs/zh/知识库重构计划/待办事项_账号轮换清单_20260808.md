## 2. 各平台强制登出操作对照

| 平台 | 操作路径 |
|---|---|
| 网易/139 | 设置 → 安全中心 → 登录设备管理 → 全部登出 |
| 阿里云 | 控制台 → 账号安全 → 会话管理 → 强制登出；RAM/AK 立即禁用轮换 |
| 腾讯云 | 控制台 → 访问管理 → API 密钥管理 → 禁用+新建 |
| GitHub | Settings → Security → Sessions → Revoke all；Developer settings → PAT 全部删除 |
| Gitee | 设置 → 安全设置 → 访问令牌/SSH 公钥 → 全部删除；登录记录 → 退出所有 |
| 微信/支付宝 | 设置 → 账号与安全 → 登录设备管理 → 删除全部设备 |
| 钉钉/飞书/SSO | 管理后台 → 设备/会话管理 → 远程登出 |
