## 2. 交付成果

### 2.1 性能优化成果
- **瓶颈定位（`scripts/probe_list_100k_perf.py`）**——10 万卡实测：
  - `list()` 无缓存冷读 **~69s**，其中 YAML 解析占 **74%**（~51s），文件 IO 占 14%（~9.5s）
  - `list(use_cache=True)` 命中 ~170ms（几乎全是指纹扫描 150ms）
- **写路径增量同步（`agent/knowledge/card.py`）**——核心优化：
  - 新增 `_sync_list_cache()`：create/update/delete 写盘成功后**即时同步内存缓存与指纹**，
    写后查询不再全量重载（旧行为 10 万卡 ~69s → 新行为 ~174ms）
  - update 支持 type 迁移双指纹（旧目录移除 + 新目录加入）；`_fp_entry` 单文件 stat
  - delete_many / import_from_dir 批量场景走 `_invalidate_list_cache()` 整体失效（O(K·N) 逐张同步不划算）
  - 安全边界：缓存与指纹同函数同步，任一遗漏 → 下次命中全量指纹比较发现 → 自动重载（只慢不坏）
- **日志埋点**：create/update 末尾 INFO 级输出 `[缓存同步]` 汇总（指纹stat+增量同步/全方法耗时），
  `_sync_list_cache`/`_fp_entry` DEBUG 级细分（实测增量同步 ~0.1ms，全方法 ~10ms）
- **方案文档**：`docs/PERF_LIST_CACHE_INCREMENTAL_SYNC.md`（契约变更细节见 §4）

## 3. 遇到的问题与解决方案

| 问题 | 根因 | 方案 |
|---|---|---|
| 10 万卡 list 冷读 69s | YAML 解析占 74%（每卡 read+safe_load），不可压缩 | 内存缓存规避重复解析；命中 170ms（指纹 150ms + 过滤 20ms） |
| 写后查询仍 69s 重载 | 旧缓存策略"写后失效→下次全量重载" | 写路径增量同步（缓存+指纹即时更新），写后直接命中 |
| 缓存命中每次扫 10 万指纹 | `_fingerprint()` 全量 scandir+stat | 缓存未加载时跳过指纹直接重载（省一次扫描）；内部写路径已跟踪无需重扫 |
| 测试断言 `len(opt)==6000` 失败 | g* 互链环目标全部存在无断链，实际断链仅 3000（o* 幽灵卡） | 修正断言 6000→3000 并注释根因 |
| `_make_card` 校验失败 | schema 要求 `insight` 一句话核心洞见 | 测试构造补 `insight` 字段 |
| create/update 埋点 `_t_start` NameError | 并行编辑时计时变量被后续编辑覆盖未持久化 | 复核 diff 后补回，单行回归验证 |
| Windows 建库 `PermissionError` | `Path.open` 作用于目录 | 删除多余 open，仅 mkdir |

## 4. 契约变更（写后查询不再全量重载）

| 操作 | 优化前 | 优化后 |
|---|---|---|
| `create()` 后 `list(use_cache=True)` | 指纹变化 → 全量重载（10 万卡 ~69s） | 缓存增量同步 → 命中（~174ms） |
| `update()` 后 `list(use_cache=True)` | 全量重载 | 命中（type 迁移双指纹同步） |
| `delete()` 后 `list(use_cache=True)` | 全量重载 | 命中（缓存即时移除） |
| `delete_many()` / `import_from_dir()` 后 | 全量重载 | 整体失效 → 全量重载（**不变**） |
| 进程外修改文件 | 指纹检测 → 重载 | **不变**（契约保持） |
| `list()` 默认 `use_cache=False` | 每次实时读盘 | **不变** |

> 详细设计、安全边界与风险见 [PERF_LIST_CACHE_INCREMENTAL_SYNC.md](../../PERF_LIST_CACHE_INCREMENTAL_SYNC.md)
