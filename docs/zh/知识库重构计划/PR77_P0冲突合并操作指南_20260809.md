## P0-1 `agent/knowledge/index.py`（+121/-106，差异最大）

### 两侧差异摘要

| 差异点 | master | develop |
|--------|--------|---------|
| `read_index_slugs` 签名 | `(index_path: str \| Path)` | 同左（行内微调） |
| `_locate_card_slug` 签名 | 无显式参数 | `(path: str \| Path, wiki_root: str \| Path) -> Optional[tuple[str, bool]]`，显式补参 |
| CardStore 导入 | 函数内 `from agent.knowledge.card import CardStore` | 同左（惰性导入已存在） |
| 卡片存储检索 | 旧实现 | 使用 `importlib.import_module` 动态导入 + 内存缓存（`c7774023` perf 优化） |

### 操作步骤

1. 以 develop 版本为基底：`git checkout --theirs agent/knowledge/index.py`
2. 手工合并区域：
   - **`_locate_card_slug`**：采用 develop 的显式签名（`path` + `wiki_root`），搜索 master 版本中调用方是否传旧签名，需同步更新调用处
   - **CardStore 惰性导入**：保留两侧一致的部分（都是函数内延迟 import，无冲突语义）
   - **`_on_event` 类型标注**：master 用 `reading: Any`，develop 去掉标注 → 保留 develop（简易原则，减少依赖）
3. 全局检查：`grep -rn "_locate_card_slug(" agent/` 确认所有调用处与新签名兼容

### 验证

```bash

python -c "from agent.knowledge.index import read_index_slugs; print('OK')"
```
