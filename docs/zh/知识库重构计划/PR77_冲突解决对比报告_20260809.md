## 二、P0 文件详细差异（modify/modify）

### 1. `.gitignore` — 并集合并
- **dev 增量**：`data/knowledge/reports/` 等知识库报告目录规则。
- **mst 增量**：`.fix*-tooltests/`、`.fix_backups/` 等 CI 修复临时目录规则。
- **决策**：两侧规则互不冲突，做并集，最终保留 `_FIX_PATTERNS` 全部规则。

### 2. `agent/knowledge/index.py` — dev 基底 + mst 防御
- **dev 侧重写**：`_on_event` 事件回调、`_load_watcher_cls` 用模块级 `import_module`（`from importlib import import_module`），watch 目录为 `concepts/entities/insights` 子目录 + archives。
- **mst 增量**：`_on_event` 中增加 `getattr` 防御性兜底，避免事件字段缺失时 KeyError。
- **决策**：以 dev 实现为基底，吸收 mst 的 getattr 兜底；`import_module` 保持模块级绑定（与 dev 测试 `patch("agent.knowledge.index.import_module")` 一致）。

### 3. `agent/server_routes/routes_knowledge.py` — dev 基底 + mst 防御
- **dev 侧重写**：lint 报告序列化用 `asdict(report)`（不依赖 `to_dict`），批量导入/健康检查等路由。
- **mst 增量**：try/except 防御包裹 lint 调用，异常时返回错误响应。
- **决策**：以 dev 为基底吸收 try/except；保留 `asdict(report)` 用法——**关键判断**：master 的 6dc94274 是给 master 版 routes 补 `to_dict` 的修复，develop 侧用 `asdict` 自洽，故不强制补 `to_dict`（并行会话后续 b73d281d 在 develop 侧自行对齐了 to_dict，已吸收，无冲突）。

### 4. `tests/unit/test_tool_negative_samples.py` — 整体取 mst 版
- **dev 版**：xfail 计数停留在旧数据（16 xfail）。
- **mst 版**：B2 数据层措辞优化后的最新实测（**11 xfail / 14 PASS**，G4 含「查看系统中运行的进程」case）。
- **决策**：取 mst 版，保证 xfail 断言与实际 BM25 表现一致（11 个）。

### 5. `yunshu-ui/src/App.tsx` — 两侧样式融合

- **决策**：dev 结构 + 吸收 mst 的 fontWeight 与条件 hover，保持视觉细节一致。
