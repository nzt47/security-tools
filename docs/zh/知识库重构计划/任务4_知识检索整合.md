## 一、目标描述

将知识库接入云枢**已有的**混合检索与重排序能力，形成"知识语义检索"：RRF 融合（BM25 关键词 + ChromaDB 向量）+ bge-reranker 重排 + 双链图扩展，并对任务2 卡片返回带来源的引用。

【不易】约束：不得修改 `agent/tool_router_hybrid.py`、`agent/tool_router_reranker.py` 的现有行为，只做**组合接线**。复用现有 RRF 融合逻辑与 `ToolReranker.rerank` 接口，不重写。

### Step 3：重排

- 候选列表经 `ToolReranker.rerank(query, candidates)` 重排（`agent/tool_router_reranker.py`）。
- 子进程不可用/超时 → 返回原序（`rerank_score=0.0`），不抛异常。
- `rerank_score` 为 sigmoid 概率（遵循项目已固化规范：raw logits 必须 sigmoid 转换以对齐 min_score 阈值）。
- 过滤 `rerank_score` 低于阈值的候选（阈值参考项目 `SKILL_RERANKER_*` 环境变量体系，知识库使用独立环境变量如 `KNOWLEDGE_RERANK_MIN_SCORE`，默认与项目一致）。

- [ ] 测试全绿，覆盖率 ≥ 80%。

- [ ] reranker 子进程不可用时自动降级为 RRF 原序，不抛异常。
- [ ] 双链扩展确实提升"概念关联型"查询的召回（对比用例：开/关扩展的召回差异）。
- [ ] 结果引用含 `[来源: slug|status]`，可追溯到卡片文件。
- [ ] 误召回保护生效：低置信 top1 返回空结果而非噪声。
