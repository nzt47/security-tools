# 云枢本地部署手册

> 目标：本地一键启动服务（Docker Compose）+ 部署演练（含真实 SSH 部署与故障排查）。
> 测试/验证相关见 `docs/zh/本地测试手册.md`；生产部署详见 `docs/zh/部署操作手册_20260816.md`。

## 一、前置条件

| 项 | 要求 |
|---|---|
| Docker | daemon + `docker compose` v2（`docker info` 正常） |
| `.env` | 含 LLM 4 项（启动必需）+ 告警段 7 项（发信必需），模板见 `.env.example` |
| 端口 | 5678（服务）、2525（本地 SMTP 捕获联调） |

## 二、一键启动（Docker Compose）

```bash
cd deploy/t8-gateway

# 构建（Dockerfile 打包依赖：CPU torch + pip install -e .）并启动
docker compose up --build -d

# 查看状态
docker compose ps
```

要点：
- `env_file: ../../.env` 自动注入 LLM_*/SMTP_*（单一数据源）
- entrypoint 自动执行：`.env` 缺失生成 `FLASK_API_TOKEN` → 审计日志租户归属补全（幂等）→ `INIT_TENANT=1` 时租户初始化
- healthcheck：`/api/open/echo` 轮询（start_period 90s，AI 依赖首次启动较慢）
- 首次构建含 torch/chromadb 等约 10-20 分钟；`.dockerignore` 已瘦身上下文

## 三、部署演练（simulate_ssh_deploy.sh）

### 模式 A：本地 compose 演练

```bash
bash scripts/dev/simulate_ssh_deploy.sh --dry-run    # 预览命令
bash scripts/dev/simulate_ssh_deploy.sh              # 执行：build → up -d → ps
```

### 模式 B：真实 SSH 部署（对应 deploy.yml deploy job）

```bash
bash scripts/dev/simulate_ssh_deploy.sh \
  --host <服务器IP> --user <用户> --key ~/.ssh/id_rsa --path /opt/yunshu \
  --ssh-port 22 --connect-timeout 10 [--verbose]
```

- 连接测试**始终 `ssh -v` 详细模式**（认证/连接细节直接输出，排查超时/拒连关键）
- `--verbose`：远程拉取/启动命令也加 `-v`
- 流程：连接测试 → `docker compose pull && up -d` → `docker compose ps`

### 参数一览

| 参数 | 说明 |
|---|---|
| `--compose-dir` | 模式 A compose 目录（默认 `deploy/t8-gateway`） |
| `--host` / `--user` / `--key` / `--path` | 模式 B 目标/用户/私钥/部署路径 |
| `--ssh-port` | SSH 端口（默认 22） |
| `--connect-timeout` | 连接超时秒数（默认 10） |
| `--verbose` | 远程命令加 `ssh -v` |
| `--dry-run` | 只打印命令不执行 |

## 四、停止与清理

```bash
cd deploy/t8-gateway
docker compose down          # 停止容器（数据卷 yunshu_data 保留）
docker compose down -v       # 连同数据卷一起清除（慎用）
```

## 五、SSH 部署故障排查

SSH 连接/认证故障（超时、Permission denied、Host key、端口等 5 类场景）见
**`docs/zh/运维排错指南.md` §一**——脚本连接测试始终 `ssh -v` 且输出已过滤
（仅保留超时/认证失败/成功关键行），失败时打印带时间戳诊断 + 4 步排查指引。

## 六、操作流程（部署部分）

```bash
# 1. 准备：.env 填 LLM + 告警段（模板 .env.example）
# 2. 一键启动
cd deploy/t8-gateway && docker compose up --build -d
# 3. 部署演练（本地 compose 或真实 SSH）
bash scripts/dev/simulate_ssh_deploy.sh --dry-run
bash scripts/dev/simulate_ssh_deploy.sh --host <IP> --user <user> --key <key> --path /opt/yunshu
# 4. 停止
docker compose down
```
