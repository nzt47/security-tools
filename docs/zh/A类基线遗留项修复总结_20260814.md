## 根因 1：本地 pre-commit hook 未同步 TLM 体系（A-2/A-3）

### 复现步骤

```
1. 确保本地 .git/hooks/pre-commit 是旧版 pre-commit 框架 hook（非 TLM 体系）
2. python scripts/run_full_pytest.py 4 1（或单跑两个用例）
3. 观察：
   - tests/regression/test_precommit_hook_blocking.py::test_real_git_commit_blocked_by_hook
     → AssertionError: No .pre-commit-config.yaml file was found
   - tests/unit/test_ci_guard_fix_regression.py::test_guard_pipeline_json可运行
     → returncode=1 (0x00000001)，stdout 含
       [BLOCK] [D1] .git/hooks/pre-commit: 部署的 hook 含编码检查段 缺少模式: ENCODING_CHECK\s*=
```

### 根因链

1. `test_precommit_hook_blocking._install_local_hook` **优先采用** `.git/hooks/pre-commit`
   （仅缺失时回退 `hook_fail_safe.psm1` 生成）——本地旧 hook 被复制到临时仓库，
   commit 触发旧 hook → 报 .pre-commit-config.yaml 缺失
2. `verify_core_invariants.D1-D3`（`required=False`）守护**部署态 hook 质量**——
   本地旧 hook 缺 `ENCODING_CHECK` 模式 → BLOCK → 模拟流水线 fail
3. 两者是**同一旧 hook**的两个受害面

### 修复（三层）

**① 环境治本**：重新部署 TLM hook
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev/sync_precommit_hook.ps1
# 旧 hook 备份为 .git/hooks/pre-commit.bak.20260814_031552
# 验证：新 hook 含 TLM_HOOK_SOURCE_REPO / ENCODING_CHECK / CI_GUARD marker
```

**② A-2 测试加固**（【不易】测试不依赖本地 hook 部署新旧）：
```python

        if b"TLM_HOOK_SOURCE_REPO" not in hook_content:
            print("[diag-hook] 本地 hook 缺 TLM marker，回退 psm1 生成", file=sys.stderr, flush=True)
            hook_content = None
    if hook_content is None:
        # ← 原 else 分支：hook_fail_safe.psm1 Get-HookContent 生成
        ...
```

**③ 顺带修复真实污染**：hook 编码检查段拦截 `scripts/protect_source_files.ps1` 双 BOM

## 根因 2：os.symlink 失败残留未清理（A-1）

### 复现步骤

```
1. Windows 无管理员/开发者模式（os.symlink 会抛异常）
2. python -m pytest tests/unit/test_impact_analysis_cache.py::TestCollectTestFilesSymlinkP1
3. 观察：
   AssertionError: 符号链接创建失败时应仅收集 1 个真实文件，实际 2
```

### 根因

`os.symlink` 抛 `FileNotFoundError [WinError 2]`（被 `except (OSError, ...)` 捕获 →
`symlink_created=False`），但**失败后磁盘残留无效链接文件**，`_collect_test_files`
用 rglob 仍收集到它 → 降级分支断言"仅 1 个"与实测 2 冲突。

### 修复

```python
except (OSError, NotImplementedError, PermissionError):
    # 【不易】os.symlink 失败后可能残留无效链接文件（实测 WinError 2 后
    # link 文件仍在磁盘），若不清理 rglob 仍会收集到
    if symlink_file.exists():
        try:
            symlink_file.unlink()
        except OSError:
            pass
    symlink_created = False
```

### 验证结果

✅ 单文件 TestCollectTestFilesSymlinkP1 通过（Windows 无权限降级分支与 Linux 分支均通过）

## 根因 3：symlink 权限异常未捕获（A-4/A-5）

### 复现步骤

```
1. Windows 无管理员/开发者模式
2. python -m pytest tests/unit/test_system_tools_core.py -k symlink
3. 观察：
   FileNotFoundError: [WinError 2] ... 'target.txt' -> 'link.txt'（测试直接崩溃）
```

### 根因

两处仅 `if hasattr(os, "symlink"):` 判断后直接 `os.symlink(...)`，未捕获
Windows 无符号链接权限的运行时异常（WinError 2/1314），崩溃而非 skip。

### 修复

```python
if hasattr(os, "symlink"):
    try:
        os.symlink(target_path, link_path)
    except (OSError, NotImplementedError):
        # 【不易】Windows 无符号链接权限（WinError 2/1314）/平台不支持
        # 时跳过而非崩溃（FileNotFoundError 是 OSError 子类）
        pytest.skip("符号链接不可用（Windows 需管理员/开发者模式）")
    result = get_file_info(link_path)
```

### 验证结果

✅ `2 skipped`（Windows 无权限 → skip；Linux 权限分支保持断言）

1. **测试不得依赖本地 `.git/hooks` 部署状态**——hook 类测试需 marker 校验 + psm1 回退双保险
2. **Windows 符号链接是"平台能力"而非"语言特性"**——`hasattr` 判断不足，须 try/except + skip
3. **hook 编码检查段是真实守护**——双 BOM 污染被正确拦截，`check_ps1_encoding --fix` 一键修复
4. **部署态守护（D1-D3, required=False）设计正确**：hook 缺失跳过、旧 hook 拦截——本地环境未同步时给出明确信号
