## 二、交付成果

### 功能清单
1. **5 类因素模块**：提示词结构 / 语言表达 / 上下文参数 / 模型参数 / 效果评估，共 15 个内置因素
2. **四种控件**：滑块、下拉、文本、开关，实时联动预览
3. **实时预览**：生成提示词 + 模拟输出 + SVG 效果雷达图；预留真实 LLM 接口（OpenAI 兼容）
4. **分类筛选**：全部 / 单类 chips 过滤
5. **自定义因素**：表单添加、删除、localStorage 持久化
6. **系统提示词组件**（新增）：7 段默认组件，逐段启停 / 编辑 / 新增 / 删除，真实调用时拼接为 system message 注入
7. **Token 用量估算**（新增）：每段 token + 系统合计 + 用户提示词 + 总占用 + 上下文窗口占比（可调窗口大小），JSON 导出 v2 含 token 明细
8. **数据导出**：JSON（可再导入分析）/ CSV（表格化）
