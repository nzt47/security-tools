> **关联**：`docs/zh/规划模块重构计划/规划模块缺陷清单.md`（D11，P1，阶段 2）

## 一、根因分析

[executor.py L186](file:///c:/Users/Administrator/agent/planning/executor.py#L186) `execute_plan` 入口仅校验状态，**无依赖图验证**：
- 悬空依赖（`task.dependencies` 引用不存在的任务 id）→ 该任务永不可执行 → 计划卡死 → 泛化错误"计划执行超时或异常终止"（L242）；
- 循环依赖不检测；
- 工具可用性不预检。

## 二、三义分析

- **【不易】** 失败前置化：畸形计划必须在执行前被拦截并给出**明确错误**（含"依赖不存在"），而非执行期卡死。
- **【变易】** 验证项可扩展（依赖图 → 环 → 工具预检），验证失败策略可配置。
- **【简易】** 单一 `validate_plan` 方法，失败即收尾 FAILED 并返回。

## 三、修复方案（推荐方案 A）

### 1. 新增 `validate_plan`（executor.py）

```python
class PlanValidationError(Exception):
    """计划验证失败"""
    pass

def validate_plan(self, plan: Plan) -> None:
    """执行前验证计划结构，失败抛 PlanValidationError"""
    task_ids = {t.id for t in plan.tasks}
    for task in plan.tasks:
        for dep in task.dependencies:
            if dep not in task_ids:
                raise PlanValidationError(
                    f"任务 '{task.id}' 依赖不存在的任务 '{dep}'（悬空依赖）"
                )
    # 环检测：DFS 找依赖环
    visiting, visited = set(), set()
    def dfs(tid: str) -> None:
        if tid in visiting:
            raise PlanValidationError(f"检测到循环依赖（涉及任务 '{tid}'）")
        if tid in visited:
            return
        visiting.add(tid)
        task_map = {t.id: t for t in plan.tasks}
        for dep in task_map.get(tid, Task()).dependencies:
            dfs(dep)
        visiting.discard(tid)
        visited.add(tid)
    for t in plan.tasks:
        dfs(t.id)
```

### 2. `execute_plan` 入口接入（L186 校验状态前）

```python
try:
    self.validate_plan(plan)
except PlanValidationError as e:
    plan.error = str(e)
    logger.error(f"计划验证失败: {e}")
    self._finalize_state(plan, PlanState.FAILED, reason="计划验证失败")
    return plan
```

### 3. 工具预检（可选，配置开关 `config.verify_tools` 默认 False）

对 `task.description` 中的工具名做注册表存在性检查，未注册则报错——本轮先以依赖图验证为主，工具预检标记为可配置扩展，避免过度（防误报：任务描述中的工具名提取为启发式）。

## 五、验证预期

- D11 复现测试 `test_dangling_dependency_detected_by_validator` **转绿**：`state == FAILED` 且 `"依赖" in error`；

## 六、风险与回滚

- **风险 1**：环检测 DFS 复杂度 O(V+E)，计划规模小（≤ 分解器 max_subtasks），可接受；
- **风险 2**：`Task()` 空构造兜底 `task_map.get(tid)`——仅在依赖 id 不存在时触发（已被悬空检测拦截，双保险）；
- **回滚**：仅 executor.py 单文件。
