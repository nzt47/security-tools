## 一、使用时机

| 时机 | 动作 |
|------|------|
| 阶段 1 完成后、提交代码前 | 逐项自检本清单，任一项 FAIL 禁止合并 |

## 三、一键检查命令

阶段 1 完成后的标准门禁命令（建议顺序执行）：

```bash
# 1) 阶段 0 脚本：静态缺陷特征 D1–D19 + 规划测试基线（本清单 A/B/C 类主要依据）
python scripts/planning_baseline_check.py

# 2) P0 复现测试专项（B-4）
python -m pytest tests/unit/test_planning_defect_d1.py \
    tests/unit/test_planning_defect_d2.py \
    tests/unit/test_planning_defect_d3.py -q

# 3) 改动范围核对（C-4）
git diff --stat HEAD -- planning/ tests/
```

三条命令全部通过即满足本清单 PASS 条件；任一 FAIL 则按上表"失败处置"处理，**禁止跳过检查直接进入阶段 2**。
