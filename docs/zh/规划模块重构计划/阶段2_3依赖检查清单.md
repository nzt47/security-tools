>

## 一、使用时机

| 时机 | 动作 |
|------|------|
| 阶段 2 完成后、提交代码前 | 逐项自检本清单，任一项 FAIL 禁止合并 |
| 阶段 3 开始前 | B 类（能力验收）与 C 类（不变量）全部 PASS 后方可动工 |
| 阶段 4 开始前 | B 类全部 PASS；D 类（前置就绪）应满足阶段 4 依赖项（经验接口/指标/摘要） |
| 阶段 2 之后任何回归 | 重跑"一键检查命令"确认无回退 |

> 阶段 3 与阶段 4 相互独立（均依赖阶段 2），可并行执行；但**各自入场前均须通过本清单 B 类**。

## 三、一键检查命令

阶段 2 完成后的标准门禁命令（建议顺序执行）：

```bash
# 1) 阶段 2 能力验证：S1–S8 静态能力 + 专项测试（本清单 B 类主要依据）
python scripts/planning_stage2_check.py

# 2) 阶段 0 基线回归（B-8）
python scripts/planning_baseline_check.py

# 3) 改动范围核对（C-4）
git diff --stat HEAD -- planning/ tests/
```

三条命令全部通过即满足本清单 PASS 条件；任一 FAIL 按上表"失败处置"处理，**禁止跳过检查直接进入阶段 3/4**。
