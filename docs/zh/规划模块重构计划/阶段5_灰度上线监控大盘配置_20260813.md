### A 区：记账与成本（重点）

## 三、记账延迟观测方案（现有指标无独立埋点 → 代理 + 兜底）

1. **代理指标**：`planning.duration_ms`（P99）覆盖规划全链路耗时（预算 check/快照回填在其中）；`planning.cost_total` 线性与 `increase(cost_total[1m])` 突刺覆盖记账"正确性"而非耗时。
2. **兜底检查**（记账延迟异常低概率，发生时表现为 cost 突变或快照缺失）：
   - `plan.metadata["budget"]` 快照非空（应用日志/接口可查）
   - `increase(planning.cost_total[1m])` 无周期尖刺
3. **后续埋点（小任务，不阻塞灰度）**：在 `planning/budget.py` `record_text`/`snapshot` 加 `time.perf_counter()` 埋点（Prometheus Histogram `planning_budget_op_duration_seconds`），并注册进 `BUSINESS_METRICS_DEFINITIONS`。TD 清单候选（随 TD-4 排期）。

## 四、告警规则（新建 `deploy/monitoring/prometheus/planning_alerts.yml`）

```yaml
groups:
  - name: planning_alerts
    interval: 30s
    rules:
      # 记账/成本异常
      - alert: PlanningCostZero
        expr: planning.cost_total == 0 and on() (sum(rate(yunshu_intent_layer_total{layer="planning"}[10m])) > 0.1)
        for: 30m
        labels: {severity: warning, category: planning, layer: billing}
        annotations:
          summary: "规划流量存在但成本恒 0（记账链路失效）"
          description: "部署版本可能未含 87856021，或 execute_plan finally 快照回填未触发。"
      - alert: PlanningCostSpike
        expr: increase(planning.cost_total[5m]) > 0.1
        for: 10m
        labels: {severity: warning, category: planning, layer: billing}
        annotations:
          summary: "规划成本 5 分钟增量超过 $0.1"
          description: "成本突刺：检查 LLM 调用是否异常放大（死循环式消耗），必要时按手册 §3.4 回滚。"
      - alert: PlanningDurationHigh
        expr: quantile(0.99, planning.duration_ms) > 30000
        for: 15m
        labels: {severity: warning, category: planning, layer: latency}
        annotations:
          summary: "规划 P99 耗时超过 timeout_seconds（30s）"
          description: "逃生通道兜底但用户体验受损；检查规划引擎性能。"
      # 错误率
      - alert: PlanningFailureRateHigh
        expr: planning.plans.failed / planning.plans.total > 0.1
        for: 10m
        labels: {severity: warning, category: planning, layer: execution}
        annotations:
          summary: "规划执行失败率超过 10%"
      - alert: PlanningLLMErrorRateHigh
        expr: sum(rate(yunshu_intent_layer_total{layer="llm_error"}[10m])) / sum(rate(yunshu_intent_layer_total{layer="llm"}[10m])) > 0.05
        for: 15m
        labels: {severity: warning, category: planning, layer: llm}
        annotations:
          summary: "LLM 错误率超过 5%（回退护栏）"
      # 流量异常
      - alert: PlanningTrafficDrop
        expr: sum(rate(yunshu_intent_layer_total{layer="planning"}[10m])) < 0.1
        for: 30m
        labels: {severity: warning, category: planning, layer: traffic}
        annotations:
          summary: "规划引擎流量消失（回滚动作异常）"
```

> ⚠ 成本类告警阈值（`$0.1/5min`、`$0.01/用例`）需按实际流量预演调整；先跑基线再启用。
