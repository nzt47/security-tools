# 任务提示词 · 阶段 3：约束、预算与容错降级

> **关联文档**：`docs/zh/规划模块重构计划/规划模块理想设计.md`（缺陷 D13/D14/D18 详见第四节）
> **前置阶段**：阶段 2（统一执行模型与持久化）。

---

## 目标描述

补齐理想设计中的"多维约束与资源管理"与"容错与风险管理"：实现预算管理（D13）、任务级降级链与重规划（D14）、协作式取消（D18），并完善 ask_user 恢复语义与超时策略。本阶段偏策略层，不改变执行模型。

## 前置依赖

- 阶段 2 已完成（统一执行模型与持久化）。

## 执行步骤

1. **预算管理（BudgetManager）**：
   - 新增 `planning/budget.py`：`PlanBudget` 数据类（`max_steps`、`max_iterations`、`max_seconds`、`max_tokens`、`max_cost`）+ `BudgetManager` 在每步/每次工具调用后累计 `elapsed_seconds / tokens / cost`（token 计数复用系统 `memory/token_counter.py`，成本按 `configs/models.yaml` 单价折算）。
   - 超预算触发策略：`steps/seconds` 超限→正常收尾返回部分结果；`tokens/cost` 超限→停止调用 LLM，降级为基于已有结果生成摘要并征求用户是否继续。
   - 接线：`ReActLoop` 迭代入口与 `PlanExecutor` 每任务执行前检查预算；预算信息写入 `ReActResult.final_state` 与 `Plan.metadata`。
2. **任务级降级链（D14）**：
   - `Task` 增加 `fallback_actions: List[str]`（可选字段，`to_dict()` 追加输出，保持兼容）。
   - `PlanExecutor._execute_task_with_retry` 重试耗尽后尝试 `fallback_actions` 中依次可用的工具（`ToolRegistry.has` 校验），全部失败才标记失败。
   - 失败归因：任务失败时调用 `reflector` 记录 lesson（已在 `learn_from_experience` 中实现，接通调用点），并记录 `failure_reason` 分类（工具缺失/超时/LLM 错误/逻辑错误）。
3. **重规划触发（Plan B）**：
   - 高优先级任务失败（当前 `priority >= 4` 即中断）不再直接中断：改为调用 `decomposer.refine(plan, feedback)` 重规划后续任务；若 refine 失败或无调整空间，再走中断。
   - 新增配置 `planner.replan_on_failure`（默认 true）。
4. **协作式取消（D18）**：
   - `PlanExecutor.cancel_plan` 设置协作式取消标志（`asyncio.Event` 或 `plan.metadata["_cancelled"]`）；`_do_execute_task` 在工具调用前检查标志；工具调用使用 `asyncio.wait_for` 超时后配合取消。
5. **ask_user 恢复语义**（接阶段 1 修复）：
   - 定义 `PlanningCore.ask_user(plan_id, question)` / `resume_plan(plan_id, user_answer)` 接口：持久化等待中的问题（阶段 2 存储），`resume_plan` 将用户答案写入 context 并恢复循环；等待超时（配置 `planning.ask_user_timeout_seconds`，默认 300）自动放弃并以"用户未确认"结束。
6. 测试：预算超限各维度、降级链（主工具失败→fallback 成功）、重规划（高优先级失败后计划被修正而非中断）、取消（工具调用中被取消）、ask_user 恢复/超时。

## 预期成果

- 预算、降级、重规划、取消、用户确认五类机制可用且可配置。
- 失败归因数据进入反思库，可供阶段 4 经验回灌使用。

## 评估标准

1. 新增测试覆盖上述 5 类机制的正/反场景（如：预算超限后不再发起 LLM 调用——用 mock 计数断言；fallback 链在 mock 主工具抛错时成功）。
2. 既有测试无回归；默认配置下（预算为极大值、降级为空、取消语义向后兼容）行为不破坏现有调用方。
3. `ask_user` 恢复后执行上下文包含用户答案（断言 context 值）。
4. 文档更新：`docs/zh/规划模块重构计划/规划模块理想设计.md` 的配置说明部分补充新增配置项。

## 回滚方式

预算/降级/重规划均为新增策略类，可在配置中关闭（`planning.budget.enabled=false`、`planner.replan_on_failure=false`）；取消与 ask_user 改动在 executor/react 中，可单独 revert。
