## 一、根因分析

ReActLoop 的 `config` 参数被保存但从未被读取：无 token/cost 预算、无 deadline（`timeout_seconds` 未实现）、无工具硬超时、无资源调度。慢工具或超长循环会无限消耗资源。

## 二、三义分析

- **【不易】** 预算边界：deadline / token / cost 三层预算必须被强制执行，超限即终止——预算不是建议而是约束。
- **【变易】** 预算超限行为需可配置：默认直接终止（向后兼容），可切换为"征求用户"暂停（与 D3 ask_user 同信号）。
- **【简易】** 在 ReActLoop 迭代入口做统一检查（单点收口），不散落各调用点。

## 三、修复方案（已落地）

### 3.1 配置项（[react.py L88-93](file:///c:/Users/Administrator/agent/planning/react.py#L88-L93)）

```python
self.deadline_seconds = self.config.get("timeout_seconds")     # deadline 预算
self.token_budget = self.config.get("token_budget")            # token 预算（估算）
self.cost_budget = self.config.get("cost_budget")              # 成本预算（token × 单价）
self.token_price = self.config.get("token_price_per_1k", 0.002)  # 每千 token 单价（USD）
self.tool_timeout = self.config.get("tool_timeout_seconds")    # 异步工具硬超时
self.budget_ask_user = self.config.get("budget_ask_user", False)  # 超限→征求用户
```

### 3.2 三层预算检查（迭代入口，[react.py L126-141](file:///c:/Users/Administrator/agent/planning/react.py#L126-L141)）

每轮迭代开始前依次检查 elapsed / token_used / cost，任一超限即调用 `_budget_result` 终止：

```python
elapsed = (datetime.now() - start_time).total_seconds()
if self.deadline_seconds is not None and elapsed >= self.deadline_seconds:
    return self._budget_result(f"超出时间预算({self.deadline_seconds}s)", steps, iteration, elapsed)
if self.token_budget is not None and self._token_used >= self.token_budget:
    return self._budget_result(f"超出token预算({self._token_used}/{self.token_budget})", ...)
if self.cost_budget is not None and self._cost >= self.cost_budget:
    return self._budget_result(f"超出成本预算(${self._cost:.4f}/{self.cost_budget})", ...)
```

### 3.3 token/cost 估算与可观测（[react.py L348-349](file:///c:/Users/Administrator/agent/planning/react.py#L348-L349)）

- 每次 LLM 调用后累计：`self._token_used += self._estimate_tokens(prompt) + self._estimate_tokens(response)`
- `_estimate_tokens` 为字符数/3 近似（中英混合通用），不依赖 LLM usage 结构。
- `self._cost = self._token_used / 1000 * self.token_price`
- `_result()` 统一透出 `token_used` / `cost` 到 `ReActResult`（[models/react.py L57-58](file:///c:/Users/Administrator/agent/planning/models/react.py#L57-L58)）。

### 3.4 异步工具硬超时（[react.py L388-408](file:///c:/Users/Administrator/agent/planning/react.py#L388-L408)）

```python
if asyncio.iscoroutinefunction(tool):
    if self.tool_timeout is not None:

    else:
        output = await tool(**params)
```

`TimeoutError` 捕获后返回 `failure_result("工具调用超时...")`，观测含超时信息。

### 3.5 预算超限行为分支（[react.py L542-565](file:///c:/Users/Administrator/agent/planning/react.py#L542-L565)）

```python
def _budget_result(self, detail, steps, iteration, elapsed):
    if self.budget_ask_user:
        # 降级为"征求用户"暂停——与 D3 ask_user 同一信号，由调用方展示预算详情
        return self._result(success=False, result=f"{detail}；等待用户确认（可提高预算后继续）",
                            steps=steps, iterations=iteration, duration_ms=elapsed * 1000,
                            error=f"等待用户输入：{detail}")
    return self._result(success=False, result=detail, steps=steps, iterations=iteration,
                        duration_ms=elapsed * 1000, error=detail)
```

## 四、边界与设计取舍

| 边界 | 处理 |
|------|------|
| 同步工具无法在事件循环内硬中断 | 由迭代级 deadline 预算兜底（同步工具单次调用后立即进入下轮检查） |
| token 估算非精确 | 字符/3 近似，不依赖 LLM usage 结构，兼容纯文本返回 |
| 预算超限默认行为 | `budget_ask_user` 默认 False → 直接终止（向后兼容）；置 True 才征求用户 |
| token/cost 字段向后兼容 | `ReActResult.token_used`/`cost` 默认 0，旧调用方无感知 |
