## 一、根因分析

任务失败即标记失败/高优先级即中断；无 Plan B、无降级链、无缓冲。`PlanExecutor.config` 支持配置但从未实现"降级链"（degrade chain），单点工具故障直接拖垮计划。

## 二、三义分析

- **【不易】** 降级语义：仅"主工具失败"触发降级链；主工具成功时备份工具绝不能被调用。
- **【变易】** 降级链按工具配置（`{主工具名: [备份工具列表]}`），可扩展多条备份；未注册备份应跳过而非抛错。
- **【简易】** 在任务执行路径内收敛（`_do_execute_task` 失败分支单点接链），不改动任务模型与重试语义。

### 3.3 降级链实现（[executor.py L382-412](file:///c:/Users/Administrator/agent/planning/executor.py#L382-L412)）

```python
async def _try_degrade_chain(self, action: Action) -> Optional[ActionResult]:
    backup_tools = self.degrade_chain.get(action.tool_name, [])
    if not backup_tools:
        return None
    for backup_name in backup_tools:
        if not self.tool_registry.has(backup_name):
            logger.warning(f"[D14降级链] 备份工具不存在，跳过: {backup_name}")
            continue
        backup_action = Action.tool_action(
            tool_name=backup_name, params=action.tool_params, description=action.description,
        )
        result = await self._execute_action(backup_action)
        if result.success:
            result.observation = f"主工具 {action.tool_name} 失败，已降级至备份工具 {backup_name} 执行成功"
            return result
        logger.warning(f"[D14降级链] 备份工具 {backup_name} 也失败: {result.error}")
    return None
```

## 四、分支语义（与复现测试一一对应）

| 分支 | 语义 | 测试用例 |
|------|------|----------|
| A | 主工具失败 → 备份成功 → 任务 completed，结果含备份输出 | `test_task_failure_uses_degrade_chain` |
| B | 主工具成功 → 备份绝不被调用（零触发） | `test_primary_success_skips_degrade_chain` |
| C | 多备份依次尝试：首个失败不中断，继续第二个 | `test_chain_tries_next_backup_after_failure` |
| D | 全部备份失败 → 任务 failed，错误保留主工具根因 | `test_all_backups_fail_keeps_primary_error` |
| E | 备份未注册 → 跳过该备份项（warning，不抛错） | `test_unknown_backup_tool_skipped` |
| F | 无 degrade_chain 配置 → 行为与修复前一致（零回退） | `test_no_degrade_chain_config_behavior_unchanged` |

## 五、边界与设计取舍

| 边界 | 处理 |
|------|------|
| 降级成功后重试语义 | 备份成功即返回成功结果，不再触发外层重试（重试仅针对全部链失败） |
| 备份工具参数 | 复用主工具参数（`action.tool_params` 原样传递） |
| 全部备份失败 | 保留主工具错误抛 `RecoverableError`，进入既有重试/失败路径 |
| 无配置兼容 | `degrade_chain` 为空字典 → `_try_degrade_chain` 立即返回 None，行为零变化 |
