- **【不易】** 契约边界：`planning.enabled` 必须读自配置（不硬编码）；原 `agent/task_planner/` 对外 API 保持可导入（薄壳重导出）；`find_tool` 匹配策略向后兼容（英文精确匹配优先）。

- **【简易】** 各缺陷收敛在单点：判定收敛 `_needs_planning`、接入收敛 lifecycle_manager、收口收敛 import 层、匹配收敛关键词表。

### 3.1 D6：复杂度分数 + 可配阈值（[core.py L312-335](file:///c:/Users/Administrator/agent/planning/core.py#L312-L335)）

```python
complex_count = sum(1 for i in complex_indicators if i in message)   # 复杂指示器数
action_count = sum(1 for k in action_keywords if k in message.lower())  # 动作关键词数
threshold = self.config.get("complexity_threshold", 1.0)   # D6：阈值参与判定
score = complex_count + action_count * 0.5
needs = score >= threshold
```
