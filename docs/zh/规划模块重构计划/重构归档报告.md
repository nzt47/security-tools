## 四、不变量守卫复核

1. **公开 API 契约**：`plan/execute_plan/chat/cancel_plan/get_plan_status/ask_user/resume_plan`、`ToolRegistry`、`ReActLoop.run` 签名未变——orchestrator、lifecycle_manager 调用方零改动；
2. **数据模型序列化**：`ExecutionRecord/Plan/Task/ReActStep/ChatResult.to_dict()` 全部"新增追加、不删不换"（`Task` 增 `fallback_actions`、`ChatResult` 增 `plan_summary`），既有断言键全部保留；
3. **默认配置行为**：`budget.enabled` / `replan_on_failure` / `metrics.enabled` 均有默认值且可配置关闭，未显式开启时行为与重构前一致；
4. **配置优先级**：`PLANNING_ENABLED` 环境变量 > `planning.enabled`（阶段 5 灰度回滚开关，已验证）。
