## 二、修复方案落地

### D13：三层预算 + 硬超时 + 征求用户分支

- **实现位置**：[react.py](file:///c:/Users/Administrator/agent/planning/react.py)（配置解析 L88-93 / 迭代入口检查 L126-141 / token 估算 L348-349 / 工具硬超时 L388-408 / 预算结果分支 L542-565）
- **deadline 预算**：`config["timeout_seconds"]`，每轮迭代入口按 elapsed 检查，超限即终止
- **token 预算**：`config["token_budget"]`，字符/3 近似估算累计（不依赖 LLM usage 结构）
- **成本预算**：`config["cost_budget"]` + `token_price_per_1k`，`cost = token_used/1000 × 单价`
- **工具硬超时**：`config["tool_timeout_seconds"]`，异步工具经 `asyncio.wait_for` 包裹，`TimeoutError` 转为工具失败
- **征求用户分支**：`budget_ask_user=True` 时预算超限降级为"等待用户输入"（与 D3 同一暂停信号）；默认 False 保持向后兼容直接终止
- **可观测**：`ReActResult` 新增 `token_used`/`cost` 字段（默认 0，兼容旧调用方）

### D14：降级链（Plan B）

- **实现位置**：[executor.py](file:///c:/Users/Administrator/agent/planning/executor.py)（配置解析 L150-152 / 失败分支接入 L369-380 / `_try_degrade_chain` L382-412）
- **配置**：`config["degrade_chain"] = {"主工具名": ["备份工具1", "备份工具2", ...]}`
- **语义**：仅主工具失败触发；逐个尝试备份，任一成功即返回（observation 标注降级来源）；全部失败保留主工具根因错误进入既有重试路径；备份未注册跳过不抛错；无配置时行为零变化
- **分支覆盖**：A 主失败→备份成功；B 主成功→备份零调用；C 多备份依次尝试；D 全败保留主错误；E 未注册备份跳过；F 无配置不变
