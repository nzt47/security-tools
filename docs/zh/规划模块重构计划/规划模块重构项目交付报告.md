| D5 取消竞态（状态滞留 RUNNING） | gather 统一收尾 | `_execute_task_with_retry_and_record` 每任务独立执行+立即标记 |
| D9 检查点残留污染测试 | 默认目录恢复历史残留 | `planning.persist_dir` 独立配置 + 测试 tmp 隔离 |
| D4 一步 finish 无中间步骤 | mock_llm 直接 finish 时 steps 为空 | 补充 `react_finish` 边界记录 |
| D18 取消覆盖状态 | CANCELLED 被终态覆盖 | `_finalize_state` CANCELLED 保留（边界 #2/#3/#6 闭环） |
| git diff 工具缓存假警报 | 工具缓存与磁盘不一致 | Python 直读磁盘验证落盘 |
