### 3.1 D15：`Plan.summarize()` 用户可读摘要（[plan.py L118-131](file:///c:/Users/Administrator/agent/planning/models/plan.py#L118-L131)）

```python
def summarize(self) -> str:
    """用户可读结构化摘要：目标/状态/进度/任务清单（D15 修复）"""
    status = "待执行" if self.state == PlanState.READY else \
             "执行中" if self.state == PlanState.EXECUTING else \
             "已完成" if self.state == PlanState.COMPLETED else "已结束"
    done = sum(1 for t in self.tasks if t.status == TaskStatus.COMPLETED)
    lines = [f"目标: {self.original_task}",
             f"状态: {status}（{done}/{len(self.tasks)} 任务完成）"]
    for t in self.tasks:
        lines.append(f"  - [{t.status.name}] {t.description}")
    return "\n".join(lines)
```

- 与 `to_dict()`（L101，开发向结构化数据）互补，面向用户展示。
- 复现测试断言：存在 `summarize` 方法且输出包含目标/状态/进度。

## 四、边界与设计取舍

| 边界 | 处理 |
|------|------|
| 摘要含任务详情行数 | 全量任务清单（计划规模小），不截断 |
| 成功率除零 | `total_plans == 0` 时 `success_rate` 返回 0.0 |
| 经验查询失败 | 捕获异常降级为无经验，仅 warning，不阻塞 ReAct 循环 |
| 成本指标未接入真实计费 | `total_cost` 预留为 0.0，后续接入 LLM usage 单价仅需改埋点处 |
