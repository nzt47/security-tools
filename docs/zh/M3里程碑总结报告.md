## 3. ChromaDB 问题排查进展

### 3.1 现象

`chromadb-preflight` job 的「构建预检镜像」步骤持续失败（容器化预检，阻断后续单测矩阵）。

### 3.2 根因（已定位）

```
ERROR: "/tests/unit": not found
ERROR: "/tests/conftest.py": not found
```

**CI 构建上下文中缺失 `tests/` 目录**（Dockerfile `COPY tests/...` 源不存在）。

### 3.3 排除的假设

| 假设 | 结论 |
|---|---|
| `.dockerignore` 排除 tests | ❌ 已核对，未排除 |
| 分支 git 中 tests 缺失 | ❌ `git ls-tree` 确认存在 |
| checkout 特殊配置（sparse 等） | ❌ 标准 `actions/checkout@v6` |
| 本地复现 | 无法验证（本机 Docker daemon 未运行） |

### 3.4 处置措施（本轮新增）

已在 ci.yml `chromadb-preflight` job 的 build 前新增**诊断步骤**：打印 workspace 根目录、`tests/`、`tests/unit/` 内容、git 跟踪状态与 `.dockerignore`——供下一轮 run 直接定位 checkout/上下文异常。

### 3.5 待办

- 观察下一轮 CI run 的诊断输出，确认 tests/ 在 runner 上的实际状态
- 若确认 runner 环境问题：联系 CI 基础设施维护方；或临时改为 Dockerfile 兼容（不依赖 tests/ 拷贝）
