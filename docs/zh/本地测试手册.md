# 云枢本地测试手册

> 目标：本地一键验证 —— 服务就绪检查、CI test 模拟（PowerShell / bash 双版本）、开放接口、SMTP 告警链路。
> 部署/启动相关见 `docs/zh/本地部署手册.md`；生产部署详见 `docs/zh/部署操作手册_20260816.md`。

## 一、一键验证清单

```bash
# 1) 服务就绪检查（端口 5678 健康 + 容器日志启动标志）
bash scripts/dev/check_service_ready.sh --container yunshu-t8-gateway
#    参数：--port / --container <名> / --timeout

# 2) 模拟 CI/CD test 步骤（路由挂载自检 + A/B 单测）
#    PowerShell（Windows 原生）
powershell -ExecutionPolicy Bypass -File scripts/dev/run_ci_test_local.ps1 -Quick
#    bash（跨平台）
bash scripts/dev/run_ci_test_local.sh --quick

# 3) 开放接口实测（需先建 Key）
python scripts/examples/open_api_client.py --user-id demo@example.com \
  --base-url http://127.0.0.1:5678

# 4) 告警邮件端到端（捕获服务器链路，7 断言）
python scripts/test_smtp_alarm_e2e.py
```

## 二、check_service_ready.sh（服务就绪）

| 参数 | 说明 |
|---|---|
| `--port` | 服务端口（默认 5678） |
| `--container <名>` | 同时检查容器日志启动标志（`docker logs`） |
| `--timeout` | 健康轮询超时（默认 60s） |

健康探测：curl 优先 + python urllib 回退（沙盒/Git Bash 网络隔离场景）。

## 三、run_ci_test_local（本地模拟 CI test）

执行：`check_mounted_routes.py`（5/5 自检）+ pytest 单测。

| 版本 | 用途 | 参数 |
|---|---|---|
| `scripts/dev/run_ci_test_local.ps1` | Windows 原生 | `-Quick`（仅审计告警）、`-Python <解释器>` |
| `scripts/dev/run_ci_test_local.sh` | bash / Linux / macOS / Git Bash | `--quick`、`--python <解释器>` |

单测覆盖：
- `tests/unit/test_audit_alert_analyze.py`（14 项）：告警导入/查询/阈值解析/超阈值触发 + SMTP 发送逻辑
- `tests/unit/test_open_api_endpoints.py`（37 项）：8 个开放端点鉴权（401/403/200）

> 提示：`pytest.ini` 引用了 `pytest-timeout` 插件，请确保解释器已装（`pip install -e ".[dev]"`）。
> Windows 下 `py` launcher 可能解析到另一解释器（缺插件），脚本已按 `python` 优先探测。

## 五、常见单测失败原因速查表

| 失败现象 | 根因 | 处理 |
|---|---|---|
| `error: unrecognized arguments: --timeout=60` | 缺 `pytest-timeout` 插件（pytest.ini addopts 引用） | `pip install -e ".[dev]"` |
| SSH 认证失败 `Permission denied`（密钥权限） | 私钥权限过宽（非 600），ssh 拒绝使用 | Linux/Git Bash：`chmod 600 <key>`；Windows：`icacls <key> /inheritance:r /grant:r "$($env:USERNAME):R"`；或用 `diagnose_ssh.ps1 -Target <ip> -User <user> -Key <key>` 定位 |
| `ModuleNotFoundError: No module named 'pytest'` | 解释器未装 pytest（如 Git Bash 自带 python3） | 用项目解释器：`-Python <路径>` / `--python <路径>` |
| py launcher 解析到另一解释器（缺插件） | Windows `py` 默认版本与开发环境不一致 | 脚本已按 `python → py → python3` 探测；仍异常时 `-Python <路径>` 显式指定 |
| 断言中文失败（Subject/正文） | MIME RFC2047 base64 编码（`Header`/`MIMEText`） | 断言前解码：`decode_header` / `get_payload(decode=True)`（参考 test_audit_alert_analyze.py） |
| `ImportError: No module named 'agent'/'scripts'` | sys.path 未含项目根 | 从项目根运行 pytest（`rootdir` 一致）；conftest 已兜底 |
| `UnicodeEncodeError`（GBK 控制台） | Windows 控制台编码非 UTF-8 | `python -X utf8 -m pytest ...` 或 `PYTHONIOENCODING=utf-8` |
| 用例间状态泄漏（网关单例污染） | `get_api_gateway()` 单例跨用例共享 | fixture 内 `mock.patch("agent.api_gateway_flask.get_api_gateway")` 返回独立实例 / 清 `_endpoints` |
| `test_open_api_endpoints.py` 过慢 | 每个用例重建网关（register_gateway 扫描路由） | 单独跑该文件或 `-Quick` 跳过；CI 中独立 job |
| 单测连不上本机服务（沙盒） | 沙盒/Git Bash 网络隔离 | 脚本已加 python urllib 回退；真机无此限制 |
| 127.0.0.1 本机诊断：DNS PASS → ping FAIL → TCP 22 FAIL | 本机未运行 sshd；本机 ICMP 常被禁 | 属预期场景：诊断在 2/3 层即定位，无需认证层；本地完整演练认证层：`python scripts/dev/mock_ssh_server.py --port 2222` + `bash scripts/dev/diagnose_ssh.sh --host 127.0.0.1 --port 2222 --user demo --key <临时key>`（banner 层需 SSH-2.0 前缀，见运维排错指南 §一） |
| 沙盒隔离导致层 3/4 失败：`bash scripts/dev/diagnose_ssh.sh` 连本机 Mock 端口报 TCP FAIL，但 `python -c "socket.create_connection(...)"` 能连通 | 沙盒对 bash 子进程的 `/dev/tcp` 网络隔离（bash 起子进程走隔离网络；原生 ssh.exe / python socket 不受限） | 换 PS 版验证：`powershell -File scripts/dev/diagnose_ssh.ps1 -Target 127.0.0.1 -Port 2222 ...`（TcpClient 不走 bash /dev/tcp）；真实 Git Bash/真机无此限制 |
