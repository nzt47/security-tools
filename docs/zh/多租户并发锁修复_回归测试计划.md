| # | 不变式 | 守护方式 |

## 2. 测试分层

### L1 — 单线程业务语义等价（首要守护）

- 文件: `tests/test_multi_tenant.py`（unittest，3 类管理器 10 用例）
- 覆盖: create_user / create_organization / create_workspace / assign_role / has_permission / set_and_get_config / config_inheritance / record_usage / check_limit / get_plan_info
- 基线: **10 passed in 0.59s**（2026-08-13 实测）
- 命令: `python -m pytest tests/test_multi_tenant.py -o log_cli=false -q`

### L2 — 并发安全（不退化）

- 文件: `tests/unit/test_multi_tenant_concurrency.py`（5 用例）
- 覆盖: 100 线程×50 角色分配无重复 / 并发创建计数精确 / 20 线程递归删除不崩溃 / 100 线程×50 用量计数精确 / 100 线程配置 set/get/delete 一致
- 基线: **5 passed** × 3 次独立运行（1.40s / 1.63s / 1.49s）
- 命令: `python -m pytest tests/unit/test_multi_tenant_concurrency.py -o log_cli=false -q`（建议连续 3 次）

### L3 — 锁开销性能回归

- 基准: `RLock` 单次 acquire/release **0.22µs**（100 万次共 215.6ms，本机实测）
- 阈值: 单次锁开销 < 0.5µs；10k QPS 场景锁总开销 < 5ms/s
- 命令:
  ```powershell
  python -c "import threading,time; l=threading.RLock(); N=1000000; t0=time.perf_counter(); [ (l.acquire(), l.release()) for _ in range(N) ]; dt=time.perf_counter()-t0; print(dt/N*1e6)"
  ```

### L4 — 调用方集成冒烟

- 多租户 HTTP 路由层（若存在 `server_routes` 中引用 multi_tenant 的用例）：`pytest tests/ -k multi_tenant -q`
- 全部调用方单测: 全量回归时 `tests/unit` 无新增失败
