## 关键覆盖场景

- **降级铁律**：LLM 不可用（`None`）/ 异常 / 完全超时（`TimeoutError`）/ JSON 解析失败，四种情形均降级为骨架产物（`distilled=False + reason`），绝不向调用方抛异常；仅使用错误（笔记/素材不存在）抛 `FileNotFoundError`/`ValueError`。
- **超时极端场景**：模拟 LLM 挂起 60s 后客户端中断，`except Exception` 兜底验证降级链完整。
- **人机边界**：冲突只标记不裁决；骨架/未确认笔记拒绝产卡；产卡恒 draft 待人工 transition。
- **敏感护栏**：PII 素材标记 `sensitive=true`，提炼跳过，正文不进 processed/。
- **幂等与只读**：入库幂等命中零副作用；层内素材 sha256 只读校验。
