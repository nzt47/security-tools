## 2. 打 Tag

```bash
# 在 yunshu-ui 目录（实际 git 根为仓库根 C:/Users/Administrator/agent）
cd C:/Users/Administrator/agent

# 1. 提交全部发布相关变更（CHANGELOG / 配置 / 脚本 / 文档）
git add CHANGELOG.md yunshu-ui/package.json yunshu-ui/scripts/ docs/wiki/云枢版本发布记录.md docs/zh/
git commit -m "release: yunshu-ui v0.1.2 安装包体积优化至 78.61MB"

# 2. 打带注释的 tag（推荐 v0.1.2）
git tag -a v0.1.2 -m "云枢 v0.1.2：体积 98.6→78.61MB；afterPack 自动剔除+校验；新增体积报告脚本"

# 3. 推送 tag 到远端（触发 Release 工作流 / 供 GitHub Release 使用）
git push origin main
git push origin v0.1.2
```

> 命名约定：`v<major>.<minor>.<patch>`（与 CHANGELOG 版本一致）。若需覆盖错误 tag：`git tag -d v0.1.2 && git push origin :refs/tags/v0.1.2` 后重建（需谨慎，勿在已发布 tag 上操作）。

## 附录 A：Git Hook 防误删核心资源（安装说明）

场景：防止修改 `scripts/afterPack.mjs` 时误把已实测"不可删"文件（ffmpeg.dll / d3dcompiler_47.dll / elevate.exe）加入 DROP 剔除清单。

**安装（任选其一）：**

```bash
# 方式 A（推荐，仓库级共享）：将 hooks 目录指向脚本所在目录
git config core.hooksPath yunshu-ui/scripts/hooks

# 方式 B（仅本机）：复制到 .git/hooks（注意沙盒环境下 hooksPath 已被全局配置覆盖，优先方式 A）
cp yunshu-ui/scripts/hooks/pre-commit .git/hooks/pre-commit
```

**行为**：
- 仅当暂存区包含 `scripts/afterPack.mjs` 变更时触发；其余提交零开销放行；
- 触发后运行 `scripts/precommit-check.mjs`：解析 DROP 数组，若包含核心保留文件 → **阻止提交**并打印实测依据；
- 手动验证：`node yunshu-ui/scripts/precommit-check.mjs`（正常输出 ✅，误删输出 ❌ + exit 1）。

**相关文件**：
- 检查逻辑：[precommit-check.mjs](../../yunshu-ui/scripts/precommit-check.mjs)
- Hook 入口：[pre-commit](../../yunshu-ui/scripts/hooks/pre-commit)
- 实测依据：架构文档 8.2.2 / 《非核心资源清理分析.md》
