## 四、新增 API 网关（agent/api_gateway_flask.py）

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| GET | `/api/open/echo` | 网关探活 | 无需鉴权 |
| POST | `/api/open/keys` | 创建 API Key（仅返回一次明文） | 内部管理 |
| GET | `/api/open/keys` | 列出 Key（脱敏） | 内部管理 |
| GET | `/api/open/stats` | 网关运行统计 | 无需鉴权 |
| GET | `/api/docs` | Swagger 文档 | 无需鉴权 |

接入方式：中间层模式——`before_request` 仅拦截网关**显式注册**的端点（`gw._endpoints`），其余 `/api/open/*` 与全部 `/api/*` 走 Flask 原生路由。

## 五、鉴权差异：两套认证体系

| 维度 | 内部 API（/api/*） | 开放 API（/api/open/*） |
|---|---|---|
| 认证机制 | 单一共享令牌 `FLASK_API_TOKEN` | 每用户独立 API Key（64 位随机，可创建/删除/禁用） |
| 请求头 | `Authorization: Bearer <token>` 或 `X-API-Token: <token>` | `X-API-Key: <key>` 或 `Authorization: Api-Key <key>` |
| 校验方式 | `secrets.compare_digest` 恒定时间比较 | ApiKeyManager 查表 + 启用状态 |
| Scope 权限 | 无 | 支持（默认 read/write） |
| 限流 | 无 | RateLimiter 多级令牌桶（全局→接口→用户→并发） |
| 配额 | 无 | QuotaManager（按用户/类型/周期） |
| 访问日志 | `log_request` 装饰器 | AccessLogger（独立） |
| 适用场景 | 本地单机（127.0.0.1） | 对外开放 / 多租户 |

**设计原则**：双轨并存、互不干扰。内部 API 保持 `FLASK_API_TOKEN` 不变（【不易】），开放 API 走网关的 Key/Scope/限流/配额体系（【变易】）。未来如需迁移内部 API 到网关体系，可按端点逐批 `register_endpoint` 接入，无需一次性改造。
