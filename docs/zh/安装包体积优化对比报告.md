## 4. 配置与脚本（归档）

```jsonc
// package.json → build
{
  "afterPack": "scripts/afterPack.mjs",   // 打包后自动剔除冗余运行时文件
  "files": ["dist/**", "dist-electron/**", "package.json", "!node_modules/**"],
  "electronLanguages": ["zh-CN", "en-US"]
}
```

| `vk_swiftshader.dll` + `vulkan-1.dll` + `vk_swiftshader_icd.json` | ~6.1MB | 中（无 GPU 环境黑屏） | 待评估（见《v2瘦身可行性分析》） |
