## 四、实现期发现并修复的真实缺陷（2 项）

1. **副作用路径口径不一致 ⇒ 回放副作用层全例误判**（27/27 用例 `side_effects` 失败）：
   Windows 下 `os.path.join` 与相对段混用产生 `C:\ws\out/x.md`，而回放侧 `ReplayEnv._norm_path()`
   归一为 `C:/ws/out/x.md`。修复：采集侧统一正斜杠绝对路径（`real_capture._slash()`），
   补回归用例 `test_side_effect_paths_use_forward_slashes`。
2. **包属性被同名函数覆盖 ⇒ 导入语义静默改变**：`agent/digestion/__init__.py` 导出同名函数
   `switch_snapshot` 会把包属性从"子模块"变成"函数"，与其它套件**同会话**跑时 7 例失败、单独跑全过。
   修复：包级不导出该同名函数，并在 `__init__.py` 写明命名纪律（改动面注释留证）。
