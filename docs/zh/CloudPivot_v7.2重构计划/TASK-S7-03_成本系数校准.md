## 一、目标描述

S5-03 已把成本口径固定为**价格锚定系数**（`anchor_prices_cents` + `coefficient_table`，`calibrated=False`，版本 `price_anchor.v1`），并明确"待 L2 基线后校准"。**S5-02 已交付 L2 Core-50**，触发条件**已经满足**——本任务把口径从"按标价换算"升级为"**按实测换算**"（或至少给出实测与标价的偏差），使 UTC 断食、ROI 判断、审批衰减率建立在真实成本比上。

**关键概念**：价格锚定假设"模型 A 单价是 B 的 3 倍 ⇒ 成本是 3 倍"，但真实成本还取决于**重试次数、失败率、输出长度、缓存命中**。实测校准 = 用**同一批标准任务**（L2 Core-50）在多模型上实跑，量出**经验成本比**。

## 二、执行步骤

### 步骤 1：校准实验设计（先写方案再跑）
- 产出 `docs/zh/成本系数校准方案.md`：
  - 样本：**L2 Core-50**（S5-02 交付，含 212 判定条目；说明哪些可自动判定、哪些需代理判定）；
  - 变量：锚模型（`resolve_anchor_model()` 当前值）+ 参与校准的模型清单（建议 **2–4 个**：主力 + 1–2 个备选 + 本地模型（如可跑））；
  - 指标：每模型的 **总 token（in/out）/ 单位任务 token / 重试次数 / 成功率 / 正常化成本（cents）**；
  - 对照：与 `price_anchor` 系数逐项比对，给出**偏差率**；
  - 复校周期：建议季度（与 S5-03 文档一致）。
- **凭据前置检查**：确认可用模型凭证（`LLM_API_KEY` / `DEEPSEEK_API_KEY` 等）。**若无多模型凭证，走步骤 2 的降级路径并如实标注**。

### 步骤 2：执行校准（含诚实的降级路径）
- **路径 A（有凭证）**：脚本 `scripts/calibrate_cost_coefficients.py` —— 对 L2 Core-50 在每个参与模型上实跑，采集 `utc.record_cost()` 事件与 `UnifiedTraceStore` 的 cost 字段，汇总为每模型经验系数；
- **路径 B（无凭证，降级）**：**离线重放已有成本数据**（`data/events/` 中历史 `cost` 事件按模型分组）+ **允许人工导入外部实测数据**（CSV），产出"部分校准"；报告中**必须显式写明"未完成完整实测校准，结论置信度受限"**；
- 全程：**不得编造任何数字**；样本不足（<20 条/模型）时按 S5-02 口径**只披露不结论**。

### 步骤 3：系数计算与偏差分析
- 实测系数：`measured_coef(model) = 单位任务正常化成本(model) / 单位任务正常化成本(anchor)`；
- 与 `price_anchor` 对比：输出偏差表（模型 / 价格系数 / 实测系数 / 偏差率 / 样本量 / 置信度）；
- **异常识别**：若某模型实测显著高于标价（常见于高重试/高失败率），在报告中点名——这正是校准的价值。

### 步骤 4：落地（版本化，不改历史追溯）
- `utc.py::coefficient_table()` 支持**来源标注**：`source ∈ {price_anchor, measured}`，并按优先级返回（有实测用实测，否则回落价格）；
- 指标输出的 `calibration` 块升级为 **`calibrated=True` + 版本 `measured.v1` + 生效模型清单 + 校准日期**；
- **历史数据不追溯**：旧记录保留其原口径版本（可查），避免"改系数导致历史成本数字变化"；
- 文档：更新 `PERF_BUDGET_REBASED.md` / 成本口径说明，明确"哪些模型已实测、哪些仍是价格锚定"。

### 步骤 5：回归与归档
- 新增单测：系数计算（含样本不足 → 只披露）、来源优先级、版本标注、历史口径不追溯、降级路径（无凭证时如实标注）；
- 邻接回归：`tests/unit/test_utc*.py`、`test_acr_metrics.py`、`test_s5_03_cost_brake.py` 零回归；
- 撰写 `TASK-S7-03_验收报告.md`（含偏差表与置信度声明）。
