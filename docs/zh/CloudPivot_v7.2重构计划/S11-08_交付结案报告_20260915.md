### 2.2 根因（代码行级）

**共同机理**：夹具/断言里的日期是**写死的绝对值**，而产品的"今天"跟随真实时钟。
时钟整体回溯（−400）后，夹具日翻到"未来"，于是"只处理历史日、今日留在活动文件"的分支全部走反。
逐条落到行：

| 用例 | 夹具侧（绝对值） | 产品侧（跟随时钟） |
|---|---|---|
| 1 | `test_behavior_drift.py:194 _write_week_baseline(tmp_path, "2026-08-03", …)` | `sensor/novelty.py:196 week_key()` 取**运行期**本周；`sensor/behavior_sensor.py:1207` 按**周键字符串升序**列基线；`agent/learning/behavior_drift.py:132-133 previous=baselines[-2]; current=baselines[-1]` ⇒ −400 时夹具周 (`2026-08-03`) 排到当前周 (`2025-08-11`) **之后**，previous/current 颠倒 ⇒ 漂移度 `\|40-80\|/80 = 0.5` |
| 2 | `test_policy_support.py:157-158` 写 `"2026-01-01"/"2026-09-01"`；`:163 read(since_days=1)` | `agent/policy/decisions.py:1436-1441 cutoff = datetime.now().astimezone() - 1d` ⇒ −400 时两条记录都在"未来"，`since_days=1` 全命中 ⇒ 2 而非 0 |
| 3/4 | `test_retention_archive.py:335/336/436` 写 `"2026-09-10"/"2026-09-11"`、`retention_testkit.py:29 FIXED_TODAY="2026-09-13"` 作**注入时钟** | 温层走**真实**时钟：`agent/skills_mgmt/log_archiver.py:394 today = date.today().isoformat()`、`:434 if day is None or day >= today`（**注入时钟与真实时钟口径不一致**：注入侧钉死 2026-09-13，真实侧回溯到 2025-08-11）⇒ `moved=0`、分片不生成 |
| 5 | `test_skills_digest_assessor.py:423-424` 写 `"2026-08-31"/"2026-09-01"` | 同 3/4 的 `log_archiver.py:434` ⇒ `archived=0` |

**为什么 +400 不暴露**：夹具日仍在"过去"，相对关系不变（S11-07 §3.4 已实测）。

### 2.3 修法（逐条成对证据）

设计口径：**夹具日与"今天"同源**，且

* **调用期取值**（模块级 `X = date.today()` 会被守卫 `test_no_import_time_clock_constants` 拦下）；
* **每个用例内只取一次**（`today = today_str()` 后用纯函数 `days_before(today, n)` 派生其余日期，
  消灭"两次取时钟之间跨 00:00"的残余风险）；
* **相对间距逐条保持**（`−3 天 / −2 天 / 今日`、`−255 天`、`−13/−12 天`、`−255/−12/−104 天`）。

| # | 改法（相对间距 → 原绝对间距） | 改前崩溃 | 改后（−400） |
|---|---|---|---|
| 1 | `_write_prev_week_baseline()`：`week_key(date.today() - 7d)`（"上一周"） | `assert 0.5 == 1.0` | 通过 |
| 2 | `_relative_days(255, 12, 104)` 单次取时钟（原 2026-01-01 / 2026-09-01 / 2026-06-01，相对 2026-09-13 = 255/12/104 天前） | `assert 2 == 0` | 通过 |
| 3 | `today = today_str(); d3, d2 = days_before(today,3), days_before(today,2)`；断言改 `f"events-{d3}.jsonl"` | `assert 0 == 5` | 通过 |
| 4 | 同上（`d3 = days_ago(3)` 单次） | `assert False` | 通过 |
| 5 | `today_day = _date.today()` 一次；两条旧行 = `today-13 / today-12` | `assert 0 == 2` | 通过 |

### 4.2 盲区 #2：导入期取时钟 vs 运行期取时钟
