## 三、通用执行约定（与 S4/S5 一致）

```powershell
cd C:\Users\Administrator\agent
python scripts/dev/new_session_worktree.py create --id <s701..s706> --base master
# ⚠ --base 默认 develop，本项目在 master，必须显式指定；id 必须形如 s<数字>
```
- 主工作区禁令：✗ `git checkout <branch>`　✗ `git reset --hard`　✗ `git add -A`　✓ 只 `git add <具体文件>`
- 提交流程：worktree 内 add/commit → 回主工作区 `git merge <id>/main` → 双远端推送同点 → `cleanup <id>`
- 本地门禁：本任务相关套件 + 邻接回归 + **kwarg 扫描两条（`--path agent` 与 `--path tests`）** + `mypy` + `importlinter` + 真实提交场景 pre-commit + 跑完检查产物漂移
- 硬约束：不改既有公开接口行为；**一切自动化开关默认关闭**；覆盖率 ≥80%；可调参数走 `.env`/config 且非法值回退默认；**不得编造数字**（无实测一律标 ❓ 并给复测方案）
- 口径纪律（S5-02/S6-01 确立）：样本 <20 只披露不考核；数据源缺位记 `None`（**不以 0 冒充**）；每个数字带数据源与公式；**不可追溯的百分比禁止上屏**
- 回报格式：交付物清单 / 任务书 §四 验收逐条（含证据命令）/ 质量证据（单测数+覆盖率+邻接回归+CI 终态）/ 遗留（带归属与阻塞性）/ `00_总览` 更新 / 双远端 SHA

**S7 批次贯穿的两条新纪律**：
1. **"不自动落地"纪律**：S7-02 产出的一切修复**只到 PR/补丁**，严禁自动 push 远端或自动合并（延续 S3-03 的 PR 边界）。
2. **"不谎报开关"纪律**：S7-01 的 UI 必须显示**真实生效来源**；被 env 锁定的开关必须置灰并说明，不得让人以为"UI 改了就是改了"。
