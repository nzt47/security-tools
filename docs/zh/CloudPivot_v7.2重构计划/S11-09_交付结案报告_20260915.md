### 5.2 根因（代码行级）

**不是 conftest 的统计钩子**。`tests/conftest.py:942-954` 与 `tests/_date_shift_plugin.py:272-297` 两个 `pytest_terminal_summary` 都**只读取/打印**、不改 `stats`（且都不打印 xfailed/xpassed ⇒ 18482 是人工相加的）。真正决定计数的是 pytest 自身 `_pytest/terminal.py:800-806`：

```python
    def pytest_collectreport(self, report: CollectReport) -> None:
        if report.failed:
            self._add_stats("error", [report])
        elif report.skipped:
            self._add_stats("skipped", [report])   # ← 非用例条目也进 stats
        items = [x for x in report.result if isinstance(x, Item)]
        self._numcollected += len(items)           # ← 收集条目数只数 Item
```

- `tests/unit/test_query_pattern.py:31` 用 `pytest.skip(..., allow_module_level=True)`，在 **import 期**抛 `Skipped` ⇒ 该文件产生一条 **outcome=skipped 且 `result` 里没有任何 Item** 的 `CollectReport`。
- 于是：`stats["skipped"] += 1`（**+1**），而 `_numcollected += 0`（**+0**）。
- 结尾行合计走 `stats`（`terminal.py:1450-1467`），且 `reports.py:168` 的 `count_towards_summary` 对 `BaseReport` 恒 `True`、`CollectReport` 未覆写 ⇒ 该收集级 skip 被计入合计。

⇒ **合计 = 收集条目数 + 1**，差的**恰好 1**；且 `18482 - 1 = 18481` 与收集数**完全相等**，说明逐条 1:1，**没有用例丢失、也没有重复执行**。

**唯一性已证**：AST 扫描 `tests/**` 共 **612 个文件**，import 期会执行的模块级 skip **恰好 1 处**。已排除：xpass 双计（会 +4）、`--continue-on-collection-errors`（本套件 0 收集错误，`pytest.ini:35` 虽设置但无 error）、`pytest_generate_tests`（无）、rerun/subtests 插件（未安装）、日期平移插件（未设 `CP_DATE_SHIFT_*` ⇒ 惰性）。
