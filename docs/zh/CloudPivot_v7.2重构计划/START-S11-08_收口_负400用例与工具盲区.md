【根因（行级，主线已核实）】
  · tests/unit/retention_testkit.py:29  `FIXED_TODAY = "2026-09-13"`（**固定绝对日**），
    它在 L32-39 的 `fixed_clock()` 里被当作**注入时钟的 "now"**；
  · 同一批用例又用**固定绝对日**当历史数据：
    tests/unit/test_retention_archive.py 的 L125/126/128/335/336/373/382/436 写
    `write_events(root, "2026-09-10"/"2026-09-11", ...)`，并在 L145/146/352/443 用字面日期断言
    （含 `"events-2026-09-10.jsonl"` 这种**拼进文件名**的用法）；
    tests/unit/test_policy_support.py 的 L68/80/158/170 用 `"2026-09-11T10:00:00+08:00"` 等。
  · **机理**：平移只会移动**被测代码读到的"今天"**；夹具里的日期是**写死的绝对值**。
    −400 时被测代码的"今天"≈2025-08，而夹具数据是 2026-09 ⇒ 数据变成**未来日** ⇒
    保留/归档这类"只处理历史日、今日留在活动文件"的逻辑行为分叉 ⇒ 用例失败。
    （+400 方向不暴露，是因为"数据仍在过去"这一相对关系不变。）

【修法（按优先级）】
  (a) **首选：让夹具日期与"今天"同源**。在 `retention_testkit.py` 增加**调用期**取值的助手：
        def today_str() -> str: return date.today().isoformat()
        def days_ago(n: int) -> str: return (date.today() - timedelta(days=n)).isoformat()
      然后把夹具的绝对日改为相对推导：`"2026-09-10"` → `days_ago(3)`、`"2026-09-11"` → `days_ago(2)`、
      `FIXED_TODAY` → `today_str()`；**断言里的字面日期与拼接文件名同步改**（如
      `f"events-{days_ago(3)}.jsonl"`）。
      ⚠️ **必须调用期取值，不要在模块级算常量** —— 模块级 `X = date.today()` 是
        "导入期取时钟"，会引入**跨零点**问题（S11-07 §2.5 已实测踩过，并修了 5 个同类）。
      ⚠️ **每个用例内只取一次**（`today = today_str()` 后用 `today`），避免用例跨零点时前后不一致。
  (b) 备选：让被测代码**统一走注入时钟**（而不是真实 `date.today()`），这样夹具的绝对日就无需改动。
      属产品改动 ⇒ 报告里显式声明变更点/影响面，并证明"默认路径行为逐字不变"。
  ⚠️ **禁止**：把断言放宽（如改成 `in (...)`）或只把日期往后挪 —— 那都是掩盖。
  ⚠️ 注意 `"2026-09-10"` 与 `"2026-09-13"` 相差 3 天、`"2026-09-11"` 差 2 天，
    改相对时**必须保持原有相对间距**，否则会改变用例语义（例如"两天历史日 + 今日"）。
