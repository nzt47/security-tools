## 二、D1–D4 逐条修复证据

### D1 — 队列完整性

**改法**：`ManualReviewQueue` 增 `liveness()` / `unknown_cases()` / `stale_reasons()` / `mark_stale()` / `scan_after_regeneration()`；`enqueue()` 入队即校验（三道闸：存活 / 形状 / 已裁定）；`pending()`/`is_closed()` 排除失效项；`review_sheet()` 显式披露失效行与原因。

**关键设计**：`ManualReviewItem.case_version_at_enqueue` 记入队时判定集版本 ⇒ **机器判定**"重生成前的旧引用"，无需靠时间戳猜。"失效"定义为**不在现行判定集的有效用例中**（`active_cases()`），与评估口径一致。

**证据**：21 例单测 + 演示段 1/2（`D1_stale_marked=2`、`D1_records_kept=2`）。

### D2 — 适用性落地与取样过滤

**改法**：`EquivalenceCase` 增 `upstream_capabilities` / `capability_set_key` / `step_count_bucket` / `shape_key` / `multi_capability` / `weak_contract` / `applies_to_capability()` / `shape_notes()`；新增 `shape_applicable_cases()` / `shape_report()`；`ShadowRunner.run` 第 ④ 步按形状过滤后才抽样，并把排除清单与理由写进报告 `shape` 字段。

**判据（口径说明）**：以"**不同能力的个数**"为准，而非步数 —— 同能力的重复调用形状未变（实测修正了初版"步数>1"的过度约束）。

**能力名归一**：经 `normalize_capability_id()`（复用既有别名表）best-effort 对齐，修掉"工具名 `read_file` vs canonical `cp.builtin.read_file`"导致的 4 条 Seed 用例误排除。

**证据**：72 例单测（含形状过滤、别名归一、弱契约）+ 真实语料 64 → 4/60。

### D3 — 归组键结构维度

**改法**：`SameTaskKey` 增 `step_count_bucket` + `capability_set`（五维）；`intent_key` → `v2|cap=…|steps:…‖<文本归一>`；`cleaning` 增结构原子/边界档位/集合摘要/`restructure_task_key()`/`grouping_conflict_rate()`/`capability_declaration_gap()`；`service.pipeline` 失败集改用 `same_task_shape()` 形状配对。

**口径变更**（详见验收报告 §五）：文本维度**保留**（`text_key_of()` 可取回），`structural=False` 保留旧口径；`as_tuple()` 3 → 5 元、`as_str()` 追加两段。**如实同步更新 8 例既有断言并新增回归对照例**。

**证据**：72 例单测 + 真实语料冲突率 `0.0303 → 0.0000`、声明缺口 `0.9242`。

### D4 — 裁定留痕台账

**改法**：新增 `agent/digestion/resolutions.py`（`ResolutionRecord` / `ResolutionStore` / `apply_resolutions()` / `enrich_needs()` / `resolution_basis()` / `resolution_sheet()`）；`backfill.plan_backfill(resolutions=…)` → `collect_needs(resolutions=…)` 拆分"仍需处理 / 已裁定"；新增 `needs_markdown()`；`ManualReviewQueue.enqueue(resolutions=…)` 跳过已裁定；每次裁定写 `audit.record(action="resolution.record")`。

**"改内容 vs 改 trust 值"的落实**：登记清单**刻意不含 RK-5** —— 它因正文修订可被规则自动识别，登记它等于把**可自动识别**伪装成**人工豁免**（那才是放宽规则）。

**证据**：41 例单测 + 实测三重反证（空台账 6 条照报 / 仅 2 条 DC-2 则 4 条 PRV-5 照报 / 台账故障降级不过滤）+ 6/6 裁定值 vs 现值一致。
