## 四、实现期发现并修复的真实缺陷（7 项）

| # | 缺陷 | 若未发现会怎样 |
|---|---|---|
| 1 | `prior_artifacts=None` 被归一为 `()` | **未声明要素绕过 §3.9 准入闸门**（判定错误，非崩溃） |
| 2 | 凭据到期用墙上时钟、忽略注入 clock | 签发与到期不同源，TTL 到期不可测 |
| 3 | `authorized_capabilities` 未规范化 | 同一 capability 两种写法被判两条 → 合法工具被误拒 |
| 4 | `executor.py` 误删 `RawOutput` 导入 | LLM 执行器**全部错误路径** `NameError`（冷路径长期潜伏） |
| 5 | `lifecycle.py` 未导入 `Any` | 类型检查失败（注解为字符串，运行期不报，易漏网） |
| 6 | `credentials.age_seconds` 返回 Any | `no-any-return` 违反 |
| 7 | 回调审计 status 类型不符 | `arg-type` 违反 |

> 缺陷 1/2 属**语义级**（输出看起来正常但判定错），仅在穷举式与时钟注入用例下现形；缺陷 4 属**冷路径**潜伏。这条经验建议纳入后续同类任务的用例设计口径：**对「准入判定」逐要素穷举、对「时间语义」注入时钟、对「错误路径」显式覆盖**。
