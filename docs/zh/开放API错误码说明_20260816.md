# 开放 API 错误码说明（API Key 鉴权）

> 适用范围：T8 开放 API（`/api/open/*` + T8.4 灰度开放的 8 个内部只读端点）
> 鉴权链路：`X-API-Key` / `Authorization: Bearer <key>` → 网关认证 → scope 校验 → 限流 → 配额 → 分发
> 配套验证：`scripts/examples/open_api_client.py`（带日志调用）、`scripts/dev/run_open_api_mock_server.py`（本地 Mock）、`tests/unit/test_open_api_endpoints.py`（37 项单测）
> 生成日期：2026-08-16

## 一、错误码总览

| 状态码 | error 字段 | 触发场景 | 可恢复 |
|---|---|---|---|
| **400** | `缺少 user_id` | `POST /api/open/keys` 未传 `user_id` | 是（补参重试） |
| **401** | `Unauthorized` | 无 Key / Key 无效 / Key 已禁用（enabled=false） | 是（换有效 Key） |
| **403** | `Forbidden` | **Key 有效但 scope 不足（本档重点）** | 是（补 scope / 绑定角色） |
| **403** | `API Key 兼容期已过，请迁移至租户绑定 Key` | 旧 Key（未绑租户）`compat_until` 已过期 | 是（迁移至租户绑定 Key） |
| **404** | `Endpoint not found` | 请求路径未在网关注册 | 否（路径错误） |
| **429** | `Rate limit exceeded` | 五级限流命中（全局/接口/租户/用户/并发） | 是（等待令牌恢复） |
| **429** | `Quota exceeded` | 用户配额耗尽 | 是（下周期恢复/提额） |
| **429** | `Tenant quota exceeded` | 租户配额耗尽 | 是（下周期恢复/提额） |
| **500** | 异常消息 | handler 内部异常（网关兜底） | 视业务而定 |

> 成功语义：200 + 业务 JSON。灰度只读端点响应体由内部视图决定（如 `/api/audit/logs` 返回 `{ok, logs, count}`）。

## 二、403 Forbidden（scope 不足）—— 详细说明

### 2.1 触发链路（时序）

```
客户端: GET /api/audit/logs  headers={X-API-Key: <key>}
网关:   authenticate() ──► validate_key() ──► 命中 key_info ──► 通过
网关:   check_scopes(key_info, required=["read"])
        ├─ Key 绑定租户：tenant_manager.has_permission(user_id, tenant_id, READ)
        │    └─ 无权限（角色 viewer 无 READ 或角色未覆盖）──► 403
        └─ Key 未绑定租户（旧 Key）：all(s in key_info.scopes for s in ["read"])
             └─ key_info.scopes 缺 "read" ──► 403
返回:   {"error": "Forbidden", "status_code": 403}
```

### 2.2 两种 scope 判定逻辑（按 Key 是否绑定租户）

| Key 形态 | 判定依据 | 权限来源 |
|---|---|---|
| 绑定了 `tenant_id` | 角色权限表（RBAC） | `tenant_manager.has_permission(user_id, tenant_id, perm)`，支持租户链继承 |
| 未绑定租户（旧 Key） | 自带 `scopes` 白名单 | 创建/迁移时写入的 `scopes` 数组（默认 `["read","write"]`） |

scope → PermissionType 映射（代码 [api_gateway.py#L422-L425](../../agent/api_gateway.py#L422-L425)）：

| scope | PermissionType | 含义 |
|---|---|---|
| `read` | READ | 只读访问 |
| `write` | WRITE | 写入 |
| `delete` | DELETE | 删除 |
| `manage` | MANAGE | 管理 |
| `admin` | ADMIN | 管理员 |

角色权限矩阵（权威见 `docs/zh/T8RBAC权限矩阵_20260816.md`）：owner=5（全量）、admin=4、member=2、viewer=1。

> **关键事实**：当前 8 个灰度只读端点要求 `scope=read`，而**所有角色（owner/admin/member/viewer）均含 READ**——因此绑定租户的 Key 对只读端点天然放行。
> 403 的真实高发场景：
> 1. **未绑定租户的旧 Key 自带 scopes 缺 `read`**（如创建时传 `scopes=["write"]` 或历史数据只有 write）
> 2. **绑定租户但该用户在该租户下无任何角色**（`has_permission` 为 False）

### 2.3 实测返回体

```json
// 8 个灰度只读端点均要求 scope=read；Key 仅含 write 时：
HTTP/1.1 403 Forbidden
{"error": "Forbidden", "status_code": 403}
```

### 2.4 常见原因排查清单（对照检查）

- [ ] Key 是否绑定租户？（`GET /api/open/keys` 看 `tenant_id`）
  - 绑定了 → 检查该用户在该租户下的**角色**是否含 READ 权限（`tenant_manager.has_permission`）
  - 未绑定 → 检查 Key 自带 `scopes` 是否含 `read`（创建时未传 scopes 默认 `["read","write"]`）
- [ ] 调用的端点要求哪些 scope？（网关 `/api/docs` 或源码 `register_internal_endpoints` 的 `scopes=[scope]`）
- [ ] 是否复用了低权限角色 Key（如 member/viewer）访问只读端点？
- [ ] 403 响应是否实为"兼容期已过"（error 字段不同，见总览表）？

### 2.5 修复方法

```python
# 方式一：未绑定租户的旧 Key —— 创建时显式声明 scopes 含 read（或依赖默认）
requests.post(f"{base}/api/open/keys",
              json={"user_id": "u1", "scopes": ["read", "write"]})

# 方式二：绑定租户 + 角色（RBAC）—— 当前只读端点要求 read，viewer 即已含 READ
requests.post(f"{base}/api/open/keys",
              json={"user_id": "u1", "tenant_id": "t1", "role": "viewer"})
# 注：若该用户在某租户下没有任何角色，has_permission 返回 False → 403（需先分配角色）

# 方式三：检查既有 Key —— GET /api/open/keys 查看 scopes / tenant_id / role
requests.get(f"{base}/api/open/keys", params={"user_id": "u1"})
```

## 三、401 Unauthorized（补充）

| 子场景 | 表现 | 处理 |
|---|---|---|
| 未带 Key | 401 `Unauthorized` | 请求头加 `X-API-Key` 或 `Authorization: Bearer <key>` |
| Key 无效（拼写/未创建） | 401 | 重新创建；注意 Key 明文仅创建时返回一次 |
| Key 已禁用 | 401 | 重新创建 / 更新 `enabled` |
| 探活端点 `/api/open/echo` | **200**（auth_required=False，不需 Key） | 先探测网关存活，再排查 Key |

## 四、429 限流/配额（三种细分）

| error 字段 | 层级 | 排查 |
|---|---|---|
| `Rate limit exceeded` | 五级限流（全局→接口→租户→用户→并发） | 等待令牌补充（接口桶默认 10/s）；压测请用 `--http-stress` 场景 |
| `Quota exceeded` | 用户配额（默认 10000/日） | 下周期恢复或提额 |
| `Tenant quota exceeded` | 租户配额 | 下周期恢复或提额 |
