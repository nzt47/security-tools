# 云枢 · v3（78.61MB）完整回归测试清单

> 目标：验证体积优化后的 v3 安装包（78.61MB，已剔除 LICENSES/dxcompiler/dxil/vk 三件套，保留 ffmpeg/d3dcompiler/elevate）功能无回归。
> 重点：**流式对话、独立窗口同步、启动速度** 是否受优化影响。
> 环境：Windows x64 · 后端 Flask 127.0.0.1:5678 · CDP 端口 9222 · 安装目录 `yunshu-app-test`
> 日期：2026-08-16

- 安装包：`release/云枢 Setup 0.1.0.exe`（**78.61MB**）；
- 产物构成：win-unpacked 251.5MB / 16 文件；app.asar 1.01MB（仅 main.js / preload.cjs / dist 渲染产物 / package.json，无遗留）；

## 6. 回归脚本速查

```bash
node scripts/cdp-verify.mjs ui      # UI 快照（模式/面板/按钮/electronAPI）
node scripts/cdp-verify.mjs detach  # detach 独立窗口（targets 1→2）

```

> 全部命令基于 `--remote-debugging-port=9222` 启动的安装版。若新增剔除项，必须重跑 1.x + 3.x（含 detach，见架构文档 8.2.2 教训）。
