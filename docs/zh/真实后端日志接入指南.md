> 目标读者：后端 + 前端开发
> 前提：系统日志导出最小落地版已闭环（权限判定 `usePermission` + 前端 CSV 导出，见「系统日志导出功能说明」）
> 更新：2026-08-21

## 接入总览

```
后端日志表/数据源
   → GET /api/system/logs（查询接口，带登录鉴权）
   → 前端 SystemLog.tsx 数据源替换（MOCK_LOGS → 接口）
   → 导出：前端导出当前页 或 后端导出接口（大数据量）
   → 权限：后端接口校验 system:log:export（PermissionManager）
```

## 步骤 3：导出方案选择

| 方案 | 适用 | 改动 |
|---|---|---|
| A. 前端导出已加载数据 | 数据量小（单页/已加载全量） | 导出逻辑不变，只替换数据源 |
| B. 后端导出接口 | 大数据量需导出全部 | 新增 `POST /api/system/log/export` 返回 CSV 流；前端调接口拿 Blob 下载 |

## 步骤 4：权限校验（后端同源）

后端接口统一用 `PermissionManager.has_permission` 校验操作级权限码：

```python
# 全局实例已存在于 app_server：_permission_manager
# 导出接口内：
user = _get_user_by_username(username)
if not _permission_manager.has_permission(user, "system:log:export"):
    return jsonify({"code": 403, "data": None, "message": "无导出权限"})
```

前端按钮显隐由 `usePermission('system:log:export')` 控制（已实现），前后端权限码契约一致。
