## 3. 归因与机制解释

- **ffmpeg.dll 为何不可删**：虽然本应用无音视频功能，但 Electron 发行版的 `ffmpeg.dll` 是 Chromium 渲染管线的一部分（Electron 对 Chromium 的 ffmpeg 做了 API 兼容层，删除后渲染进程初始化/页面脚本执行异常）。实测表现为"进程在但页面不渲染"——比启动崩溃更隐蔽，回归时**不能只查进程是否存在**，必须验证页面 title/DOM。
- **vk 三件套为何可删**：`vk_swiftshader.dll` 是 Vulkan 软件渲染兜底（无 GPU 时才加载），`vulkan-1.dll` 是 Vulkan 加载器。本应用渲染走 ANGLE（libEGL/libGLESv2，保留）+ D3D11，实测环境有 GPU 可用，故删除后渲染不受影响。

## 4. 风险与边界（【不易】约束）

| 风险项 | 说明 | 缓解 |
|---|---|---|
| **无 GPU / 远程桌面环境** | vk_swiftshader 是软渲染最后兜底，若目标用户含此类环境，删除可能黑屏/白屏 | 已按实测保留在 afterPack DROP 中，但注释标明；若确认目标环境均含 GPU 可放心启用 |
| **Electron 版本升级** | ffmpeg 依赖是当前 43.4.0 的实测结论，升级大版本后须重新回归 | 已写入 afterPack 注释 |
| **误删 ffmpeg** | 已在 afterPack 中**显式排除**，并以注释警示 | 删除清单与排除项分开管理 |
