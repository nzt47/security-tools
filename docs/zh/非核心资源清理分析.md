# 云枢 · 非核心资源清理分析（目标 75MB 以内的可行性）

> 目标：在 v3（78.61MB）基础上继续清理非核心资源（字体/图片/语言包/DLL），评估能否压到 **75MB 以内**。
> 方法：逐项实测（删除 → CDP 验证 → 恢复），拒绝静态猜测。
> 日期：2026-08-16 · 基线：yunshu-ui 0.1.0（Electron 43.4.0）· v3 安装包 78.61MB

## 1. 结论摘要

**75MB 以内不可达（工程极限约 78.6MB）**。原因：安装包大头（~88MB 压缩前，215MB 主二进制）是 Chromium 运行时固定开销，运行时侧全部可动项已实测剔除完毕；应用侧 app.asar 仅 1MB 无可压空间。

| 清理项 | 大小 | 结论 | 实测证据 |
|---|---|---|---|
| `d3dcompiler_47.dll` | 4.52MB | ❌ **不可删** | 删除后主窗口正常，但 **detach 独立窗口崩溃 → 进程退出**（新渲染进程 shader 编译依赖） |
| `elevate.exe` | 0.10MB | ❌ **不可删** | 与 d3dcompiler 一并实测，同场景独立窗口崩溃 |
| `ffmpeg.dll` | 2.93MB | ❌ 不可删（上一轮已证） | 删除后渲染进程异常 |
| 字体/图片 | 0 | 无（app 无自定义字体/大图） | asar 内仅 favicon.svg(0.4KB) |
| 未使用语言包 | 0 | 已精简 | locales 仅 zh-CN/en-US（各 ~0.55MB） |
| `storage-test.html/js` | 9KB | ✅ **已清理** | public/ 遗留测试文件，删除后不进 dist |
| `preload.mjs` | 0.6KB | ✅ **已清理** | 旧产物（当前构建只产 preload.cjs） |
| NSIS `compression: maximum` | 0 | **无收益** | v4 实测安装包仍 78.61MB（PE 二进制 LZMA 压缩率已饱和） |

## 2. 逐项实测记录

### 2.1 d3dcompiler_47.dll + elevate.exe（本轮新增实测，均不可删）

在 v3 安装目录删除两者后：

| 检查项 | 结果 |
|---|---|
| 启动 + UI 快照 | ✅ 桌面模式 / 4 面板 / electronAPI 齐全（主窗口正常） |
| 主窗口 SSE 流式对话 | ✅ 正常出流 |
| detach 独立窗口 | ❌ targets 1→2 后 **进程退出（ECONNREFUSED）**，独立窗口渲染进程崩溃 |
| 恢复后复测 | ✅ 全部恢复正常 |

**归因**：`d3dcompiler_47.dll` 是 D3D 11 shader 编译 DLL，主窗口可能复用已缓存的 shader，但 **detach 创建的新渲染进程需要现场编译 → 崩溃**。elevate.exe 与 NSIS 安装器提权相关，一并保留。

> 教训【不易】：**单窗口正常 ≠ 多窗口正常**。Electron 面板分离架构依赖新渲染进程，任何 DLL 剔除必须做 detach 回归，仅验主窗口会漏判。

### 2.2 应用侧遗留文件（已清理，收益小但属正确性清理）

- `public/storage-test.html/js`：历史联调遗留，被 Vite 原样复制进 dist → 进 asar。已删除源文件 + `files` 白名单加 `!dist/storage-test.*` 双保险；
- `dist-electron/preload.mjs`：vite-plugin-electron 旧产物（当前只产出 `preload.cjs`）。已删除 + `files` 加 `!dist-electron/preload.mjs`；
- 确认 v4 asar 内仅含 `main.js` / `preload.cjs` / dist 渲染产物 / package.json，无冗余。

### 2.3 compression: maximum（无收益）

v4 打包（含 maximum 压缩 + 遗留清理）安装包实测仍 **78.61MB**——与 v3 完全一致。原因：215MB 的 `云枢.exe`（PE 二进制）在 LZMA normal 档已接近压缩上限，提高档位不再带来收益。

## 3. 剩余体积构成（不可压缩部分）

| 文件 | 解压大小 | 为何不可动 |
|---|---|---|
| `云枢.exe` | 215.1MB | Chromium+V8+Node 合并二进制（固定） |
| `icudtl.dat` | 10.4MB | ICU 国际化数据（必需） |
| `libGLESv2.dll` / `libEGL.dll` | 8.1MB | ANGLE 渲染层（必需） |
| `resources.pak` | 6.9MB | Chromium 内置资源（必需） |
| `d3dcompiler_47.dll` | 4.5MB | 独立窗口 shader 编译（本轮实测必需） |
| `ffmpeg.dll` | 2.9MB | 渲染管线依赖（上轮实测必需） |

**安装包 78.61MB ≈ Chromium 运行时压缩后（~77.5MB）+ app.asar（~1MB）**。要低于 75MB 只有两条路，均不可行：
1. 裁剪 Chromium 二进制 → Electron 官方无精简发行版，自维护编译链收益为负；
2. 缩小运行时依赖 → 已全部实测排除。
