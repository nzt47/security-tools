## v0.1.2（2026-08-16）· 安装包体积优化发布

### 版本信息

| 项 | 值 |
|---|---|
| 版本 | 0.1.2（v4 产物） |
| 安装包 | `release/云枢 Setup 0.1.0.exe` |
| **最终体积** | **78.61MB**（优化前 98.6MB，-20.3%） |
| app.asar | 1.01MB（优化前 64.9MB，-98.4%） |
| win-unpacked | 251.5MB / 16 文件 |
| 发布方式 | 见《发布部署操作手册》 |

### 本版变更摘要

1. **体积优化链路**：排除 node_modules + 关闭 sourcemap + 精简语言包（98.6→91.5MB）→ afterPack 剔除 6 个冗余运行时文件（91.5→80.14MB）→ 追加剔除 vk 三件套（80.14→78.61MB）。
2. **afterPack 自动化**：`scripts/afterPack.mjs` 固化剔除 + 校验；`scripts/report-volume.mjs` 打包后自动生成体积报告（`release/volume-report.md`）。
3. **遗留清理**：删除 `public/storage-test.*`，`build.files` 排除 `preload.mjs` 旧产物。

### 保留文件清单（【不易】边界，实测勿删）

| 文件 | 大小 | 保留原因（安装版实测） |
|---|---|---|
| `ffmpeg.dll` | 2.93MB | 删除后渲染进程异常（页面 title 空、DOM 无响应）——是 Chromium 渲染管线依赖，非纯音视频解码 |
| `d3dcompiler_47.dll` | 4.52MB | 删除后主窗口正常但 **detach 独立窗口崩溃→进程退出**（新渲染进程需现场编译 shader） |
| `elevate.exe` | 0.10MB | NSIS 提权助手，与 d3dcompiler 同场景实测 |

### 75MB 目标不可达结论（实测数据）

- 安装包 78.6MB ≈ **Chromium 运行时压缩后（~77.5MB）** + app.asar（~1MB）；
- 运行时侧可动项（LICENSES/dxcompiler/dxil/vk 三件套 = 6 项）已全部实测剔除完毕，其余为渲染必需；
- `compression: maximum` 实测**无收益**（PE 二进制 LZMA 压缩率已饱和，78.61→78.61MB）；
- **低于 75MB 需裁剪 Chromium 二进制**（Electron 无官方精简发行版，自行维护编译链收益为负）→ **当前 78.61MB 视为工程极限**。

### 回归验证

- 安装版 CDP 实测：启动（~10s，与优化前持平）、四面板渲染、preload 注入、detach 独立窗口、SSE 流式对话、跨窗口同步全部通过；
- 单元测试：`CodeEditorPanel.test.tsx` 4/4 通过；
- 归档：详见 [发布前最终检查清单](../zh/发布前最终检查清单.md) 与 [v3回归测试清单](../zh/v3回归测试清单.md)。
