# 四套 UI 调色板 · 语义命名表（2026-11-21）

> Owner 2026-11-21 决定：把 §11.184 集中的四套调色板从「角色/色阶名」改成**语义名**。
> 纯改名 —— **颜色值逐字不变**、规则仍然只写 `var()`、语义 token `--wb-*` 一个都不动。
> 命名空间前缀保留（`--wbp` / `--pl` / `--dc` / `--ve`），因为它们是四个独立主题作用域，
> 也让颜色等价性量具可以按前缀还原：`.local/verify_palette_equiv.py`（声明级，漂移 0）。

## 命名规则

| 家族 | 语义名（每主题可用的后缀） | 含义 |
|---|---|---|
| 画布/表面 | `canvas` / `canvas-raised` / `canvas-sunken` / `surface` / `surface-sunken` / `overlay` / `scrim` | 页面底色 → 浮层 → 更深的凹槽，按「离用户多远」分层 |
| 文字 | `text-primary` / `text-strong` / `text-secondary` / `text-muted` / `text-faint` / `text-heading` / `text-contrast` | 正文 → 强调 → 次级 → 弱化；heading 只给标题 |
| 边框 | `border` / `border-strong` | 常规分隔 / 强调分隔 |
| 品牌与强调 | `accent` / `accent-alt` / `accent-text` / `accent-contrast` / `accent-strong` / `brand-text` / `brand-glow` | 主强调色与它的可读文本色 |
| 状态 | `success` / `success-text` / `danger` / `danger-text` / `warning` / `warning-text` / `warning-strong` | 成功 / 失败 / 警示；带 -text 的是同色系的可读文本 |
| 语义面 | `tool-accent` / `tool-accent-text` / `token-accent` / `token-accent-text` / `branch-true` / `branch-false` / `node-*` | 工具步骤、令牌、分支与节点这类业务含义的强调 |
| 其它 | `shadow` / `shadow-40` / `shadow-50` / `mask` / `surface-contrast` | 阴影、遮罩、纯白/纯黑这类特殊值 |
