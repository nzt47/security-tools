# 技能转化器（Skill Transformer）设计草案

> 2026-11-01 · Owner 口径：
> 1. 转化器要对**外来技能**做去重/合并/优化/合规安全审核；
> 2. 新技能要与**自身已有能力**对比，**只提取不重复的部分**；
> 3. 技能加载要**分层、按需渐进**；
> 4. **取外来技能的内涵，重写成自身的能力，原技能不再需要**。
>
> 本文是方案，不是已实现代码；P0 前置（入轨一条龙）已上线。

## 0. 一句话

外来技能是**素材**，不是资产。转化器把它的**内涵**（能力语义：什么时候用、怎么做、要什么参数、什么算做完）
抽出来，与**自身已有能力**比对去重，**用自己的表述重写成云枢的能力**；源技能归档留痕后**退出检索与能力清单**。

```
外来技能（一次性素材）
   │  抽内涵 ── 不是「复制原文」，是「读懂它想让你做什么」
   ▼
能力语义（触发 / 步骤 / 参数 / 示例 / 约束 / 验收）
   │  与自身能力比对 ── 只留不重复的部分
   ▼
重写为自身能力（云枢的术语、结构、示例、验收）＋ 并入或新建
   │
   ▼
源技能归档（raw + hash + absorbed_into），不再参与召回 / 不进能力清单
```

## 1. 为什么必须「重写」而不是「入职 / 引用」

| 做法 | 后果 |
|---|---|
| 原文直接入库（现状） | 46 条里 15 条 pd-* 互相抢召回；gstack 48.5 KB、gh-cli 39.9 KB 一次塞满上下文 |
| 原文入库 + 新技能引用原文 | 两份内容长期共存，改一处忘一处；递归引用让加载层数不可控 |
| **重写成本体、原文归档** | 只有**一份**事实源（我们自己的能力卡）；原文可追溯但不参与召回 |

判据：**转化完成后，源技能目录不再出现在 skills_repo 的检索面里**（只在 data/ingestion/transforms/ 留档）。

## 2. 流水线

| 段 | 做什么 | 关键约束 |
|---|---|---|
| **S0 采集** | claude / trae / zip / URL / git → artifact（原文 + 来源 + sha256） | 同 hash 幂等 |
| **S1 解析** | 切出「内涵」：触发面 / 步骤面 / 参数面 / 示例面 / 约束与验收 | 切不出来（纯目录、纯链接）→ 判「无内涵」退回 |
| **S2 对比** | 与**自身能力**逐面对比（见 §2.1），算出「新在哪」 | 只保留新增/更优的部分 |
| **S3 重写** | 用云枢的结构与术语**重写成能力卡**（L1）与全文（L2），示例改成可跑的最小例子 | 每条都能指回原文锚点（防编造）；不保留原文段落 |
| **S4 审核** | 许可、凭据/PII、危险指令、外部脚本、内容政策 | 规则 + 证据行号；block 不需要人 |
| **S5 能力化** | 并入既有能力或新建技能 → 入轨 PR（复用 intake_one/open_pr） | H-3 两条 409；源技能归档并标 absorbed_into |

### 2.1 S2 对比：与「自身能力」比，逐面判

自身能力先按同一套切法建索引（一次性落 data 目录，不新增服务）：

| 面 | 比什么 | 判重 |
|---|---|---|
| **触发面** | 何时使用 / 触发条件 / 适用场景 | 关键词 + 语义向量 |
| **步骤面** | 操作序列（归一化：动词+对象） | 集合 Jaccard + 顺序 LCS |
| **参数面** | 输入/配置/开关 | 名称+类型集合 |
| **示例面** | 命令/代码块 | 归一化后哈希 |
| **约束面** | 边界、反例、验收判据 | 关键词 + 语义 |

四种结论：

| 结论 | 条件 | 动作 |
|---|---|---|
| **duplicate** | 各面都 ≥0.85 | 不新建；只把更新/更好的示例与参数补进既有能力（记 overlay） |
| **incremental** | 部分面低相似 | **只重写低相似面**，并入既有能力的新小节（记 absorbed_into） |
| **conflict** | 同一面相似但内容相反 | 交人：并排 diff 选 merge / keep / variant |
| **distinct** | 各面都低 | 重写成新能力 |

## 3. 分层加载（按需渐进）

| 层 | 内容 | 体量 | 何时加载 | 来源 |
|---|---|---|---|---|
| **L0 摘要** | name + description + summary（≤60 字）+ tags | 常驻索引 | 检索/列表 | front matter |
| **L1 能力卡** | CARD.md：触发 / 步骤骨架 / 参数 / 一个可跑示例 / 验收 | ≤150 行 | 命中且要执行 | 转化产物 |
| **L2 全文** | skill.md 正文（含细节、反例、长说明） | 不定 | L1 不够用时显式展开 | skill.md |
| **L3 资源** | scripts/、引用文档、外部命令 | 按需 | 真执行 | 目录/路径 |

- **预算闸**：L0 200 / L1 2k / L2 20k / L3 单文件 8k token，超了截断并标 truncated；
- **可观测**：台账记 layer + 字节数，用于回收「从没被读到 L2 的能力」；
- **降级兼容**：没有 CARD.md 的老技能，L1 = 前 N 行 + 标题骨架（不建新文件也能分层）。

## 4. 数据模型

```
data/ingestion/transforms/<transform_id>/
  manifest.json     # 源、sha256、S1 内涵、S2 对比结论、absorbed_into/overlay、审核结论、时间线
  raw.md            # 原文归档（不进 git、不进检索）
  compare.json      # 逐面分数、判定、新增清单
  card.md           # 重写后的能力卡（L1）
  full.md           # 重写后的全文（L2 候选）
  review.json       # 审核发现（rule/file/line/evidence/verdict）
  diff.patch        # 并入既有能力的补丁（若有）
```

- 幂等键 = sha256(raw)；
- 审计：skill.transform.plan / .apply / .rollback（带 transform_id）；
- 回滚：反向补丁 + 审计；原文在 raw.md，可重放。

## 5. 人工决策点（只三处）

1. **conflict**（同面相反）——并排 diff 选 merge / keep / variant；
2. **审核 warn**（block 自动停）；
3. **入轨 PR 合并**（CI 绿也由人点）。

## 6. 接口

```bash
python scripts/skill_transform.py --plan  <artifact>          # 只读：解析内涵 + 对比 + 审核 + 卡片草案
python scripts/skill_transform.py --apply <artifact> [--into <id>] [--pr]
```

| API | 用途 |
|---|---|
| POST /api/skills-mgmt/transform/plan | 只读分析（compare / review / card） |
| POST /api/skills-mgmt/transform/apply | 重写落盘 + 能力化（可选开 PR） |
| GET  /api/skills-mgmt/transform/status | 队列与逐阶段进度 |
| POST /api/skills-mgmt/transform/<id>/rollback | 回滚 |

UI：吞噬页「转化队列」——左对比结论（按面分色）、右审核发现、下重写后的卡片与并入 diff。

## 8. 分阶段

| 阶段 | 内容 | 判据 |
|---|---|---|
| **P0 已上线** | 入轨一条龙 | #1388 |
| **P1** | --plan 只读：内涵切分 + 逐面对比 + 审核 + 卡片草案 | pd-* 15 条聚 1 组并给逐面分数；gh-cli 给出 ≤150 行卡片草案；假危险技能 block 且给行号；跑完 git status 为空 |
| **P2** | --apply：重写落盘 + 并入/新建 + 可选开 PR | 同 hash 幂等；源技能标 absorbed_into 且退出检索面 |
| **P3** | 分层加载（CARD.md + 预算闸 + 台账 layer） | 老技能无卡片也能只加载 L1 |
| **P4** | UI 转化队列 + 回滚 | 回滚后 git diff 为空、审计有 rollback |
| **P5** | LLM 参与重写（严格引用校验） | 每条指回原文锚点，引用不符即降级 |

## 9. 风险与反例

1. **重写 ≠ 改写措辞**：必须保住内涵（做事的因果与判据），否则能力退化成空话；
2. **别让 LLM 决定能不能进**：审核用规则 + 证据；
3. **别把大文件塞进 git**：raw.md 留在 transforms/；
4. **别自动合并同面冲突**：相似度只排序，不判决；
5. **别绕过 H-3**；
6. **别让分层变成藏内容**：每层都要可显式展开，截断必须标出来。
