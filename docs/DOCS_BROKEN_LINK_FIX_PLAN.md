# 文档链接预检失效链接修复方案（独立 PR）

## 问题

「文档链接预检与锚点回归测试」check 失败，本地 `scripts/dev/check_docs_broken_links.ps1` 复现：

```
失效链接(host)                           目标                建议
云枢系统前端可视化与干预方案_20260816.md  docs/zh/红/二次确认  删除引用或补建目标文档
```

该失效链接存在于 **master 分支预存文档**（非任何 PR 引入），触发 PR checks 失败。

## 根因

`docs/zh/云枢系统前端可视化与干预方案_20260816.md` 第 268 行附近存在一条相对链接：

```markdown
[紧急停止](红/二次确认)
```

- `precheck_docs.ps1` 用正则 `\[([^\]]+)\]\(([^)]+)\)` 提取链接，相对路径按**文档所在目录**（`docs/zh/`）解析 → 完整目标 `docs/zh/红/二次确认`
- 该目标目录/文档**不存在**（`docs/zh/红/` 目录不存在）
- 上下文（第 163/268 行）显示"红色二次确认"是**功能描述文本**（高危动作二次确认弹窗），此链接疑似误加，无对应目标文档

## 修复方案（推荐：删除失效链接）

将失效链接改为纯文本，保留语义（链接无实际目标，纯文本更准确）：

```diff
- 4. 紧急停止操作触发[紧急停止](红/二次确认)，`reason` 必填，操作写入日志审计可查；
+ 4. 紧急停止操作触发**红色二次确认**，`reason` 必填，操作写入日志审计可查；
```

若该链接本意是跳转到 UI 规范文档，可改为指向仓库内已存在的相关文档（需确认目标），例如 `docs/UI_COMPONENT_SPEC.md` 或 `docs/zh/可视化界面完整展示.md`。**推荐先删除**（语义已在正文描述，链接无增益）。

## 验证

1. 修改后本地运行：`pwsh -NoProfile -File scripts/dev/check_docs_broken_links.ps1` → 0 个失效链接。
2. push 触发「文档链接预检与锚点回归测试」→ success。
