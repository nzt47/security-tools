### 1.2 "哪些文件真的读 config.yaml" 是怎么机械求出来的（关键步骤）

用 AST（不是正则）求三类证据的并集：

1. **路径构造**：任何 `BinOp(Div)`、`open(...)` 实参、字符串常量里含 `config.yaml` 的表达式；
2. **YAML 解析调用**：仅认**真 yaml 模块别名**上的 `safe_load / load / full_load / safe_load_all`；
   （**不能用** `ast.Attribute.attr in {"load"}` —— 那会把 `json.load(f)` 全部误收，
   本审计第一版就踩了这个坑：候选从 61 个虚高到 154 个）
3. **同文件 import 了已知 config 读取助手**（`read_config_yaml` / `_config_lookup` / `config_yaml_path`）。

`@python
# 可复跑：python find_cfg_readers.py（在仓库根执行）
import ast
from pathlib import Path
REPO = Path(r'<repo>')
YAML_LOAD_ATTRS = {"safe_load","load","full_load","safe_load_all","load_all","unsafe_load"}

for p in sorted((REPO/'agent').rglob('*.py')):
    try: tree = ast.parse(p.read_text(encoding='utf-8'))
    except Exception: continue
    alias = set()
    for n in ast.walk(tree):
        if isinstance(n, ast.Import):
            for a in n.names:
                if a.name == 'yaml': alias.add(a.asname or 'yaml')
        elif isinstance(n, ast.ImportFrom) and n.module and n.module.split('.')[-1] == 'yaml':
            for a in n.names: alias.add(a.asname or a.name)
    real_load = [n.lineno for n in ast.walk(tree)
                 if isinstance(n, ast.Call) and isinstance(n.func, ast.Attribute)
                 and n.func.attr in YAML_LOAD_ATTRS
                 and isinstance(n.func.value, ast.Name) and n.func.value.id in alias]
    cfg_path  = [n.lineno for n in ast.walk(tree)
                 if isinstance(n, ast.Constant) and isinstance(n.value, str)
                 and n.value.strip().endswith('config.yaml')]
    if cfg_path or real_load:
        print(p.relative_to(REPO).as_posix(), cfg_path, real_load)
`@

### 1.3 键 → 读取点的机械关联

用仓库自带的 AST 提取器，避免自己写第二套：

`@powershell
python scripts/scan_settings.py --json scan.json     # 622 文件；managed 名 417，读取点 458
`@

据此把每个登记键映射到**它的全部真实 env 读取点**；再把读取点所在模块 ∪ `owner_module`

61 个逐键人读后：**55 个 需补登记 + 6 个 正确**。
