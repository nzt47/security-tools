## 6. 本会话新增的方法学

1. **守卫的计数口径要把非调用形态排除**：第九批前端断言写成 `count("unwrapEnvelopeBody") >= 3`，
   把 **import 行**也算了进去 ⇒ 只回退 compress 仍绿；改成按调用形态 `unwrapEnvelopeBody<` 计数后立刻 1 红。
2. **PowerShell 后台编排器的返回值会被日志污染**：函数内 `Write-Output` 打日志 ⇒ 返回值变成
   「整串日志 + 状态」，`-eq 'GREEN'` 判假，于是在已 GREEN 时走了 STOP 分支。**日志不要走 stdout**。
3. **全局探针只应记录它声称记录的那一类调用**（`open` / `sleep` 两处实例）。
4. **生成物的 content_hash 只锁分类结论**，不锁「谁引用了它」的文件清单（否则任何无关编辑都假红）。
