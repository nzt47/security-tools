## 二、关键技术结论（都是实测，不是推断）

1. **模型侧几乎没有限制**：`GET /v1/models` 直答 `deepseek-flash` = DeepSeek-V4.1-Flash，
   `context_window=1048576`、`max_output_tokens=393216`；`max_tokens=200000` 的请求实测被接受。
2. **云枢侧原有五层口径互相打架**（pydantic 字段 / Config.DEFAULT / 字典校验器 / 修正器 / UI 副本），
   导致"把窗口调大"被**静默改回 4096**。已收口成模块常量 + 四处共用 + 回归锚。
3. **主 UI（工作台流式）此前根本不吃这些旋钮**：`max_tokens=2048` 写死、历史写死"最近 8 条"。
   现已统一到单一口径模块 `agent/chat_limits.py`。
4. **工作台此前不写全局记忆**：长期记忆/压缩/召回只反映另一半对话。现已在正常收尾时写入。
5. **四条"拟态"阶段事件已删除**（"知识检索 ✓"而实际没检索）：界面不再声称没发生过的事。
6. **`effort` 参数在 OpenAI 兼容面不生效**（三次均值无单调性）⇒ 明确不实现，避免又一个死旋钮。
