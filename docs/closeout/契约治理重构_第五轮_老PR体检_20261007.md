## 5. 一条可继承的方法学

**自动解冲突时绝不能用 `git add -u`**：本次第一遍自动循环里 `git add -u` 把仍带
`<<<<<<<` 标记的 `CHANGELOG.md`/`progress.md` 当作「已解决」暂存并提交，于是分支上留下了
**带冲突标记的提交**（实测 `git grep '^<<<<<<<' ` 命中，随后整段 rebase 重做）。
正确做法是**只对确认为「取 ours」的路径** `git add -- <path>`，并且**每次 continue 前重查
`git diff --diff-filter=U`**；一旦还剩未解决项就停下人工处理。
这是本仓「静默失效」家族的新成员：**坏结果以「continue 成功」的形式出现**。
