| 用例 | 定性 | 证据 |

| `test_vector_store_sqlite_vec`（4 例） | 🔴 **真实产品 bug** | vec0 的 KNN 约束写成 `ORDER BY distance LIMIT ?` 子查询，**依赖"LIMIT 被下推进 vec0"**：Windows 放行、CI 的 Linux 必报 `A LIMIT or 'k = ?' constraint is required`。实测 sqlite-vec `0.1.9/0.1.10a2/0.1.10a4` 在 Windows 上**都放行** ⇒ 与扩展版本无关，是平台查询计划器差异 |

**顺带揭开的静默失效（比上面 4 个用例本身更重要）**

② 失败时必须 ERROR 留痕、且日志写明"返回空列表=查询失败，非查无结果"。
