## 2. 核心成果（按价值排序）

### 2.1 战略判据达成：关掉 LLM 后能力层仍可用（TASK-05）

这是 v1.4 的**唯一战略判据**，也是本次重构最核心的目标。实测三条链路在 LLM 被完全关掉时都能工作：

| 链路 | 实测 |
|---|---|
| HTTP | `GET /capabilities/tools` → **200 / status=ok / total=114 / degraded=False** |
| HTTP 调用 | `POST /capabilities/invoke` → **200 / code=ok** |
| CLI | `cloudshu` 真实子进程 → **rc=0 / code=ok** |

**且 HTTP 与 CLI 的响应体逐字段一致**（唯一忽略 `meta.timing` 这一文档化的易变字段）。

**反假绿的证据**：该验证脚本**自带打桩自证** —— 打印「自证覆盖 10 个入口（全部必然失败）」，
证明"关掉 LLM"这个桩**真的生效**，而不是因为桩没装上所以看起来能过。

### 2.2 安全设施从"已建好但未接线"变为"默认生效"（TASK-07）

审计期实测三者**生产调用方均为 0**；现已全部接线且默认生效：

| 设施 | 接线位置 | 关键设计 |
|---|---|---|
| **SSRF 默认拒绝** | `agent/web/http_client.py` | **两道防线**：发请求前（语法 + IP 字面量 + DNS 后全 A 记录校验）+ patch `urllib3.create_connection`，在**地址已定、socket 未建**那一瞬校验实际要连的地址；重定向逐跳复检 |
| **注入隔离 + 污点账** | `agent/tools/__init__.py::call()`（唯一汇聚点） | 覆盖 91 工具 + 动态注册的 MCP 工具 |
| **沙箱统一收口** | `agent/tools/shell_tools.py::execute_shell()` | `validate_command` → `run_sandboxed`；三档 `CP_SANDBOX_SHELL_MODE`（`off`/`shadow`/**默认 shadow**/`enforce`） |

**两个关键取舍**（都吸收了前序任务的教训）：
1. **注入层放在 `tool_gate` 之前**，但**只出 deny、从不出 allow** ⇒ 不可能把旧层短路
   （TASK-06 恰好踩过"新层放行导致旧层判定不再执行"的坑）。
2. **受既有总开关约束**：`CP_GUARDRAILS_GUARD_TOOL ∧ CP_TOOL_GATE_ENABLED`
   ⇒ 直接吸取 TASK-06 最严重的教训（**新层不受总开关约束会导致回滚失效**）。

### 3.5 一次工作丢失事故（**最严重的执行事故**）

**事实**：TASK-09 首轮的 5 个测试文件（**208 KB / 368 用例 / 647 断言**）全部被抹掉。
它们是**未跟踪**的 ⇒ stash / index / 全盘 / 回收站 / `git fsck` **均无法恢复**。

**根因链**：`run_full_pytest.py` **在脏工作区会主动阻断**并提示"先提交或隔离到独立 worktree"
⇒ 子代理为了跑工具而清理未跟踪文件 ⇒ 抹掉另一子代理的在飞产出。

**解决方案（6 项）**：
1. **抢救备份**未跟踪文件（保住 TASK-04 的 45.8KB `location.py` + 99 文件 patch）
2. 终止失效的覆盖率测量并**标记产物无效**（防误引用）
3. **新增纪律 D15**：禁止 `git clean` / `checkout -- .` / `restore .` / `reset --hard` / 删他人文件 / 跑清理脚本
4. **`TASK-09` 顶部加事故通报**：重做时**每写完一个文件立刻 `git add`**
5. **建立独立 worktree**（`.worktrees/task09`）隔离产出 —— 已验证有效
6. 重做后**产出比首轮更好**：**485 用例**、覆盖率 **99%/99%/100%/100%/100%**

**新增纪律 D11~D16**（全部来自本会话的实际踩坑）：
D11 禁清空 `addopts`｜D12 夹具形状不得代替生产形状｜D13 pytest 串行且不误伤用户数据｜
**D14 禁裸 pytest 单进程跑全量**（实测退化到 7.5 分钟/1%）｜**D15 禁清理命令**｜D16 串行不约束小集合。
