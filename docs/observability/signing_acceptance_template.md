# 交付签署确认单（模板）

> **用途**：项目/功能交付的正式签署确认凭证。
> **使用说明**：复制本模板，填写「一、交付信息」与「二、验收范围」，
> 逐项勾选「三、确认清单」，由各方在「五、签署区」签字后归档。

| 项 | 内容 |
|----|------|
| 确认单编号 | `AC-YYYYMMDD-<序号>`（如 AC-20260628-001） |
| 关联交付 | （填写交付主题 / PR / 分支） |
| 生成日期 | （填写） |

## 三、确认清单

> 由验收方逐项勾选确认，未达标项须在「备注」说明。

- [ ] 交付物完整，与交付范围一致
- [ ] 功能符合预期，主流程 / 分支流程验证通过
- [ ] 测试覆盖达标，无已知未修复缺陷逃逸
- [ ] CI / CD 验证通过，无回归
- [ ] 文档（报告 / 使用说明）已更新归档
- [ ] 遗留问题已明确记录，责任人 / 期限已指定
- [ ] 代码已推送至指定仓库，与远程同步
