# E4-5 第六批：LiveShare（只读实时分享）设计 —— **待 Owner 拍板后实现**

> 2026-11-28。上游：`docs/plan/2026-11-24-dsh-parity-roadmap.md` §E4-5「LiveShare（可选）」。
> **本文只出方案，不改代码**：LiveShare 是 E4-5 里唯一会**改对外安全姿态**的一项（要么给未登录访问者一个
> 只读面，要么要求对方持有凭据），按本仓纪律属需 Owner 明确点头的范围。

## 1. 目标与不做

- 目标：把**某一个会话**的只读视图分享给另一个人/另一台设备（同一局域网或公网经反代），
  对方**不需要云枢账号**、**不能**发消息/改会话/看别的会话；分享方可随时撤销、可设过期。
- 不做：不做协同编辑、不做语音/终端共享、不做跨会话聚合、不分享工具原始输出与附件二进制、
  不分享系统提示词与内部思考（`steps` 默认不投影）。

## 2. 必须先定的三件事（Owner 拍板）

1. **对外安全姿态**：是否允许「持分享令牌即可读」而**不登录**？
   - 允许 ⇒ 需要在鉴权中间件里给 `/api/liveshare/*` 前缀开一个**极窄**白名单，路由内自己校验令牌（fail-closed）。
   - 不允许 ⇒ 分享只对已登录的其他账号生效（实现简单，但「发给外部的人」这个主要场景就没了）。
2. **分享什么**：整段对话（默认）还是仅从分享时刻起的**新消息**？（建议：整段只读快照 + 可跟随后续新消息）
3. **有效期**：建议默认 24h、上限 7d、可随时撤销；是否需要「一次性（阅后即焚）」？

## 3. 推荐方案（最小可行面，默认关）

| 维度 | 结论 |
|---|---|
| 令牌 | 32 字节随机（`secrets.token_urlsafe(32)`），**只存 sha256** 于 `data/liveshare/shares.json`（gitignore）；创建时明文只回一次 |
| 传输 | **轮询**（前端 2s 拉一次增量）；先不上 SSE/WebSocket（省长连接与背压复杂度，实时性 2s 足够） |
| 读面 | `GET /api/liveshare/<token>/messages?after=<seq>`：只回 `role/content/timestamp/seq`，正文每段截 2000 字符、单次最多 50 条；**不**回 steps/工具字段/附件路径 |
| 生命周期 | `POST /api/sessions/<sid>/share`（需登录）建分享；`DELETE /api/sessions/<sid>/share` 撤销该会话全部分享；`GET /api/sessions/<sid>/share` 看状态（不返令牌） |
| 开关 | `CP_LIVESHARE_ENABLED`（A 级、默认关，关时四条路由全部回 `disabled` 且**不读**分享文件） |
| 前端（实现时） | 工作台页头「分享」→ 生成链接 + 有效期 + 撤销；独立只读页 `/live/<token>`（新页面 ⇒ 需重派生 `ui_reachability` 与 `route_ui_coverage`） |
| 撤销/回滚 | 删除分享记录立即失效；整体回滚 = 关开关（页面回「未启用」） |

## 4. 安全边界（实现时必须逐条做到）

- 令牌**只在 URL 片段**（`#t=...`）出现，不落 Referer/日志；服务端日志只记 sha256 前 8 位。
- 一枚令牌**只对应一个会话**；会话被删 ⇒ 分享记录级联失效（读时二次校验会话存在）。
- 只读：所有 liveshare 路由只允许 `GET`；任何写动作 405。
- 过期/撤销/不存在一律回同一个 404（不区分原因，避免枚举）。
- 限流：单 IP 每分钟 ≤ 60 次；单令牌并发 ≤ 4。
- 不许分享「未归属会话」之外的东西：不接受客户端指定任意文件/任意 session id。
- 审计：建/撤销各记一条（只记 sid 摘要与操作者），**不记令牌**。

## 5. 判据（实现时的验收）

1. 开关关：四条路由 `disabled` 且不读 `shares.json`（用例断言）；
2. 建分享：回一次性明文令牌 + 过期时间；`shares.json` 里**没有明文**（只有 sha256）；
3. 读面：`after` 游标增量、字段白名单、截断上限、过期/撤销/错误令牌统一 404；
4. 级联：删除会话后旧令牌立即 404；
5. 只读：非 GET 405；限流生效；
6. 前端：分享/撤销/只读页（含「未启用」「已失效」两态）+ `ui:check` 绿 + 派生两份覆盖率产物；
7. 不新增工具；新 env 登记 registry；新路由同批有前端引用。

## 6. 分期

- **P1（本文建议的第一步）**：只读快照 + 轮询 + 24h + 撤销 + 默认关（不跟随新消息）。
- **P2**：跟随新消息（游标轮询已够，不需要 SSE）。
- **P3**：SSE/WebSocket、多人观看、水印/只读终端（都不在本批范围）。

## 7. 等 Owner 的三句话

1. 允许「持分享令牌即可读、免登录」吗？（不允许 ⇒ 本功能价值减半，建议不做）
2. 分享范围 = 整段对话 + 后续新消息？
3. 默认有效期 24h / 上限 7d / 可撤销，够不够？
## 8. 实施记录（2026-11-28，Owner 拍板后）

Owner 2026-11-28 答复：① **允许**免登录持令牌读；② 分享**整段对话 + 之后的新消息**；③ 有效期由实现方定
（本实现取：默认 **24h**、最小 5min、上限 **7d**、随时可整体撤销、记录保留 7 天后清理）。

### 8.1 最终口径

| 项 | 结论 |
|---|---|
| 鉴权 | `/api/liveshare/*` 进入鉴权中间件**默认豁免**（本机 `.env` 的 `CP_API_AUTH_ALLOW` 需同步补）；该前缀下**只有一条**公开 GET，路由内自校验令牌（fail-closed） |
| 令牌 | `secrets.token_urlsafe(32)`，一次性返回；盘上只存 **sha256**（`data/liveshare/shares.json`，gitignore）；日志只记 sha256 前 8 位 |
| 传输 | 浏览器 `#/live/<token>` 页面每 **2s 轮询** `GET /api/liveshare/messages?after=<seq>`（不用 SSE/WebSocket） |
| 读面投影 | 只回 `seq/role/content/chars/truncated/timestamp`；正文截 2000 字符、单页 ≤50 条 |
| 失效口径 | 令牌无效/过期/撤销/功能关/会话不存在 **统一 404 同形**，不给枚举信号 |
| 限流 | 单 IP 60 次/分钟（进程内滑动窗口，超限 429） |
| 开关 | `CP_LIVESHARE_ENABLED`（A 级、默认关）+ `CP_LIVESHARE_TTL_SECONDS`（默认 86400，300–604800） |

### 8.3 判据（已验）

1. 开关关：公开面 404（同形）、管理面 `disabled`，且不读分享文件；
2. 令牌只回一次、盘上无明文；TTL 夹取；过期/撤销立即失效；
3. 读面字段白名单（工具步骤与 tool_calls 不出现）、游标增量、正文截断；
4. 缺令牌/错令牌/会话被删/读失败各有稳定表现（404 同形 / 500 固定文案，不含异常原文）；
5. 限流 429；管理面状态不含令牌与摘要；
6. `npm run ui:check` 绿；两份覆盖率产物重派生。
