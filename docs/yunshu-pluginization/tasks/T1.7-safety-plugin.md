# 任务 T1.7：拆分 safety 插件（safety / permission / privacy / window-consent）

## 目标

把 `app_server.py` 中的安全/权限/隐私域路由迁移到 `plugins/safety.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2–T1.6、T1.8–T1.9 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 待迁移路由（以实际代码为准）

| 路径 | 方法 | 说明 |
|---|---|---|
| `/api/safety/check` | POST | 安全审查 |
| `/api/safety/alerts` | GET | 安全告警 |
| `/api/safety/keywords` | GET/POST | 安全关键词 |
| `/api/permission/status` | GET | 权限状态 |
| `/api/permission/log` | GET | 权限日志 |
| `/api/permission/stats` | GET | 权限统计 |
| `/api/permission/access-log` | GET | 访问日志 |
| `/api/permission/emergency` | POST | 紧急控制 |
| `/api/permission/toggle` | POST | 权限开关 |
| `/api/privacy/info` | GET | 隐私信息 |
| `/api/window/consent` | POST | 窗口采集同意 |

## 步骤

1. 创建 `plugins/safety.py`，模板同 T1.2。
2. 迁移上述路由函数体；安全/权限相关私有 helper 若只被本域使用，一并搬入（`_on_safety_alert` 等若被其他域引用则留在 app_server，函数内 import）。
3. 敏感过滤/告警单例函数内延迟 import。
4. 声明 `PLUGIN = register_plugin(Plugin(name="safety", version="1.0.0", description="安全、权限与隐私", blueprint=bp, routes=[...]))`。
5. `plugins/__init__.py` 追加 `from . import safety`。
6. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/permission/status`、`GET /api/privacy/info`、`GET /api/safety/alerts` 响应与迁移前一致（只读端点；POST 端点可跳过或只验证 4xx 行为一致）
- [ ] `GET /api/plugins` 含 safety 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- 安全域涉及**写操作**（emergency、toggle、consent），冒烟时勿触发真实危险动作；可用测试环境或只验证只读端点。
- 完成后 git 提交：`refactor(plugins): extract safety domain into plugins/safety.py`。
