# 任务 T1.6：拆分 admin 插件（config / auth / audit / network / system-prompt / llm / search）

## 目标

把 `app_server.py` 中的管理/配置域路由迁移到 `plugins/admin.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2–T1.5、T1.7–T1.9 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 待迁移路由（以实际代码为准）

| 路径 | 方法 | 说明 |
|---|---|---|
| `/api/config` | GET/POST | 全局配置 |
| `/api/config/logs` | GET | 配置日志 |
| `/api/auth/token-check` | GET | 令牌校验 |
| `/api/audit/logs` | GET | 审计日志 |
| `/api/network-config` | GET/POST | 网络配置 |
| `/api/network-config/reset` | POST | 重置网络配置 |
| `/api/network-config/export` | GET | 导出网络配置 |
| `/api/network-config/import` | POST | 导入网络配置 |
| `/api/apply-network-config` | POST | 应用网络配置 |
| `/api/system-prompt` | GET/POST | 系统提示词 |
| `/api/system-prompt/reset` | POST | 重置系统提示词 |
| `/api/llm/instances` | GET/POST | LLM 实例列表/新增 |
| `/api/llm/instances/<string:instance_id>` | GET/PUT/DELETE | LLM 实例详情/更新/删除 |
| `/api/llm/instances/<string:instance_id>/default` | POST | 设为默认 |
| `/api/llm/instances/<string:instance_id>/test` | POST | 测试实例 |

| `/api/search/instances/<string:instance_id>/test` | POST | 检索测试 |
| `/api/search-performance/status` | GET | 检索性能状态 |
| `/api/search-performance/start` | POST | 启动性能测试 |
| `/api/search-performance/stop` | POST | 停止性能测试 |
| `/api/search-performance/check` | POST | 性能检查 |
| `/api/search-performance/history` | GET | 性能历史 |
| `/api/search-performance/summary` | GET | 性能汇总 |

## 步骤

1. 创建 `plugins/admin.py`，模板同 T1.2。
2. 迁移上述路由函数体；`config.py` 中的配置单例在函数内延迟 import（本任务**不修改** `config.py` 本身）。
3. 若 `/api/config` 的 GET/POST 逻辑较长且被 `config.py` 或 `main.py` 引用，仅迁移路由层，业务函数留在原模块，函数内 import。
4. 声明 `PLUGIN = register_plugin(Plugin(name="admin", version="1.0.0", description="配置、认证、审计与模型实例管理", blueprint=bp, routes=[...]))`。
5. `plugins/__init__.py` 追加 `from . import admin`。
6. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/config`（需令牌则带 token）、`GET /api/auth/token-check`、`GET /api/system-prompt`、`GET /api/llm/instances` 响应与迁移前一致
- [ ] `GET /api/plugins` 含 admin 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- `/api/config` 涉及敏感配置，冒烟时**不要提交修改**（只 GET）。
- 带 `<string:instance_id>` 的路由 converter 写法保持原样。
- `require_token` 装饰器函数内 import 使用。
- 完成后 git 提交：`refactor(plugins): extract admin domain into plugins/admin.py`。
