# 任务 T1.9：拆分 system_tools 插件（workspace / filesystem / sandbox / browser / process / clipboard / web）

## 目标

把 `app_server.py` 中的系统工具域路由迁移到 `plugins/system_tools.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2–T1.8 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 步骤

1. 创建 `plugins/system_tools.py`，模板同 T1.2。
2. 迁移上述路由函数体；浏览器/进程/Web 工具单例（如 `browser_tools` 相关，注意 README 中「浏览器单例不迁移到 SingletonManager」的例外说明）在函数内延迟 import。
3. 声明 `PLUGIN = register_plugin(Plugin(name="system_tools", version="1.0.0", description="工作区、文件系统、沙箱与系统工具", blueprint=bp, routes=[...]))`。
4. `plugins/__init__.py` 追加 `from . import system_tools`。
5. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/workspace`、`GET /api/filesystem/list`、`GET /api/process/list`、`GET /api/web/stats` 响应与迁移前一致（只读端点；写/执行类端点只验证 4xx 或测试环境）
- [ ] `GET /api/plugins` 含 system_tools 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- 本域端点多涉及**真实系统操作**（写文件、起进程、浏览器自动化），冒烟严禁触发真实危险动作；只读端点优先，其余验证 4xx/权限拦截行为与迁移前一致。
- 完成后 git 提交：`refactor(plugins): extract system tools domain into plugins/system_tools.py`。
