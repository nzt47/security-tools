# 任务 T1.10：装配器收尾 + 全量回归（阶段 1 完成）

## 目标

完成阶段 1 的收尾工作：删除临时示例插件、核对路由全集、全量回归、确认 `/api/plugins` manifest 完整、验证前端不受影响。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（§7 完成标准）。
- 前置：T1.1–T1.9 全部完成。

## 步骤

1. **清理示例插件**：删除 `plugins/example.py`，移除 `app_server.py` / `plugins/__init__.py` 中对它的引用。
2. **核对 `plugins/__init__.py`**：应包含全部 8 个域插件（chat / memory / status / skills / admin / safety / mcp_scheduler / system_tools），无临时模块。
3. **核对路由全集**：
   - `Select-String -Path app_server.py -Pattern '@app\.route'`：剩余应仅为页面路由（`/`、`/chat`、`/legacy`、`/static/<path>`、`/mascot-test`、`/network-test`、`/search-status`、`/network-config-debug`、`/replay-viewer`）与测试路由（`/api/test/*`）、以及装配器新增的 `/api/plugins`。
   - 8 个插件文件的 `@bp.route` 路径与迁移前 `@app.route` 路径集合**完全一致**（可写一次性对比脚本，输出差异）。
4. **manifest 完整性**：启动服务，`GET /api/plugins` 应返回 8 个插件，每个含 name/version/description/schema(空或 dict)/routes。
5. **全量回归**：
   - `python -m pytest tests/ -x -q`（全量，仓库基线 12714 项）。
   - 前端：`cd yunshu-ui && npx tsc -b --noEmit && npx vitest run`（确认后端改动未破坏前端构建）。
   - 构建冒烟：`cd yunshu-ui && npm run build`。
6. **端到端冒烟**：启动 `app_server.py`，依次请求：`/api/health`、`/api/sensors`、`/api/status`、`/api/chat`（简单输入）、`/api/sessions`、`/api/skills`、`/api/config`（GET，只读）、`/api/plugins`，全部 200 且响应正常。
7. **瘦身确认**：`app_server.py` 行数较迁移前（213KB）显著下降（目标 ≤ 60KB）。

## 验收标准（阶段 1 完成标准）

- [ ] 8 个域插件全部注册，`plugins/` 目录无临时文件
- [ ] `app_server.py` 只保留页面/静态/测试路由 + `/api/plugins` + 装配逻辑
- [ ] 迁移前后路由路径集合完全一致（脚本核对无差异）
- [ ] `GET /api/plugins` manifest 完整正确
- [ ] 全量 pytest 通过；前端 `tsc`、`vitest`、`build` 全部通过
- [ ] 端到端冒烟全部 200
- [ ] `app_server.py` 瘦身达标

## 风险与注意事项

- 若全量 pytest 因**本任务无关**的历史失败（如 Windows 平台 C 扩展崩溃相关文件，README 中有记录），在提交说明中列出排除项与原因，不得静默跳过。
- 路由对比脚本建议一次性使用（可放 `scripts/` 或临时文件，不污染仓库）。
- 完成后 git 提交：`refactor(plugins): finalize backend pluginization (phase 1)`，并在提交说明中附回归摘要。
