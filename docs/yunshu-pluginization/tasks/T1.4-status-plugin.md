# 任务 T1.4：拆分 status 插件（health / sensors / status / heartbeat / personality / panorama / planning / cognitive）

## 目标

把 `app_server.py` 中的状态/感知/性格域路由迁移到 `plugins/status.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2/T1.3/T1.5–T1.9 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 待迁移路由（以实际代码为准）

| 路径 | 方法 | 说明 |
|---|---|---|
| `/api/health` | GET | 健康检查（注意：`health_bp` blueprint 可能已含 `/api/health`，**核对是否重复**，若 blueprint 已提供则本域不含它） |
| `/api/sensors` | GET | 传感器 |
| `/api/status` | GET | 系统状态 |
| `/api/mode` | GET | 模式 |
| `/api/planning/toggle` | POST | 规划开关 |
| `/api/cognitive/status` | GET | 认知状态 |
| `/api/heartbeat` | GET | 心跳 |
| `/api/heartbeat/history` | GET | 心跳历史 |
| `/api/heartbeat/status` | GET | 心跳状态 |
| `/api/panorama` | GET | 全景 |
| `/api/personality` | GET | 性格 |
| `/api/personality/params` | POST | 性格参数 |
| `/api/personality/profile` | POST | 性格画像 |
| `/api/personality/reset` | POST | 性格重置 |

> 核对 `/api/health`：`app_server.py` 第 129 行注册了 `health_bp`，但 825 行又有 `@app.route("/api/health")`。若二者并存，把 `@app.route` 版本迁入插件并确认无重复注册冲突；若 `health_bp` 已覆盖，则跳过该路径并在任务说明中记录。

## 步骤

1. 创建 `plugins/status.py`，模板同 T1.2。
2. 迁移上述路由函数体；`PersonalityManager` 等私有类若只被本域使用，一并搬入插件（函数内实例化或模块级初始化均可，只要不顶层 import app_server）。
3. 传感器/状态单例（`_init_window_sensor` 等）函数内延迟 import。
4. 声明 `PLUGIN = register_plugin(Plugin(name="status", version="1.0.0", description="系统状态、感知与性格", blueprint=bp, routes=[...]))`。
5. `plugins/__init__.py` 追加 `from . import status`。
6. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper/类。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/status`、`GET /api/sensors`、`GET /api/personality`、`GET /api/heartbeat` 响应与迁移前一致
- [ ] `GET /api/plugins` 含 status 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- 传感器域可能在 import 或首次调用时初始化硬件/系统 API（如 `_init_window_sensor`），冒烟前确认环境具备（Windows 下窗口传感器 API）。
- `PersonalityManager` 若被 chat 域引用，保留在 app_server 或放入共享层，两处函数内 import。
- 完成后 git 提交：`refactor(plugins): extract status domain into plugins/status.py`。
