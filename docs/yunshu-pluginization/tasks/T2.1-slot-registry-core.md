# 任务 T2.1：前端插槽注册表核心（slotRegistry + SlotHost + profile + 单测）

## 目标

为云枢前端建立插槽体系核心：`slotRegistry`（注册表）、`SlotHost`（渲染组件）、`profile`（配置驱动）、`SlotProvider`（注入）。**本任务不改造 App.tsx**，只建核心 + 单测。

## 背景

- 项目：云枢前端 `yunshu-ui/`（React 18 + TS + Vite + Tailwind + Zustand + vitest）。
- 方案：`docs/yunshu-pluginization/PLAN-2-frontend-slots.md`（先读，§2 有核心实现参考代码）。
- 现状：`App.tsx`（381 行）手写布局 + 布尔开关切面板；本任务不动它。

## 设计契约（必须满足）

1. 新建 `yunshu-ui/src/plugins/` 目录，包含：
   - `slotRegistry.ts` — 按 `PLAN-2` §2 的参考实现：`registerSlot` / `mountToSlot` / `unmountFromSlot` / `getSlotEntries` / `loadProfile` / `getProfile`，类型 `SlotEntry` / `SlotProfile`。
   - `SlotHost.tsx` — `<SlotHost slotId="..." className?/>`：读取该插槽条目（应用 profile 的 order/hidden），按序渲染；外层 `data-slot={slotId}`。
   - `SlotProvider.tsx` — 挂载时 `loadProfile(defaultProfile)`，`children` 透传。
   - `profile.json` — 初始 profile（见下）。
   - `index.ts` — 汇总导出。
2. `profile.json` 初始内容（占位，后续任务填充真实组件）：

```json
{
  "slots": {
    "topbar": [],
    "sidebar": [],
    "main": [],
    "panels": []
  }
}
```

3. 组件挂载示例（仅用于测试验证，写在测试文件里或一个 `demo.ts`，**不要挂进 App**）：

```ts
mountToSlot('sidebar', { id: 'demo', component: () => <div>demo</div>, order: 1 });
```

4. **单测**（vitest，`yunshu-ui/src/plugins/slotRegistry.test.ts`）覆盖：
   - `registerSlot` 幂等；`mountToSlot` 自动建插槽
   - `getSlotEntries` 按 order 排序、hidden 过滤
   - `loadProfile` 后 order/hidden 生效；无 profile 条目时用组件默认值
   - `unmountFromSlot` 摘除
   - `SlotHost` 渲染测试（`@testing-library/react`）：挂两个组件按序渲染；profile 隐藏后不渲染
   - TS 类型检查通过（`npx tsc -b --noEmit`）

## 步骤

1. 阅读 `PLAN-2` 与 `yunshu-ui/package.json`（确认 vitest 配置、`@testing-library/react` 已装）。
2. 创建 `src/plugins/` 下全部文件。
3. 编写并运行单测。
4. 若 tsconfig 未包含 `src/plugins`（应已包含整个 src），确认无需改动。

## 验收标准（Definition of Done）

- [ ] `cd yunshu-ui && npx tsc -b --noEmit` 通过
- [ ] `cd yunshu-ui && npx vitest run src/plugins` 全部通过
- [ ] `npm run dev` 启动无报错，页面行为与改造前一致（未接 App，理应一致）
- [ ] 提交信息：`feat(plugins): add frontend slot registry core`

## 风险与注意事项

- 不要修改任何现有组件/页面；本任务只新增文件。
- `SlotHost` 中 `getSlotEntries` 每次渲染都读取最新 profile，无需额外订阅机制（单人工具够用）。
- 完成后 git 提交。
