# 任务 T1.8：拆分 mcp_scheduler 插件（mcp / scheduler / schedules / tasks）

## 目标

把 `app_server.py` 中的 MCP 与调度域路由迁移到 `plugins/mcp_scheduler.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2–T1.7、T1.9 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 待迁移路由（以实际代码为准）

| 路径 | 方法 | 说明 |
|---|---|---|
| `/api/mcp/services` | GET/POST | MCP 服务列表/新增 |
| `/api/mcp/services/<string:service_id>` | GET/PUT/DELETE | MCP 服务详情/更新/删除 |
| `/api/mcp/enable` | POST | MCP 启用 |
| `/api/scheduler/tasks` | GET | 调度任务 |
| `/api/scheduler/create` | POST | 创建调度 |
| `/api/scheduler/delete` | POST | 删除调度 |
| `/api/scheduler/toggle` | POST | 调度开关 |
| `/api/scheduler/execute-now` | POST | 立即执行 |
| `/api/scheduler/history` | GET | 调度历史 |
| `/api/schedules` | GET/POST | 计划列表/新增 |
| `/api/schedules/<task_id>` | DELETE | 删除计划 |
| `/api/schedules/<task_id>/pause` | POST | 暂停 |
| `/api/schedules/<task_id>/resume` | POST | 恢复 |
| `/api/schedules/history` | GET | 计划历史 |
| `/api/tasks` | GET | 任务列表 |
| `/api/tasks/<task_id>` | GET | 任务详情 |
| `/api/tasks/<task_id>/cancel` | POST | 取消任务 |

## 步骤

1. 创建 `plugins/mcp_scheduler.py`，模板同 T1.2。
2. 迁移上述路由函数体；`<task_id>` / `<string:service_id>` converter 写法保持原样。
3. 调度器/MCP 执行器单例函数内延迟 import（如 `mcp_executor`、`task_scheduler`，与项目 SingletonManager 风格一致）。
4. 声明 `PLUGIN = register_plugin(Plugin(name="mcp_scheduler", version="1.0.0", description="MCP 服务与任务调度", blueprint=bp, routes=[...]))`。
5. `plugins/__init__.py` 追加 `from . import mcp_scheduler`。
6. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/mcp/services`、`GET /api/scheduler/tasks`、`GET /api/schedules`、`GET /api/tasks` 响应与迁移前一致（只读端点）
- [ ] `GET /api/plugins` 含 mcp_scheduler 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- 调度域有**副作用端点**（create/delete/execute-now/cancel），冒烟只验证只读端点与 4xx 行为。
- 完成后 git 提交：`refactor(plugins): extract mcp/scheduler domain into plugins/mcp_scheduler.py`。
