# 任务 T1.1：后端插件注册表 + 装配器骨架

## 目标

为云枢（Yunshu）后端建立「插件注册表」机制，并把 `app_server.py` 改造成装配器：创建 Flask app、注册全部插件 blueprint、提供 `/api/plugins` 元信息端点。**本任务不迁移任何现有路由**，只搭骨架。

## 背景

- 项目：云枢，Python Flask 后端。方案文档：`docs/yunshu-pluginization/README.md`、`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（先读）。
- 现状：`app_server.py`（213KB）是单体，约 177 个 `@app.route` 直接挂在大 `app` 上，只有 2 个 blueprint（`health_bp`、`learning_metrics_bp`）。
- 约束：路由路径、请求/响应格式、行为必须 100% 不变；本任务不动任何现有路由。

## 设计契约（必须满足）

1. 新建 `plugins/` 目录（仓库根目录下，与 `app_server.py` 同级），包含：
   - `plugins/__init__.py` — 空或仅文档注释（本任务不 import 任何域插件）
   - `plugins/plugin_api.py` — 插件协议层，内容见下方「协议代码」
2. 协议代码：

```python
# plugins/plugin_api.py
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional
from flask import Blueprint

@dataclass
class Plugin:
    name: str
    version: str
    description: str = ""
    schema: Dict[str, Any] = field(default_factory=dict)
    blueprint: Optional[Blueprint] = None
    routes: List[str] = field(default_factory=list)

_REGISTRY: List[Plugin] = []

def register_plugin(plugin: Plugin) -> Plugin:
    if not any(p.name == plugin.name for p in _REGISTRY):
        _REGISTRY.append(plugin)
    return plugin

def get_plugins() -> List[Plugin]:
    return list(_REGISTRY)

def manifest() -> Dict[str, Any]:
    import sys, flask
    return {
        "plugins": [
            {
                "name": p.name,
                "version": p.version,
                "description": p.description,
                "schema": p.schema,
                "routes": sorted(p.routes),
            }
            for p in _REGISTRY
        ],
        "host": {"python": sys.version.split()[0], "flask": flask.__version__},
    }
```

3. 修改 `app_server.py`（**只加不改**）：
   - 顶部 `from plugins.plugin_api import get_plugins, manifest as plugin_manifest`
   - 在现有 `app.register_blueprint(health_bp)` / `app.register_blueprint(learning_metrics_bp)` 之后，追加注册循环：

```python
for _p in get_plugins():
    if _p.blueprint is not None:
        app.register_blueprint(_p.blueprint)
```

   - 新增端点（放在其他 `/api/*` 路由附近）：

```python
@app.route("/api/plugins", methods=["GET"])
def api_plugins():
    return jsonify(plugin_manifest())
```

   - 保持 `app` 创建、所有现有路由、装饰器（`require_token`、`log_request` 等）原样不动。
4. 写一个**临时示例插件** `plugins/example.py` 验证机制（本任务结束可保留，后续任务会删除）：

```python
# plugins/example.py
from flask import Blueprint, jsonify
from .plugin_api import Plugin, register_plugin

bp = Blueprint("example", __name__)

@bp.route("/api/example/plugin-probe")
def api_example_probe():
    return jsonify({"plugin": "example", "ok": True})

PLUGIN = register_plugin(Plugin(
    name="example",
    version="0.1.0",
    description="插件机制探测",
    blueprint=bp,
    routes=["/api/example/plugin-probe"],
))
```

   - 在 `app_server.py` 顶部追加 `from plugins import example  # noqa: F401`（或在 plugins/__init__.py 中 import）。
