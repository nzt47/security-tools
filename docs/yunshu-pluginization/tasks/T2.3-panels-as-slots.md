# 任务 T2.3：面板插槽化（SkillManagement / Knowledge / DevConsole）

## 目标

把 `App.tsx` 中由布尔开关控制的浮层面板（SkillManagement、Knowledge、DevConsole）改为「注册进 `panels` 插槽 + 面板切换器统一驱动」。行为不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-2-frontend-slots.md`（§3、§4）。
- 前置：T2.2 已完成。
- 现状：`App.tsx` 用 `skillMgmtOpen` / `knowledgeOpen` 布尔开关控制面板显隐；DevConsole 可能由其他入口触发（以实际代码为准）。

## 设计契约（必须满足）

1. **面板注册协议**：每个面板以 `{ id, title, component, icon? }` 元数据注册进 `panels` 插槽。扩展 `SlotEntry` 支持可选 `title` / `icon`（`slotRegistry.ts` 增加字段，保持向后兼容）：

```ts
export interface SlotEntry {
  id: string;
  component: React.ComponentType;
  order?: number;
  hidden?: boolean;
  title?: string;   // 面板标题（切换器用）
  icon?: string;    // lucide 图标名或组件（可选）
}
```

2. **面板切换器**（新组件 `src/plugins/PanelSwitcher.tsx` 或 `src/components/Panels/PanelSwitcher.tsx`）：
   - 读取 `panels` 插槽条目（应用 profile 的 hidden/order）；
   - 渲染每个面板的开关按钮（title/icon）；
   - 点击切换显隐（状态用 zustand store：`panelsStore`，字段 `open: Record<string, boolean>`，默认按 profile hidden 初始化）；
   - 渲染当前打开的 `<PanelHost/>`：遍历打开的条目渲染组件。
3. **改造 `App.tsx`**：
   - 删除 `skillMgmtOpen` / `knowledgeOpen` 布尔状态与相关 JSX；
   - 面板区替换为 `<PanelSwitcher/>`（内部含 PanelHost）；
   - SkillManagement / Knowledge / DevConsole 各自 `mountToSlot('panels', {...})`（可建 `src/plugins/panels.ts` 集中挂载）。
4. `profile.json` 的 `panels` 填充三条目（`skills` / `knowledge` / `devconsole`），初始 `hidden: true`。

## 步骤

1. 通读 `App.tsx` 中面板开关相关代码与三个面板组件的 props 契约。
2. 扩展 `slotRegistry.ts`（title/icon），建 `panelsStore`（zustand）、`PanelSwitcher`、`PanelHost`。
3. 迁移挂载与开关逻辑，删布尔状态。
4. 单测：`PanelSwitcher` 渲染按钮、点击开关、profile hidden 生效（vitest + testing-library）。

## 验收标准

- [ ] `npx tsc -b --noEmit` 通过；`npx vitest run` 全部通过（含新增 PanelSwitcher 测试）
- [ ] `npm run dev` 冒烟：三个面板开关行为与改造前一致（打开/关闭/多开）
- [ ] 修改 profile.json 隐藏某面板 → 切换器不再显示该按钮
- [ ] `App.tsx` 继续瘦身（目标 < 200 行）
- [ ] 提交信息：`refactor(ui): panels driven by slot registry + PanelSwitcher`

## 风险与注意事项

- DevConsole 若含全局监听/拦截逻辑（如 requestInterceptor），保持其生命周期不变（挂载时启用、卸载时恢复）。
- 面板关闭时组件卸载（而非隐藏）会丢失内部状态；若改造前是「隐藏保留状态」，PanelHost 需改为隐藏（CSS）而非卸载，保持行为一致。
- 完成后 git 提交。
