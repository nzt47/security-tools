# 任务 T1.5：拆分 skills 插件（skills / extensions / tools）

## 目标

把 `app_server.py` 中的技能/扩展/工具域路由迁移到 `plugins/skills.py`。路由路径与行为 100% 不变。

## 背景

- 方案：`docs/yunshu-pluginization/PLAN-1-backend-pluginization.md`（重点 §2、§4）。
- 前置：T1.1 已完成。与 T1.2–T1.4、T1.6–T1.9 相互独立，可并行。
- 共享依赖约定：函数内延迟 import；模块顶层不得 import `app_server`。

## 步骤

1. 创建 `plugins/skills.py`，模板同 T1.2。
2. 迁移上述路由函数体；`SkillsManager` 类（704 行附近）若只被本域使用，一并搬入插件。
3. 工具状态 helper（`_load_tool_states`、`_save_tool_states`、`_get_tool_state`、`_set_tool_state`、`_get_enabled_tool_names`）若只被本域使用，一并搬入；若被其他域共享，留在 app_server。
4. 声明 `PLUGIN = register_plugin(Plugin(name="skills", version="1.0.0", description="技能、扩展与工具管理", blueprint=bp, routes=[...]))`。
5. `plugins/__init__.py` 追加 `from . import skills`。
6. 删除 `app_server.py` 中已迁移的路由与不再被引用的私有 helper/类。

## 验收标准

- [ ] `py_compile` 通过；`import app_server` 无循环导入
- [ ] 冒烟：`GET /api/skills`、`GET /api/extensions/list`、`GET /api/tools/config`、`GET /api/tools/categories` 响应与迁移前一致
- [ ] `GET /api/plugins` 含 skills 插件且 routes 正确
- [ ] 迁移前后路径集合一致；`python -m pytest tests/ -x -q`（或相关子集）通过

## 风险与注意事项

- extensions 域路由可能触发网络请求（市场搜索/发现），冒烟时注意超时与离线降级行为，保持与迁移前一致。
- 完成后 git 提交：`refactor(plugins): extract skills domain into plugins/skills.py`。
