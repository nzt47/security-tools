## Summary

修复「文档链接预检与锚点回归测试」check 失败：`docs/zh/云枢系统前端可视化与干预方案_20260816.md` 含一条指向不存在目标的失效链接。

## 根因

该文档第 268 行存在相对链接：

```markdown
紧急停止
```

`precheck_docs.ps1` 按文档所在目录（`docs/zh/`）解析 → 目标 `docs/zh/红/二次确认` **不存在**（`docs/zh/红/` 目录不存在）。上下文显示"红色二次确认"是功能描述文本（高危动作二次确认弹窗），链接疑似误加，无对应目标文档。

## 修复

删除失效链接，改为纯文本（语义已在正文描述）：

```diff
- 4. 紧急停止操作触发紧急停止，`reason` 必填，操作写入日志审计可查；
+ 4. 紧急停止操作触发**红色二次确认**，`reason` 必填，操作写入日志审计可查；
```
