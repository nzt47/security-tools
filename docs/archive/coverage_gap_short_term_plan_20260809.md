# 覆盖率缺口短期提升方案（2026-08-09）

> 目标：短期（1-2 迭代）将全项目覆盖率提升至 ≥40%，使 observability-ci 质量门禁转绿。
> 数据源：run 31263942975 `full-coverage-report/coverage.xml`（coverage.py 7.15.4，6-shard 合并口径）

## 3. 三条提升路径（按投入产出排序）

### 路径 A：修正覆盖率统计口径（排除不应计量的代码）—— 最快，1 步

**问题**：`coverage-combine` 合并时把 `scripts/`（CI/部署/工具脚本）与 `tests/`（测试自身）计入分母，
但这些代码大多不是可测业务单元。

**动作**：在 `pyproject.toml` `[tool.coverage.run]` 增加 `omit`（与 `source` 对齐）：

```toml
[tool.coverage.run]
source = ["agent", "sensor", "memory", "planning", "persona", "core", "cognitive", "lifetrace", "utils"]
omit = [
  "tests/*",
  "scripts/ci/*",
  "scripts/deploy/*",
  "scripts/release/*",
  "scripts/dev/*",
]
```

**收益估算**：
- 仅排除 `tests/`（5730 行）→ 37.96% → **40.5%** ✅ 达标
- 再排除 `scripts/ci|deploy|release|dev`（估算 ~1.5 万行 CI 辅助脚本）→ 预计 **45%+**

**风险**：低。口径与 `source` 列表一致；需同步确认 `scripts/` 中核心业务脚本（如 `observability_quality_gate.py`、`visibility_report.py`）**不**在 omit 内，保证门禁自身可被覆盖。

**验收**：本地 `coverage combine && coverage report --fail-under=40` 通过。

### 路径 B：定向补测 server_routes + extensions（真实价值提升）—— 中等投入

**server_routes/**（5721 行，34.7% → 目标 60%）：
- 该层是 API 路由分发，补测可顺带提升 `web/`、`auth/` 等下游
- 估算补 1000 行 → +0.84 个百分点

**extensions/**（2197 行，31.3%）：
- 插件加载/生命周期测试，估算补 500 行 → +0.42 个百分点

**验收**：新增测试文件 `tests/unit/test_server_routes_*.py`、`tests/unit/test_extensions_*.py`，覆盖率达到 60%+。

### 路径 C：短期维持门禁为「警示」而非「阻断」（兜底选项）

若 A+B 在一个迭代内无法落地，可将门禁 `--min-coverage` 临时设为 35%（仍低于实测 37.96%），
并在门禁报告中注明「覆盖率缺口 ≥2 个百分点，禁止发版」的软警告。**不推荐长期使用**。

## 4. 推荐执行顺序

| 步骤 | 动作 | 预期效果 | 依赖 |
|---|---|---|---|
| 1 | **路径 A**：pyproject omit 排除 tests/ 与 CI 脚本 | 37.96% → ≥40% | 无 |
| 2 | 复跑 coverage-combine + 门禁验证 | 门禁转绿 | 步骤 1 |
| 3 | **路径 B**：补 server_routes 路由测试（首批 3-5 个核心路由） | 覆盖率 +0.5~1% | 无 |
| 4 | 持续监控：门禁阈值保持 40%，随补测自然提升 | 覆盖率 →45%+ | 步骤 3 |

## 5. 关键决策记录

| 决策点 | 选项 | 选择 | 理由 |
|---|---|---|---|
| 统计口径 | 全量统计 / 排除 tests+CI 脚本 | **排除** | scripts/ 占 43.8% 行数却仅 6.9% 覆盖，严重稀释真实业务覆盖率 |
| omit 范围 | 仅 tests/ / 含 CI 脚本 | **先 tests/，CI 脚本视脚本性质** | 首步即达标（40.5%），避免一次改大出争议 |
| 阈值 | 35% 临时 / 保持 40% | **保持 40%** | 对齐 visibility-report 契约；缺口靠补测解决而非降标 |
