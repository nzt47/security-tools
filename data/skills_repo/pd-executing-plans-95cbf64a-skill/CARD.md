# executing-plans

> LLM 整理，逐条经**原文引用校验**：verified 28 / 28（未通过的已丢弃）。

## 何时使用

- 当你有一份书面实施计划，需要在单独的会话中执行并设置审查节点时使用。

## 步骤

- 读取计划文件。
- 批判性地审查计划，找出任何疑问或顾虑。
- 如果有顾虑，在开始前向人类伙伴提出。
- 如果没有顾虑，创建 TodoWrite 并继续。
- 将任务标记为进行中。
- 严格按计划的每个小步骤执行。
- 按计划规定运行验证。
- 将任务标记为已完成。
- 宣布将使用 finishing-a-development-branch 技能完成工作。
- 必须使用 superpowers:finishing-a-development-branch 子技能。
- 遵循该技能验证测试、呈现选项并执行所选方案。

## 参数

- 相关技能 superpowers:using-git-worktrees 用于确保隔离工作区（创建或验证现有工作区）。
- 相关技能 superpowers:writing-plans 用于创建本技能所执行的计划。
- 相关技能 superpowers:finishing-a-development-branch 用于在所有任务完成后完成开发。

## 约束 / 反例

- 遇到阻塞（缺少依赖、测试失败、指令不清）时应停止。
- 计划存在关键缺口导致无法开始时停止。
- 不理解某条指令时停止。
- 验证反复失败时停止。
- 伙伴根据你的反馈更新计划。
- 基本方法需要重新考虑时停止。
- 先批判性地审查计划。
- 严格遵循计划步骤。
- 不要跳过验证。
- 计划要求时引用相应技能。
- 受阻时停止，不要猜测。
- 未经用户明确同意，绝不在 main/master 分支上开始实施。
