# 主动建议

> LLM 整理，逐条经**原文引用校验**：verified 17 / 17（未通过的已丢弃）。

## 何时使用

- 用户描述任务但未询问实现方式时，可提示可选路径。
- 多轮对话中识别到潜在风险或优化点时主动提示。
- 任务完成后，建议下一步相关操作，如测试、归档、复盘。
- 当前轮次没有显式问句时，才属于触发条件之一。
- 上下文中存在可识别的隐含需求信号时触发。
- 建议项必须有明确依据，不得凭空推断。

## 步骤

- 解析当前轮次与最近 N 轮对话，抽取任务主题与未解决项。
- 仅当识别到高置信度（≥ 0.7）的隐含需求时才生成建议。
- 建议必须附依据来源，如上文某轮、某事实或某规则。
- 每轮最多输出 1-2 条建议，避免信息过载。
- 建议以“提示”形式呈现，不替代用户决策。

## 参数

- 建议项列表每条含 suggestion、rationale、confidence（0-1）。
- 无建议时输出空列表，不强制生成。

## 约束 / 反例

- 不得编造依据，所有 rationale 必须可追溯到对话上下文。
- 建议仅作提示，不自动执行任何操作。
- 不打断当前任务流程，建议以可选形式呈现。
