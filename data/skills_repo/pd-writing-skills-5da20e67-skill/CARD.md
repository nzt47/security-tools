## 何时使用

- 适用于创建、编辑或验证 agent 技能（SKILL.md）之前或过程中
- 核心是将 TDD 应用于流程文档编写
- 触发条件包括创建技能、编辑技能、验证技能、SKILL.md

## 步骤

- RED 阶段：运行无技能时的基线压力场景，观察 agent 在未使用技能时的违规行为
- RED 阶段用子代理执行压力场景，记录其自然行为与合理化借口
- 逐字记录 agent 在基线测试中使用的具体合理化理由，用于后续显式封堵
- 逐字记录合理化理由，用于后续在技能中显式封堵
- GREEN 阶段：编写最小化技能文档 SKILL.md，仅针对基线测试中观察到的违规行为
- GREEN 阶段不添加假设性内容，遵循 SKILL.md 格式与黄金法则
- 用相同压力场景重新运行测试，确认 agent 在技能存在时遵守规则
- 验证通过则进入 REFACTOR，否则继续补充技能
- REFACTOR 阶段：识别 agent 新找出的漏洞或合理化方式，在技能中显式添加反制条款
- 每次发现新漏洞即补充并重新测试
- 反复运行测试和补充技能，直到技能在各种压力场景下保持有效
- 涵盖纪律型、技法型、模式型、参考型技能的不同测试方法
- 执行部署前验证，确保当前技能已通过测试后再进入下一个技能
