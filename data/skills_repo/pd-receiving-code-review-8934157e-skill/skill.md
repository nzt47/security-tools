# receiving-code-review

Use when receiving code review feedback, before implementing suggestions, especially if feedback seems unclear or technically questionable - requires technical rigor and verification, not performative agreement or blind implementation。由 1 份素材蒸馏生成

## 触发条件
- `receiving`
- `code`
- `review`

## 步骤清单
### 步骤 1: （纯指令）
- READ: Complete feedback without reacting

### 步骤 2: （纯指令）
- UNDERSTAND: Restate requirement in own words (or ask)

### 步骤 3: （纯指令）
- VERIFY: Check against codebase reality

### 步骤 4: （纯指令）
- EVALUATE: Technically sound for THIS codebase?

### 步骤 5: （纯指令）
- RESPOND: Technical acknowledgment or reasoned pushback

### 步骤 6: （纯指令）
- IMPLEMENT: One item at a time, test each

### 步骤 7: （纯指令）
- "You're absolutely right!" (explicit CLAUDE.md violation)

### 步骤 8: （纯指令）
- "Great point!" / "Excellent feedback!" (performative)

### 步骤 9: （纯指令）
- "Let me implement that now" (before verification)

### 步骤 10: （纯指令）
- Restate the technical requirement

### 步骤 11: （纯指令）
- Ask clarifying questions

### 步骤 12: （纯指令）
- Push back with technical reasoning if wrong

### 步骤 13: （纯指令）
- Just start working (actions > words)

### 步骤 14: （纯指令）
- Trusted - implement after understanding

### 步骤 15: （纯指令）
- Still ask if scope unclear

### 步骤 16: （纯指令）
- No performative agreement

### 步骤 17: （纯指令）
- Skip to action or technical acknowledgment

### 步骤 18: （纯指令）
- Check: Technically correct for THIS codebase?

### 步骤 19: （纯指令）
- Check: Breaks existing functionality?

### 步骤 20: （纯指令）
- Check: Reason for current implementation?

### 步骤 21: （纯指令）
- Check: Works on all platforms/versions?

### 步骤 22: （纯指令）
- Check: Does reviewer understand full context?

### 步骤 23: （纯指令）
- Clarify anything unclear FIRST

### 步骤 24: （纯指令）
- Then implement in this order:

### 步骤 25: （纯指令）
- Blocking issues (breaks, security)

### 步骤 26: （纯指令）
- Simple fixes (typos, imports)

### 步骤 27: （纯指令）
- Complex fixes (refactoring, logic)

### 步骤 28: （纯指令）
- Test each fix individually

### 步骤 29: （纯指令）
- Verify no regressions

### 步骤 30: （纯指令）
- Suggestion breaks existing functionality
