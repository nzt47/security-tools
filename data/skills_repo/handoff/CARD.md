# 会话交接文档生成器

> LLM 整理，逐条经**原文引用校验**：verified 7 / 7（未通过的已丢弃）。

## 何时使用

- 当需要把当前对话压缩成交接文档、供另一个代理接手时使用。

## 步骤

- 撰写一份总结当前对话的交接文档，让新代理能继续工作。
- 文档保存到用户操作系统的临时目录，而不是当前工作区。
- 文档中包含“建议技能”一节，建议代理应调用的技能。

## 参数

- 若用户传入参数，将其视为下一次会话重点的描述，并据此调整文档。

## 约束 / 反例

- 不要重复其他产物中已记录的内容，改为按路径或 URL 引用。
- 隐去 API 密钥、密码、个人可识别信息等敏感信息。
