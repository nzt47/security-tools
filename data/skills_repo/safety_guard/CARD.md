# 安全守护

> LLM 整理，逐条经**原文引用校验**：verified 20 / 20（未通过的已丢弃）。

## 何时使用

- 在工具调用前校验参数路径，防止目录穿越和系统文件写入
- 在回应中检测手机号、身份证、密钥、token 等隐私信息泄露
- 用户请求涉及删除、格式化、批量修改等危险操作时强制二次确认
- 每次工具调用前自动运行，作为前置门控
- 回应生成后、输出前自动运行，作为后置审查
- 命中风险关键词或正则模式时触发拦截

## 步骤

- 维护包含路径黑名单、敏感信息正则、危险操作动词清单的风险规则库
- 工具调用前校验参数路径与操作类型，命中黑名单则拦截
- 回应输出前扫描隐私信息与危险指令，命中则替换或告警
- 删除、格式化、批量执行等高风险操作不直接执行，返回需二次确认
- 所有拦截与告警记录结构化日志，包含 trace_id 与命中规则

## 参数

- 输出 action 字段，取值为 allowed、blocked 或 confirm_required
- 输出 matched_rules 字段，为命中的规则 ID 列表
- 输出 sanitized_content 字段，为脱敏后的内容（如有）
- 输出 severity 字段，取值为 info、warning 或 critical

## 约束 / 反例

- 任何拦截不得静默，必须返回明确的 action 与 matched_rules
- 敏感信息脱敏必须彻底，不得部分残留
- 二次确认操作必须等待用户显式同意后才执行，不得绕过
- 风险规则库变更必须留审计日志，禁止运行时静默修改
