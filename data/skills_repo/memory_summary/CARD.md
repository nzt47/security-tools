# memory_summary

> LLM 整理，逐条经**原文引用校验**：verified 21 / 21（未通过的已丢弃）。

## 何时使用

- 单轮对话超过上下文窗口阈值时，触发前文压缩
- 跨会话恢复时，加载历史摘要替代全量历史
- 长期记忆检索前，按主题归并相似条目
- 适用于总结对话历史、压缩记忆、梳理历史、归纳之前的内容等场景

## 步骤

- 按时间窗或主题切分原始记忆
- 抽取每段的事实与决策，丢弃寒暄与冗余
- 合并同主题条目，跨段时间线保持顺序
- 写入摘要时附带 source_refs 以便回溯

## 参数

- 摘要包含 topic 字段，主题用一句话表示
- 摘要包含 facts 字段，为关键事实列表，不可省略数字、人名、时间
- 摘要包含 decisions 字段，记录已达成的决策与决策依据
- 摘要包含 open_questions 字段，记录未解决的问题
- 摘要包含 timestamp 字段，为摘要生成时间
- 摘要包含 source_refs 字段，为原始消息定位（会话ID + 消息序号区间）

## 约束 / 反例

- 上下文 token 用量超过阈值（默认 80%）时触发
- 用户主动请求总结之前的内容或梳理历史时触发
- 跨会话恢复且历史超过 N 轮（默认 20）时触发
- 数字、人名、时间必须原样保留，不得改写
- 决策依据不可省略
- 摘要必须可追溯到原始消息，不可凭印象生成

## 示例

- 示例步骤：按时间窗或主题切分原始记忆，抽取每段的事实与决策并丢弃寒暄与冗余
