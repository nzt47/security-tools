# 语音交互

> LLM 整理，逐条经**原文引用校验**：verified 20 / 20（未通过的已丢弃）。

## 何时使用

- 用户不便打字时，可通过语音输入指令与对话内容。
- 视觉障碍用户可通过语音播报获取回应。
- 长文本回应场景下可自动转语音播放，减轻阅读负担。
- 用户显式启用语音模式时触发。
- 检测到音频输入设备连接且用户开始说话时触发。
- 回应超过一定长度（默认 200 字）且启用自动播报时触发。

## 步骤

- 语音输入流程：采集音频，经 ASR 转文字后进入对话处理流程。
- 语音指令路由：识别停止、暂停、继续、切换主题等控制指令。
- 语音输出流程：回应文本经 TTS 合成后播放音频流。
- 中断处理：用户说话时若再次发声，触发打断并停止当前播报。
- 错误恢复：ASR 或 TTS 失败时回退至文本模式并提示。

## 参数

- 输出包含识别出的文本 asr_text。
- 输出包含合成音频的访问地址或二进制流 tts_audio_url。
- 输出包含识别到的控制指令 command，如无则为 null。
- 输出包含是否被用户打断的布尔值 interrupted。

## 约束 / 反例

- 语音数据不得在本地持久化明文存储，处理完即丢弃。
- ASR 识别结果必须回显给用户确认，不可静默执行。
- 打断响应延迟须不超过 500ms，避免信息继续输出造成混淆。
- TTS 合成失败时必须回退文本模式，不得静默丢弃回应。
