## 3. 修复内容清单

### 3.1 请求级会话隔离（根因闭环）

- `/api/chat` 解析优先级：**body `session_id` > query `session` > 全局默认**（[app_server.py](file:///c:/Users/Administrator/agent/app_server.py)）。
- 显式会话不存在时自动 `create_session(session_id=...)`，非法 ID / Windows 路径 OSError 回退默认会话（不 500）。

### 3.2 SessionManager 显式会话创建边界加固

- 非法字符拦截：路径穿越（`/ \ .. :`）+ Windows 非法字符（`* ? < > | " \x00`）。
- Windows 保留设备名（CON/NUL/COM1~9/LPT1~9，大小写与空格/点变体）。
- 超长 ID 上限 128 字符（Windows 路径 260 限制）。
- **检查-创建-写索引全程持锁原子化**：幂等守卫放锁外会被并发击穿（8 线程同 ID → 索引 8 条重复 + `write_text("")` 清空消息文件），锁内二次检查杜绝 TOCTOU。

### 3.3 内存泄漏防护（本报告新增）

- `dialog_state._SESSION_STATES` 模块级 dict 无界增长 → **LRU 容量守卫**（上限 256，超限淘汰最久未访问），外部无限造 session_id 不再导致内存不可回收爬升。
- 已确认 SessionManager 不缓存 MemoryManager（orchestrator 单例），本层无泄漏。
