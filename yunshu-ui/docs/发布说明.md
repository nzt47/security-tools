# 云枢桌面端 发布说明（v0.1.0）

> 适用于 Electron 桌面版（Electron 43 + React 18 + Vite 6）。
> 由 `npm run dist:electron` 自动构建安装包，本说明与打包产物同步维护。

## 一、安装步骤

1. **获取安装包**：从 `release/` 目录取得 `云枢 Setup 0.1.0.exe`（约 79 MB）。
2. **运行安装程序**：双击安装包，进入 NSIS 安装向导。
   - 默认安装到 `%LOCALAPPDATA%\Programs\云枢`（可选自定义目录）；
   - 可勾选"创建桌面快捷方式"与"开始菜单快捷方式"。
3. **启动应用**：安装完成后通过桌面/开始菜单快捷方式启动，或直接运行 `云枢.exe`。
4. **验证**：主窗口弹出（1440×900），进入登录页即安装成功。

## 二、数据与日志位置

| 项目 | 路径 |
|---|---|
| 用户数据（localStorage / Mosaic 布局等） | `%APPDATA%\云枢`（Local Storage 等） |
| 应用日志（JSON，按天轮转） | `%APPDATA%\云枢\logs\app-YYYY-MM-DD.log` |

> 卸载应用**不会**自动删除 `%APPDATA%\云枢`，用户数据保留；如需彻底清理，手动删除该目录。

## 三、日志格式（对接日志系统）

日志为 stdout 单行 JSON + 落盘文件双写，字段固定：

```json
{"ts":"2026-08-23T14:08:31Z","level":"info","module":"main","event":"window-created","width":1440,"height":900,"title":"云枢 · 工作台"}
```

主要事件：

| event | level | 含义 |
|---|---|---|
| `window-created` | info | 主窗口创建 |
| `renderer-loading` | info | 开始加载前端（`mode: dev/prod`） |
| `renderer-loaded` | info | 加载完成 |
| `renderer-load-failed` | **error** | 加载失败（对应 `did-fail-load`，含 `code`/`description`/`url`） |
| `panel-detached` | info | 面板分离为独立窗口 |
| `reload-shortcut-triggered` | info | Ctrl+R 刷新（仅开发模式） |

## 四、日志分析脚本

仓库内 `scripts/analyze-logs.mjs` 可自动解析并统计加载失败（did-fail-load）次数：

```powershell
node scripts/analyze-logs.mjs            # 默认读取 %APPDATA%\云枢\logs
node scripts/analyze-logs.mjs <logDir>   # 自定义日志目录
```

输出：日志总量、`renderer-load-failed` 次数、错误码/描述分布、最近 20 条失败明细。

## 五、已知问题与排查指南

### 1. 应用白屏 / 加载失败
- **现象**：窗口弹出但空白，或停留在加载态。
- **排查**：查看日志中 `renderer-load-failed` 事件（含错误码与 URL），常见：
  - `-6 ERR_FILE_NOT_FOUND` → 打包产物 `dist/index.html` 缺失或路径错误（构建已配置 `base='./'` 相对路径规避）；
  - `-3 ERR_ABORTED` → 页面跳转/资源中途取消，多为正常路由切换，若频繁出现需关注。
- **自动化**：运行 `node scripts/analyze-logs.mjs` 直接统计。

### 2. 打包失败：win-unpacked 文件被占用（EPERM）
- **现象**：`EPERM: unlink 'release\win-unpacked\ffmpeg.dll'`。
- **原因**：正在运行的旧版 `云枢.exe` 占用运行时文件，electron-builder 无法清理覆盖。
- **已解决**：`beforePack` 钩子（`scripts/beforePack.mjs`）会在打包前自动 `taskkill /IM 云枢.exe /F /T`，无需手动处理。

### 3. Electron 下载超时 / 缓存不命中
- **现象**：打包时长时间停在 `Downloading electron-v43...`。
- **原因**：electron-builder 需要下载 Electron 二进制（国内网络慢）。
- **已解决**：构建配置 `electronDist: "node_modules/electron/dist"` 直接复用本地已安装的 Electron，离线打包。

### 4. 开发模式 Ctrl+R 无效
- **预期行为**：`Ctrl+R` 刷新快捷键**仅开发模式**生效（生产环境 `file://` 加载下无意义且避免误触清空状态），生产包按 `Ctrl+R` 不刷新属正常。
- 开发模式验证：`$env:ELECTRON=1; npm run dev:electron`。

### 5. 面板分离窗口异常
- **现象**：面板拖出为独立窗口后崩溃/黑屏。
- **排查**：确认日志出现 `panel-detached`；若窗口加载失败会记录 `renderer-load-failed`（独立窗口走同一日志链路）。
- **注意**：afterPack 保留 `d3dcompiler_47.dll`/`ffmpeg.dll`（删除会导致独立窗口崩溃或渲染异常），**请勿**将其加入剔除清单。

### 6. 升级安装 / 数据兼容
- 直接运行新版安装包覆盖安装即可，`%APPDATA%\云枢` 数据保留。
- 若升级后布局异常，可删除 `%APPDATA%\云枢\Local Storage` 后重启（会重置本地缓存，不影响账号数据）。

## 六、构建与发布命令

```powershell
cd yunshu-ui
npm run dist:electron   # 构建 + 打包 + 体积报告（产物在 release/）
node scripts/analyze-logs.mjs  # 发布后巡检日志（可选）
```

产物清单（`release/`）：

| 文件 | 说明 |
|---|---|
| `云枢 Setup 0.1.0.exe` | NSIS 安装包（分发此文件） |
| `win-unpacked/云枢.exe` | 免安装便携版 |
| `volume-report.md` | 体积与校验报告 |
