# 云枢桌面端（yunshu-ui）交付报告

> 交付日期：2026-08-23 ｜ 版本：v0.1.0（Electron 43 + React 18 + Vite 6）
> 交付方式：从 Web 版完成 Electron 桌面化改造，含开发调试、日志体系、打包链路、自动化测试与发布文档。

## 一、交付成果

### 1. Electron 桌面化（基于既有 vite-plugin-electron 方案）
- 主进程 [electron/main.ts](electron/main.ts)：多窗口（主窗口 + 面板分离独立窗口）、跨窗口状态同步总线、IPC 白名单校验、`userData` 固定 `%APPDATA%\云枢`。
- 预加载 [electron/preload.ts](electron/preload.ts)：contextBridge 暴露白名单 API（`detachPanel`/`getWindowMeta`/状态同步）。
- 修复 dev 模式失效 Bug：vite-plugin-electron 1.x 注入 `VITE_DEV_SERVER_URL`，旧代码用 0.x 的 `ELECTRON_RENDERER_URL` 导致永远加载生产产物，已兼容修复。

### 2. 开发体验
- Ctrl+R 刷新快捷键（仅开发模式）：抽取 [devShortcut.ts](electron/devShortcut.ts) 独立模块，便于单元测试。

### 3. 日志体系（生产可观测）
- 统一 JSON 结构化日志（`{ts, level, module, event, ...}`），事件：`window-created` / `renderer-loading` / `renderer-loaded` / `renderer-load-failed` / `panel-detached` / `reload-shortcut-triggered`。
- 落盘 `%APPDATA%\云枢\logs\app-YYYY-MM-DD.log`（按天轮转，写失败静默降级）。
- 分析脚本 [analyze-logs.mjs](scripts/analyze-logs.mjs)：统计 `did-fail-load` 次数/错误码分布/失败明细。

### 4. 打包链路（稳定可重复）
- `electronDist` 复用本地 Electron，离线打包（解决缓存不命中/下载超时）。
- `beforePack` 钩子自动清理同名旧进程（解决 `ffmpeg.dll`/`d3dcompiler_47.dll` EPERM）。
- `afterPack` 剔除 6 个冗余运行时文件 + 校验；`report-volume` 自动体积报告。
- 产物：`release\云枢 Setup 0.1.0.exe`（79.04 MB，NSIS 安装包）+ 便携版 `win-unpacked`。

### 5. 测试
- 单元测试 [devShortcut.test.ts](electron/devShortcut.test.ts)：7 用例（dev 注册/Ctrl+R/Cmd+R/非 R 键/裸 R/生产不注册/旧变量名兼容）全部通过。
- 自动化安装测试 [install-test.mjs](scripts/install-test.mjs)：静默安装 → 卸载程序集成验证 → 启动 → 日志自动创建 → 卸载清理，**7/7 通过**。

### 6. 文档
- [docs/发布说明.md](docs/发布说明.md)：安装步骤、日志格式、已知问题排查指南。

## 二、遇到的问题及解决方案

| # | 问题 | 原因 | 解决方案 |
|---|---|---|---|
| 1 | dev 模式窗口加载旧构建（无 HMR） | vite-plugin-electron 1.x 环境变量名变更（`VITE_DEV_SERVER_URL`） | 兼容双变量名，主进程日志确认 dev/prod 分支 |
| 2 | Electron 打包卡在下载（ETA 1.8h） | `electronDownload.cache` 字面 `${env.TEMP}` 历史缓存 hash 不匹配 | 配置 `electronDist` 复用本地 dist，离线打包 |
| 3 | 打包 EPERM（`ffmpeg.dll`） | 旧版云枢进程占用 win-unpacked 文件 | `beforePack` 钩子 taskkill + 句柄释放等待 |
| 4 | 窗口标题错误 | `index.html` 的 `<title>My Trae Project</title>` 覆盖窗口标题 | 改为"云枢" |
| 5 | 安装测试安装路径不符预期 | NSIS 记忆上次安装目录（`yunshu-app-test` 残留） | 测试用 `/D=` 指定干净目录 + 清理残留 |
| 6 | 安装测试日志假阳性 | 基线比较误用对象引用 | 改用时间戳基线 |
| 7 | 并行 Edit 竞态丢失修改 | 同文件并行编辑未落盘（3 次） | 已修复，结论：同文件修改须串行 |
