## 一、目标描述

实现设计文件"质量守卫分层建设"的代码化落地：孤儿页面/矛盾/过期声明检测、冲突裁决协议、基于文件监听的增量索引，以及定时自动审计（复用 task_scheduler），产出《知识库健康报告》。

【不易】约束：不修改 `agent/memory/reviewer.py`，复用其健康分扣分模式作为参考算法即可。

```python
    health_score: float = 100.0

    ...
```

检测项与规则：

| 检测项 | 规则 | 数据来源 |
|---|---|---|
| 孤儿页面 | `find_orphans`（无任何入链） | 任务2 `links.py` |
| 断链 | `find_broken_links`（links 指向不存在卡片） | 任务2 `links.py` |
| index 漂移 | 卡片集合与 index.md 条目集合 diff | 任务2 `index.py` |
| 过期声明 | `status=current` 且 `date` 距今天数 > `stale_days` 且 `updated_at` 超期 | Card frontmatter |
| 未裁决矛盾 | `contradictions` 中 `status != resolved` | Card schema |

健康分算法（参考 `agent/memory/reviewer.py` 扣分模式）：

```
base = 100
孤儿: 每张扣 2（封顶 20）
断链: 每条扣 2（封顶 20）
index 漂移: 每张扣 2（封顶 10）
过期声明: 每条扣 3（封顶 20）
未裁决矛盾: 每条扣 5（封顶 30）
health_score = max(0, round(base - 扣分, 1))
```
