## 2. Card 字段（dataclass）

必填：`title` `slug` `status` `type` `source` `date`；
默认值：`tags=[]` `links=[]` `contradictions=[]` `insight=""` `scope=""` `content=""` `metadata={}`
（list/dict 用 `field(default_factory=...)`，实例相互独立）。

## 3. validate_card 校验规则（绝不抛异常，返回违规字符串列表）

- 缺失/空值必填字段 → `缺少必填字段: <name>`
- 非法 `type` → `非法 type: ...`
- 非法 `status` → `非法 status: ...`
- `slug != slugify(title)` → `slug 与 slugify(title) 不一致`（除非 `explicit_slug=True`）
- contradictions 结构：缺 `target_slug` / `status` 非法 / 非 dict
- `insight` 为空 → `缺少一句话核心洞见`
- 非 dict 入参 → `["card 必须是 dict"]`

## 4. slugify 规则

- NFKC 规范化（全角→半角）→ 小写 → 仅保留 `[a-z0-9\u4e00-\u9fff]`，其余转单个连字符
- 去除首尾/连续连字符；**循环剥除尾部 `-<数字>` 去歧义后缀**（`topic-2-3` → `topic`）
- 幂等：`slugify(slugify(x)) == slugify(x)`
- 空/非字符串输入 → `""`

## 5. 生命周期状态迁移表（lifecycle.py::TRANSITIONS）

| 当前 \ 目标 | draft | current | archive | unknown |
|-------------|:---:|:---:|:---:|:---:|
| draft | ✗ | ✓ | **✗ 拒绝直跳** | ✓ |
| current | ✓ | ✗ | ✓ | ✗ |
| archive | ✗ | ✗ | ✗（终态） | ✗ |
| unknown | ✓ | ✓ | ✗ | ✗ |

- `can_transition(current, target) -> bool`（不抛异常）
- `validate_transition(current, target) -> Optional[str]`（合法 None，非法原因字符串；
  非 CardStatus 入参 → `非法当前状态/非法目标状态`）
- 状态迁移不移动文件，仅更新 frontmatter；唯一例外：Archive 态物理移入 `archives/`（任务2 重链）
