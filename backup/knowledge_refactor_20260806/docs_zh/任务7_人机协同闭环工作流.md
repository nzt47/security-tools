# 任务7：人机协同闭环工作流

**任务ID**: T7
**阶段**: 7（闭环层）
**前置依赖**: 任务2（卡片引擎）、任务4（检索）、任务5（治理）
**预计工作量**: 3-4 天
**输出类型**: Python 模块 + 对话工具入口 + 测试

---

## 一、目标描述

打通设计文件《最好的个人知识库》的完整人机协同工作流：Inbox 收集 → AI 提炼 → 深度讨论（人机追问校准）→ 产卡聚合 → 定时审计，作为可对话触发的端到端流程。固化"AI 簿记、人思考"边界（【不易】约束）：AI 不替人做判断，只维护链接/摘要/格式/矛盾标记。

参考工作流（设计文件）：

```
Step1 低摩擦收集  → 任务1 Ingest
Step2 AI辅助清洗  → 任务3 Distill
Step3 深度讨论    → 本任务 discuss（AI 扮演作者/领域专家）
Step4 产卡与聚合  → 本任务 card_from_discussion（任务2 CardStore）
Step5 审计与健康  → 任务5 Lint
```

产卡映射：

|---|---|

### Step 4：对话工具入口

将工作流暴露为云枢可调用工具（复用 `agent/tools` 机制，参考现有工具注册方式）：

| 工具名 | 功能 | 映射 |
|---|---|---|
| `kb_capture` | 收集素材入库 | `run_ingest` |
| `kb_distill` | 提炼结构化笔记 | `run_distill` |
| `kb_discuss` | 深度讨论 | `run_discuss` |
| `kb_card` | 产卡 | `run_card` |
| `kb_lint` | 健康巡检 | `run_audit` |
| `kb_search` | 知识检索 | 任务4 `KnowledgeSearch` |

边界护栏（写死在工具实现与 AGENTS.md）：
- **AI 禁止自动执行"人生决策/个人日记"类内容入库 wiki**——此类内容仅允许 raw/inbox 保存，且 meta 标记 `sensitive=true`（复用任务1）。
- AI 只标记矛盾、建议归档，不自动裁决（裁决由人触发任务5 `resolve_conflict`）。

### Step 5：编写单元测试

新建 `tests/unit/test_knowledge_workflow.py`，覆盖：
- 全流程 happy path：capture→distill→discuss→card→audit 一条命令跑通，log.md/index.md 全程同步。
- 任一中间步骤失败（如 LLM 离线）→ 流程回退到上一状态，不产生半成品卡片。
