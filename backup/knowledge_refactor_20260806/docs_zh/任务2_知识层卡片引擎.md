# 任务2：知识层卡片引擎（核心）

**任务ID**: T2

## 一、目标描述

实现 wiki 知识卡片的核心引擎：基于任务0 的 schema，支持卡片创建/更新/读取/归档，双向链接解析与校验，生命周期状态机落地，并维护 `index.md` 与 `log.md`。

【不易】约束：不得改变现有 `MemoryInterface`（`agent/memory/base.py`）与 `VectorStore`（`memory/vector_store/vector_store.py`）接口。卡片引擎为纯文件系统存储（Markdown 文件），不依赖向量库。

```python
    """
    ...
```

规则：
- 调用 `agent.knowledge.lifecycle.can_transition` 校验，非法迁移抛 `InvalidTransitionError`。
- Archive 归档时：
  1. 移动文件到 `archives/<slug>.md`。
  2. 扫描 wiki 全部卡片，找出 `links` 含该 slug 的卡片，将其链接改为 `[[archives/<slug>|旧名]]`（或 `[[../archives/<slug>]]`，取决于链接解析约定，二选一并写入 AGENTS.md），并更新其正文中的双链文本。
  3. 更新 `index.md` 与 `log.md`。
